Anatomie

          
Jede Card besteht aus 3 optionalen Slots und bis zu 11 Convenience-Elementen.


          
3-Slot-Struktur

          

            

            
SlotElementOptionalBeschreibung

            
              
Media.nc-card__mediaJaBild, Video oder Platzhalter. Standard aspect-ratio 3:2.

              
Content.nc-card__contentNeinFreier Inhaltsbereich. flex-grow: 1, Padding via Token.

              
Footer.nc-card__footerJaAktionen, Meta. margin-top: auto, immer am unteren Rand.

            
          

        


          
Convenience-Elemente

          

            

            
ElementKlasseSlotBeschreibung

            
              
Kicker.nc-card__kickerContentEyebrow/Badge-Text (uppercase, xs, secondary)

              
Title.nc-card__titleContentHauptüberschrift, konsumiert --nc-card-title-*

              
Title Link.nc-card__title-linkContentStretched Link im Titel, ::after { inset: 0 }

              
Description.nc-card__descriptionContentFließtext, konsumiert --nc-card-description-*

              
Meta.nc-card__metaContentMetadaten-Zeile (flex row, tertiary, xs)

              
Icon.nc-card__iconContentIcon, Größe via --nc-card-action-icon-size

              
Input.nc-card__inputContentHidden Input (radio/checkbox) für Selectable

              
Footer Action.nc-card__footer-actionFooterButton im Footer, z-index: 1 über title-link

              
Summary.nc-card__summary—Summary-Element für Expandable (details/summary)

              
Expand Icon.nc-card__expand-icon—Chevron-Icon, rotiert bei [open]

              
Details Content.nc-card__details-content—Content innerhalb von <details>

DOM-Hinweise

  
    
    
  • Root-Element haengt vom Behavior ab: <article> (static), <a> (navigational-entire), <label> (selectable), <details> (expandable).
    • 
    
  • Title-Link (navigational-partial): ::after { position: absolute; inset: 0 } fuer Stretched Link.
    • 
    
  • Selectable: Hidden <input> (sr-only), :has(:checked) fuer Selected-State.
    • 
    
  • Footer-Actions haben z-index: 1 ueber dem Stretched Title-Link.
    • 
    
  • Skeleton-State via --skeleton Modifier auf Root — kein JS noetig.
    • 
  





        


        
        
        
        


          

Accessibility Referenz


Cards sind Container — interaktives Verhalten haengt vom Behavior-Typ ab.



  
  

    
Nicht interaktiv

    
    
      
  • Diese Komponente ist nicht fokussierbar und nicht klickbar.
    • 
    

  





  
  

    
Farbkontrast: WCAG AA normal text (4.5:1)

    
    
      
  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
    • 
      
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.
    • 
    

  





  
  

    
Zugänglicher Name erforderlich

    
    
      
  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).
    • 
    

  





  
  

    
Wenn: behavior = navigational

    
    
      
  • Pflicht: href
    • 
      
  • Navigational Cards muessen ein gueltiges href-Attribut haben. Bei partial-Navigation: title-link traegt den Link.
    • 
    

  





  
  

    
Wenn: behavior = selectable

    
    
      
  • Pflicht: name
    • 
      
  • Pflicht: value
    • 
      
  • Selectable Cards benoetigen name und value auf dem Hidden Input. :has(:checked) steuert den Selected-State.
    • 
    

  





  
  

    
Wenn: behavior = expandable

    
    
      
  • Empfohlen: aria-expanded
    • 
      
  • details/summary bietet native Expansion. Falls custom JS: aria-expanded erforderlich.
    • 
    

  





  
  

    
Wenn: pattern = status

    
    
      
  • Pflicht: aria-label
    • 
      
  • Status-Indikator (Farbe) darf nicht das einzige Signal sein. Textuelle Begleitung oder aria-label noetig.
    •
