Checkbox

Custom Checkbox mit nativem Input und visuellem Control-Element. Unterstützt Checked, Indeterminate und Disabled. Kanonische Klasse: .nc-checkbox (BEM). Alle Werte kommen aus --nc-checkbox-* Component-Tokens.

Accessibility Referenz

Checkbox-Komponenten nutzen natives <input type="checkbox"> und müssen die WCAG 2.1 AA-Kriterien erfüllen.

Gruppen-Semantik (role="group")

  • Checkbox-Gruppen müssen role="group" am Container haben
  • Die Gruppe muss mit aria-labelledby einen sichtbaren Gruppentitel referenzieren
  • Alternativ aria-label am Container, wenn kein sichtbarer Titel vorhanden
  • Screenreader kündigen die Gruppe an: “[Titel], Gruppe”

Indeterminate-State (:indeterminate)

  • Der Indeterminate-State kann nur per JavaScript gesetzt werden: checkbox.indeterminate = true
  • Es gibt kein HTML-Attribut dafür — nur die DOM-Property
  • Screenreader kündigen an: “mixed” (anstelle von “checked” oder “unchecked”)
  • Typischer Anwendungsfall: “Alle auswählen”-Checkbox, wenn nur einige Kinder aktiviert sind
  • Visuell wird ein horizontaler Strich statt des Checkmarks angezeigt

Tastaturnavigation

  • Tab fokussiert die nächste Checkbox
  • Space toggled den Checked-State
  • Jede Checkbox ist individuell per Tab erreichbar (anders als Radio-Buttons)
  • Der Focus-Ring (--nc-checkbox-focus-ring) muss sichtbar sein

Farbkontrast (WCAG 1.4.3 / 1.4.11)

  • Label-Text muss mindestens 4.5:1 Kontrast zum Hintergrund haben
  • Das Control-Element (Rahmen) muss mindestens 3:1 Kontrast haben (UI-Komponente, WCAG 1.4.11)
  • Das Checkmark-Icon muss zum --nc-checkbox-bg-checked-Hintergrund kontrastreich sein
  • Disabled-State ist von den Kontrastanforderungen ausgenommen
