Themes

Verwaltung und Konfiguration der 4 Design-System Themes. Neo-Themes sind schreibgeschützt, Customer-Themes frei konfigurierbar.

Was sind Themes?

Das Design-System nutzt eine 3-Schichten Color-Architektur. Primitives definieren die Basis-Farbpaletten (primary, secondary, accent). Semantische Tokens vergeben feste Rollen (text-primary, background-base, etc.). Themes bringen beides zusammen und erzeugen unterschiedliche Erscheinungsbilder für hell/dunkel und Neo/Customer.

Layer System (Carbon-Modell)

Geschachtelte Container nutzen layer-01 bis layer-03 fuer abgestufte Hintergruende.

Regel Light: background-base (weiss) → layer-01 (grau) → layer-02 (weiss) — alternierend.

Regel Dark: background-base (#0f0f0f) → layer-01 (#1a1a1a) → layer-02 (#252525) → layer-03 (#303030) — aufsteigend ("Lifted Dark").

Interaktions-Stati (State Tokens)

Interaktive Elemente (Buttons, Tags, Chips) benötigen Zustands-Varianten für hover und active. Das Design System erzeugt diese automatisch per color-mix() — die Mischrichtung kehrt sich im Dark Mode automatisch um.

Foundation-Token: --fnd-state-mix-target

Dieser Token steuert die Richtung der Zustandsfarben-Mischung:

Theme-KontextWertEffekt
Light (neo-light, customer-light) var(--fnd-color-always-dark) Hover/Active dunkeln ab
Dark (neo-dark, customer-dark) var(--fnd-color-always-light) Hover/Active hellen auf

Zwei Kategorien: bold & subtle

Die Intensität der Zustandsänderung hängt von der Flächenart ab. Das Sass-Mixin state-colors() unterstützt zwei Kategorien:

KategorieHoverActiveEinsatz
bold 15% Mix (85% Basis) 25% Mix (75% Basis) Gefüllte farbige Flächen (Buttons, Tags mit solidem Hintergrund)
subtle 8% Mix (92% Basis) 15% Mix (85% Basis) Transparente/kontrastarme Flächen (Ghost, Chips, Tabellenzeilen)

Sass-Mixin Verwendung

// Erzeugt 3 Tokens: base, base-hover, base-active
@include state.state-colors(
  --nc-button-success-bg,
  var(--fnd-color-feedback-success)
);
// → --nc-button-success-bg:        var(--fnd-color-feedback-success);
// → --nc-button-success-bg-hover:  color-mix(in srgb, ... 85%, var(--fnd-state-mix-target));
// → --nc-button-success-bg-active: color-mix(in srgb, ... 75%, var(--fnd-state-mix-target));

// Nur Hover-Token (z.B. fuer Tags)
@include state.state-hover(
  --nc-tag-info-bg,
  var(--fnd-color-background-info),
  $category: 'bold'
);

// Subtle-Kategorie fuer dezente Flaechen
@include state.state-colors(
  --nc-chip-bg,
  var(--fnd-color-background-secondary),
  $category: 'subtle'
);
