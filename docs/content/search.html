DOM-Hinweise

  • Root: role='combobox', aria-haspopup='listbox', aria-expanded='true|false'.
  • Input-Wrapper: relative Container mit Scope-Trigger (optional), Such-Icon (links), Input (Mitte), Ghost (optional), Shortcut-Hint (rechts).
  • Scope-Trigger: Button links im Input-Wrapper, zeigt aktuellen Suchbereich + Chevron. Oeffnet scope-menu.
  • Ghost: Absolute positionierter, transparenter Vorschlagstext (Type-Ahead). pointer-events: none.
  • Such-Icon: absolute positioniert, pointer-events:none, dekorativ (aria-hidden).
  • Input: nutzt nc-input Tokens, extra padding-start fuer Icon. aria-autocomplete='list', aria-controls.
  • Shortcut-Hint: optionales Kbd-Element (z.B. Cmd+K), absolute rechts, dekorativ.
  • Scope-Menu: Absolute Dropdown unter dem Input-Wrapper mit Bereichsauswahl.
  • Results: position:absolute, role='listbox'. Versteckt via [hidden]. Animation: fnd-dropdown-enter.
  • Item: role='option', aria-selected='true|false'. Hover und aria-selected bekommen bg-hover.
  • Highlight: <mark> Element mit Warning-30% Background fuer Treffer-Hervorhebung.
  • Command Palette: position:fixed Overlay, zentriert, aria-modal='true', role='dialog'.
  • Minimal: Transparenter Input ohne Border, ideal fuer Header-Integration.
  • XL: 64px Hoehe, groessere Schrift, fuer Hero-Suchfelder.

Accessibility Referenz

Root: role='combobox', aria-haspopup='listbox', aria-expanded. Input: aria-autocomplete='list', aria-controls zeigt auf Results-ID. Results: role='listbox'. Items: role='option', aria-selected. Keyboard: ArrowDown/Up navigiert Items, Enter waehlt, Escape schliesst Results. Such-Icon: aria-hidden='true'.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: resultsState = empty

  • Empfohlen: aria-live
  • Empty-State: 'Keine Ergebnisse' via aria-live='polite' ankuendigen.

Wenn: resultsState = loading

  • Empfohlen: aria-busy
  • Loading-State: aria-busy='true' auf dem Results-Container waehrend der Suche.

Wenn: scope = scoped

  • Empfohlen: aria-label
  • Scope-Trigger: aria-label beschreibt aktuellen Suchbereich (z.B. 'Suche in: Dokumente'). Scope-Menu: role='listbox' mit aria-label='Suchbereich waehlen'.

Wenn: appearance = xl

  • Empfohlen: aria-label
  • XL: aria-label statt Placeholder fuer barrierefreie Beschreibung des Hero-Suchfelds.
