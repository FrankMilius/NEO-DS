Typography

Einheitliches Fluid Typography System. Alle drei Kategorien — Display, Heading, Paragraph — nutzen clamp() für viewport-responsive Skalierung zwischen 320px und 1400px.

Font Families

Drei Schriftfamilien bilden die typografische Basis. Body-Text nutzt Manrope für optimale Lesbarkeit, Überschriften nutzen Space Grotesk für visuelle Prägnanz, Code-Elemente nutzen DM Mono für klare Monospace-Darstellung. Alle drei sind per Theme überschreibbar.

Einheitliches System

Alle drei Kategorien teilen dasselbe Fluid-Fundament. Die SCSS-Mixins bilden eine konsistente API.

/* Einheitliche API */ @include display('l'); // → Display L: 48px → 64px, LH ×1.15 @include heading('m'); // → Heading M: 24px → 31px, LH ×1.15 @include paragraph('l'); // → Paragraph L: 14px → 18px, LH ×1.6 /* Alle nutzen CSS Custom Properties */ font-size: var(--fnd-typography-{category}-{size}-font-size); line-height: var(--fnd-typography-{category}-{size}-line-height); letter-spacing: var(--fnd-typography-{category}-{size}-letter-spacing); /* Gemeinsames Fluid-Fundament */ Viewport Range: 320px – 1400px Base Scale: Modular Scale Ratio 1.2 Line-Heights: Heading = ×1.15 | Body = ×1.6 | Tight = ×1.05
