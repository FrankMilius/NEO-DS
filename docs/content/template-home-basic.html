Template: Home Basic

Inhalts-Sektion für die Homepage mit 12-Spalten-Grid (7 + 5). Titel links, Optionslink rechts, Body unten links, Media unten rechts. Basisklasse: .home-basic.

Verwendungszweck

Das Home-Basic-Template ist der Standard-Inhaltsblock der Homepage. Es folgt typischerweise auf den Hero-Bereich und stellt einen Themenbereich mit grossem Titel, optionalem „Alle anzeigen“-Link, Fliesstext und einer Medien-Kachel dar. Mehrere .home-basic-Sektionen können vertikal gestapelt werden.

Layout-Struktur

Auf Desktop wird ein 12-Spalten-Grid mit grid-columns(7) + grid-columns(5) aktiviert. Auf Mobile ist das Layout einspaltiger Flächenfluss.

.home-basic // padding-block: spacing-10 (mobile) / spacing-12 (desktop) // desktop: grid, grid-template-areas: title link / body media .home-basic-title // grid-area: title; heading(xl); color: text-low em // font-style: normal; color: text-high .home-basic-link // grid-area: link; place-self: start end .home-basic-body // grid-area: body; align-self: end; heading(xs); color: text-mid .button-container // margin-block: spacing-08 0 .home-basic-media // grid-area: media; border-radius: radius-lg; overflow: clip img // aspect-ratio: fnd-media-ratio-4-3; object-fit: cover

em-Element im Titel

  • Das <em>-Element wird mit font-style: normal rein visuell eingesetzt.
  • Screenreader können <em> mit einer Betonungs-Prosodie vorlesen — semantisch korrekt für Hervorhebungen.
  • Wenn die Hervorhebung rein visuell ohne semantische Bedeutung ist, stattdessen <span> verwenden.

Link-Kontext

  • .home-basic-link enthält häufig einen „Alle ansehen“-Link.
  • Dieser Link muss einen beschreibenden Kontext haben — z.B. „Alle Produkte ansehen“ statt nur „Alle ansehen“.
  • Alternativ: aria-label mit vollem Kontext auf dem <a> setzen.
