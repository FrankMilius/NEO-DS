Radio

Accessibility Referenz

Radio-Komponenten nutzen natives <input type="radio"> und müssen die WCAG 2.1 AA-Kriterien erfüllen.

role="radiogroup"

  • Der Container für zusammengehörige Radios muss role="radiogroup" erhalten
  • aria-labelledby verweist auf die sichtbare Gruppen-Überschrift
  • Bei Validierungsfehlern aria-describedby auf die Fehlermeldung setzen
  • Alle Radios einer Gruppe teilen denselben name-Attribut

Tastatur-Navigation (Pfeiltasten)

  • Tab springt in die Gruppe (fokussiert den ausgewählten oder ersten Radio)
  • Pfeil hoch / Pfeil links — vorherige Option auswählen
  • Pfeil runter / Pfeil rechts — nächste Option auswählen
  • Die Auswahl wechselt sofort beim Pfeiltasten-Drücken (natives Verhalten)
  • Space wählt den aktuell fokussierten Radio aus (falls nicht bereits ausgewählt)

Focus-Ring

  • Der Focus-Ring wird auf .nc-radio__control delegiert, obwohl der native Input fokussiert ist
  • Nur bei :focus-visible sichtbar (nicht bei Maus-Klick)
  • Der native Input ist per sr-only visuell versteckt, bleibt aber im Tab-Flow
