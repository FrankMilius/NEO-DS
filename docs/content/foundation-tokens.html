Foundation Tokens

Alle Foundation-Tokens beginnen mit --fnd- und bilden die Basis fuer das gesamte Design System.

Layer System (Carbon-Modell)

Geschachtelte Container nutzen layer-01 bis layer-03.

Regel Light: background-base (weiss) → layer-01 (grau) → layer-02 (weiss) — alternierend.

Regel Dark: background-base (schwarz) → layer-01 (dunkelgrau) → layer-02 (grau) — aufsteigend.

background-base (Page)
layer-01 (Card)
layer-02 (Element in Card)
--fnd-color-layer-01/02/03
Container-Hintergruende fuer geschachtelte Ebenen
--fnd-color-on-surface
Textfarbe auf background-base
--fnd-color-on-layer-01
Textfarbe auf layer-01
--fnd-color-on-layer-02
Textfarbe auf layer-02

Motion / Keyframes

Foundation-Keyframes fuer konsistente Ein-/Ausblend-Animationen. Alle respektieren prefers-reduced-motion.

fnd-fade-in / fnd-fade-out
Opacity 0 → 1 / 1 → 0
fnd-slide-up / down / left / right
8px translate + fade
fnd-scale-in / fnd-scale-out
Scale 0.95 → 1 + fade
fnd-spin
360-Grad-Rotation (Spinner)
fnd-dialog-enter / exit
Scale + fade + translateY(4px)
fnd-dropdown-enter
Slide down + fade
fnd-toast-enter
Slide up 16px + fade
Do: animation: fnd-dialog-enter 0.2s var(--fnd-motion-ease-focused) forwards;
