Checkbox Group

Container für mehrere Checkboxen mit gemeinsamem Label und Gruppen-Semantik. Unterstützt vertikales und horizontales Layout, Size-gekoppelten Gap, Select-All Header und Gruppen-Hint. Kanonische Klasse: .nc-checkbox-group (BEM). Alle Werte kommen aus --nc-group-* Component-Tokens.

Verwendung

Die Checkbox-Group fasst mehrere Checkboxen in einer semantischen Gruppe zusammen. Sie sorgt für konsistente Abstände und propagiert States (Error, Disabled) auf alle enthaltenen Checkboxen.

Default (Vertikal)

<div class="nc-checkbox-group" role="group" aria-labelledby="group-label">
  <span id="group-label" class="nc-form-label">Optionen</span>
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
</div>

Horizontal

Checkboxen nebeneinander mit flex-wrap bei Platzmangel.

<div class="nc-checkbox-group nc-checkbox-group--horizontal" role="group" aria-labelledby="group-label">
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
</div>

Size-Varianten

Gap-Abstufung gekoppelt an Checkbox-Größe: SM (8px), MD (12px, Standard), LG (16px).

<div class="nc-checkbox-group nc-checkbox-group--sm">...</div>
<div class="nc-checkbox-group">...</div>  <!-- MD (Default) -->
<div class="nc-checkbox-group nc-checkbox-group--lg">...</div>

Select-All (Master-Checkbox)

Header-Slot mit Master-Checkbox und Separator. Indeterminate-State bei Teilauswahl.

<div class="nc-checkbox-group" role="group" aria-labelledby="group-label">
  <div class="nc-checkbox-group__header">
    <label class="nc-checkbox">
      <input type="checkbox" class="nc-checkbox__input" />
      <span class="nc-checkbox__control">...</span>
      <span class="nc-checkbox__label">Alle auswählen</span>
    </label>
  </div>
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
</div>

Mit Gruppen-Hint

<div class="nc-checkbox-group" role="group" aria-labelledby="group-label" aria-describedby="group-hint">
  <label class="nc-checkbox">...</label>
  <label class="nc-checkbox">...</label>
  <div class="nc-checkbox-group__hint">
    <span class="nc-form-hint" id="group-hint">Wählen Sie mindestens eine Option.</span>
  </div>
</div>

States

Error propagiert roten Rand auf alle Checkbox-Controls. Disabled graut die gesamte Gruppe aus.

<!-- Error -->
<div class="nc-checkbox-group nc-checkbox-group--error" role="group" aria-describedby="group-error">
  <label class="nc-checkbox">...</label>
  <span class="nc-form-error" id="group-error" role="alert">Bitte mindestens eine Option wählen.</span>
</div>

<!-- Disabled -->
<div class="nc-checkbox-group nc-checkbox-group--disabled" role="group">
  <label class="nc-checkbox">
    <input type="checkbox" disabled />...
  </label>
</div>

DOM-Hinweise

  • Flex-Column Container für mehrere .nc-checkbox Elemente.
  • Gap via --nc-group-gap. Horizontal: flex-row, flex-wrap, --nc-group-gap-horizontal.
  • Size-Modifier koppelt Gap an Checkbox-Größe: sm=8px, md=12px, lg=16px.
  • Header-Slot: Enthält Master-Checkbox für Select-All. Separator via border-bottom.
  • Master-Checkbox nutzt :indeterminate wenn nur Teilmenge ausgewählt (input.indeterminate = true).
  • Error propagiert border-error auf alle Checkbox-Controls.
  • Disabled: opacity + pointer-events:none auf gesamte Gruppe.

Accessibility Referenz

Die Checkbox-Group nutzt role="group" mit aria-labelledby für die semantische Gruppierung. Einzelne Checkboxen haben eigene A11y-Anforderungen.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.

Pflicht: role="group" + aria-labelledby

  • Pflicht: role="group" auf dem Container.
  • Pflicht: aria-labelledby verweist auf Legend oder Label.

Wenn: Error-State

  • Empfohlen: aria-describedby auf Gruppen-Error-Text.

Wenn: Select-All Header

  • Empfohlen: aria-checked="mixed" im Indeterminate-State.
  • Master-Checkbox: Bei Teilauswahl input.indeterminate = true und aria-checked="mixed".
  • JS muss den Zustand synchronisieren: alle gecheckt → checked, keins → unchecked, teilweise → indeterminate.

Wenn: Gruppen-Hint vorhanden

  • Empfohlen: aria-describedby auf dem Gruppen-Container verweist auf Hint-ID.
