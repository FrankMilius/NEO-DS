Alert Dialog

Modaler Bestätigungs-Dialog basierend auf dem nativen <dialog>-Element. Fokus-Trap, ESC-Close und Body-Scroll-Lock sind nativ integriert. Kanonische Klasse: .nc-alert-dialog (BEM). Verwendet --nc-dialog-* Component-Tokens.

Live Demo

Wähle Theme, Action-Style und Beschreibungs-Modus, um den Alert Dialog live zu konfigurieren.

Action-Style

Code

<dialog class="nc-alert-dialog" aria-labelledby="dlg-title" aria-describedby="dlg-desc">
  <div class="nc-alert-dialog__header">
    <h2 class="nc-alert-dialog__title" id="dlg-title">Sind Sie sicher?</h2>
    <p class="nc-alert-dialog__description" id="dlg-desc">
      Diese Aktion kann nicht rückgängig gemacht werden.
    </p>
  </div>
  <div class="nc-alert-dialog__footer">
    <button class="nc-button nc-button--outline">Abbrechen</button>
    <button class="nc-button nc-button--danger" autofocus>Löschen</button>
  </div>
</dialog>

Basis Alert Dialog

Kanonische HTML-Struktur eines Alert Dialogs. Der Dialog wird per showModal() geöffnet und ist ein modales Overlay.

<dialog class="nc-alert-dialog" aria-labelledby="dlg-title" aria-describedby="dlg-desc"> <div class="nc-alert-dialog__header"> <h2 class="nc-alert-dialog__title" id="dlg-title">Sind Sie sicher?</h2> <p class="nc-alert-dialog__description" id="dlg-desc"> Diese Aktion kann nicht rückgängig gemacht werden. </p> </div> <div class="nc-alert-dialog__footer"> <button class="nc-button nc-button--outline">Abbrechen</button> <button class="nc-button nc-button--danger" autofocus>Löschen</button> </div> </dialog>

Destructive Confirmation

Ein destruktiver Bestätigungs-Dialog für kritische Aktionen wie das Löschen eines Kontos.

Ohne Beschreibung

Ein vereinfachter Dialog ohne Beschreibungstext — nur Titel und Aktions-Buttons.

JavaScript API

Die native <dialog>-API zum Öffnen, Schließen und Event-Handling.

// Öffnen (modal mit Backdrop + Focus-Trap) const dialog = document.querySelector('.nc-alert-dialog'); dialog.showModal(); // Schließen dialog.close(); // Event: Dialog wurde geschlossen dialog.addEventListener('close', () => { console.log('Dialog geschlossen, returnValue:', dialog.returnValue); }); // Event: ESC gedrückt dialog.addEventListener('cancel', (e) => { // Optional: e.preventDefault() um ESC zu blockieren });

DOM-Hinweise

  • Root: natives <dialog> Element. showModal() fuer modale Anzeige.
  • Verwendet --nc-dialog-* Tokens (geteilt mit Modal und Drawer).
  • Icon-Slot (v2.0): Optionales Status-Icon vor dem Header. Bei destructive: rotes Warnsymbol (nc-dialog-danger-icon-color). Verstaerkt visuelle Dringlichkeit.
  • Header: flex-column, Title + Description. Gap via header-gap.
  • Footer: flex, justify-end, Cancel + Action Buttons.
  • [open]: display:flex. Zentriert via fixed + margin:auto.
  • Backdrop: ::backdrop mit overlay-bg Fade-in Animation.
  • Body Scroll Lock: body:has(.nc-alert-dialog[open]) { overflow: hidden }.
  • Destructive-Modifier: .nc-alert-dialog--destructive setzt Icon-Farbe auf danger und styled Action-Button als Danger-Button.
  • Focus-Management: Bei default: autofocus auf Action-Button (primaere Aktion). Bei destructive: autofocus auf Cancel-Button (verhindert versehentliches Loeschen = Anti-Slipping-Pattern).
  • Visuelle Synergie: Danger-Farben (bg, border, icon-color) sind identisch mit .nc-alert--danger, sodass ein Danger-Alert im Formular visuell exakt zum darauf folgenden Destructive-Alert-Dialog passt.

Accessibility Referenz

Natives <dialog> liefert role='dialog', aria-modal='true' bei showModal(). aria-labelledby → Title. aria-describedby → Description. ESC schliesst nativ. Fokus-Trap nativ.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: intent = default

  • Empfohlen: autofocus-action
  • Default: autofocus auf Action-Button (primaere Aktion) fuer direkten Keyboard-Zugriff.

Wenn: intent = destructive

  • Pflicht: autofocus-cancel
  • Destructive: autofocus auf Cancel-Button statt Action — verhindert Slipping-Fehler (versehentliches Loeschen bei schnellem Enter). Best-Practice fuer destruktive Aktionen.

Wenn: content = with-icon

  • Pflicht: aria-hidden-icon
  • Status-Icon ist dekorativ (aria-hidden='true'). Semantik kommt aus dem Titel und der Beschreibung.
