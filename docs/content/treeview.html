TreeView

Hierarchische Baumnavigation mit Expand/Collapse, Keyboard-Navigation und optionalen Icons. Inspiriert vom Carbon Design System TreeView. Kanonische Klasse: .nc-treeview (BEM). Verwendet --nc-treeview-* Component-Tokens.

Live Demo

Wähle Theme und Variante, um den TreeView live zu konfigurieren.

Variante

Code


          


          
          

            
Default

            

              Einfache verschachtelte Baumstruktur mit Expand/Collapse. Klicke auf eine Zeile oder den Chevron, um Untergruppen zu öffnen.
            

            

          


          
          

            
Controlled Expansion

            

              TreeView mit zwei Steuerungs-Buttons: „Alles aufklappen“ und „Alles zuklappen“.
            

            

          


          
          

            
With Icons

            

              TreeView mit kontextuellen Icons aus dem Icon-Set. Ordner-Icons für Branch-Nodes, Dokument-Icons für Leaf-Nodes.
            

            

          


          
          

            
With Links (extern)

            

              TreeView mit externen Links. Leaf-Nodes sind <a>-Elemente mit target="_blank" und einem External-Link-Indikator.
            

            

          


          
          

            
JavaScript API

            

              Expand/Collapse wird über aria-expanded gesteuert. Selection über CSS-Klasse und aria-selected.
            

            
// Toggle expand/collapse
const item = document.querySelector('.nc-treeview__item--branch');
const isExpanded = item.getAttribute('aria-expanded') === 'true';
item.setAttribute('aria-expanded', String(!isExpanded));

// Select an item
tree.querySelectorAll('.nc-treeview__item').forEach(i => {
  i.classList.remove('nc-treeview__item--selected');
  i.setAttribute('aria-selected', 'false');
});
item.classList.add('nc-treeview__item--selected');
item.setAttribute('aria-selected', 'true');

// Expand all
tree.querySelectorAll('.nc-treeview__item--branch').forEach(i => {
  i.setAttribute('aria-expanded', 'true');
});

// Collapse all
tree.querySelectorAll('.nc-treeview__item--branch').forEach(i => {
  i.setAttribute('aria-expanded', 'false');
});

State Management

            

              States werden über ARIA-Attribute und CSS-Klassen gesteuert — kein data-state.

DOM-Hinweise

  
    
    
  • Hierarchische Baumstruktur mit role=tree und role=treeitem.
    • 
    
  • Toggle-Chevron rotiert sanft 0° auf 90° bei Expand (CSS transition).
    • 
    
  • Children-Slot nutzt CSS-Grid 0fr→1fr Animation fuer Slide-Down.
    • 
    
  • Action-Slot (rechts) wird nur bei Hover/Focus-within sichtbar.
    • 
    
  • Guide-Lines: Vertikale Linien verbinden Eltern mit Kindern (optional).
    • 
    
  • Checkbox-Mode: Checkboxen pro Node fuer Multi-Select (aria-checked).
    • 
    
  • Drag-Handle: 6-dots Griff, nur bei --draggable Modifier sichtbar.
    •

Accessibility Referenz


role=tree auf Root-<ul>. role=treeitem auf <li>. role=group auf verschachtelten <ul>. aria-expanded fuer Branch-Items. Keyboard: ArrowUp/Down navigiert, ArrowLeft/Right collapsed/expanded, Home/End springt, Enter/Space selektiert.



  
  

    
Farbkontrast: WCAG AA normal text (4.5:1)

    
    
      
  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
    • 
      
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.
    • 
    

  





  
  

    
Fokus-Indikator

    
    
      
  • focus-ring mixin, :focus-visible
    • 
    

  





  
  

    
Zugänglicher Name erforderlich

    
    
      
  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).
    • 
    

  





  
  

    
Wenn: selection = multiple

    
    
      
  • Pflicht: aria-checked
    • 
      
  • Im Checkbox-Mode: aria-checked='true|false|mixed'. Eltern-Checkbox nutzt 'mixed' wenn nur einige Kinder ausgewaehlt.
    • 
    

  





  
  

    
Wenn: interaction = draggable

    
    
      
  • Drag-Handle benoetigt aria-label='Element verschieben'. Drop-Targets brauchen aria-dropeffect='move'. aria-grabbed auf gezogenem Item.
    •
