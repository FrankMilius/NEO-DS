TreeView

Hierarchische Baumnavigation mit Expand/Collapse, Keyboard-Navigation und optionalen Icons. Inspiriert vom Carbon Design System TreeView. Kanonische Klasse: .nc-treeview (BEM). Verwendet --nc-treeview-* Component-Tokens.

Wähle Theme und Variante, um den TreeView live zu konfigurieren.

Variante

Code


          


          
          

            
Default

            

              Einfache verschachtelte Baumstruktur mit Expand/Collapse. Klicke auf eine Zeile oder den Chevron, um Untergruppen zu öffnen.
            

            

          


          
          

            
Controlled Expansion

            

              TreeView mit zwei Steuerungs-Buttons: „Alles aufklappen“ und „Alles zuklappen“.
            

            

          


          
          

            
With Icons

            

              TreeView mit kontextuellen Icons aus dem Icon-Set. Ordner-Icons für Branch-Nodes, Dokument-Icons für Leaf-Nodes.
            

            

          


          
          

            
With Links (extern)

            

              TreeView mit externen Links. Leaf-Nodes sind <a>-Elemente mit target="_blank" und einem External-Link-Indikator.
            

            

          


          
          

            
JavaScript API

            

              Expand/Collapse wird über aria-expanded gesteuert. Selection über CSS-Klasse und aria-selected.
            

            
// Toggle expand/collapse
const item = document.querySelector('.nc-treeview__item--branch');
const isExpanded = item.getAttribute('aria-expanded') === 'true';
item.setAttribute('aria-expanded', String(!isExpanded));

// Select an item
tree.querySelectorAll('.nc-treeview__item').forEach(i => {
  i.classList.remove('nc-treeview__item--selected');
  i.setAttribute('aria-selected', 'false');
});
item.classList.add('nc-treeview__item--selected');
item.setAttribute('aria-selected', 'true');

// Expand all
tree.querySelectorAll('.nc-treeview__item--branch').forEach(i => {
  i.setAttribute('aria-expanded', 'true');
});

// Collapse all
tree.querySelectorAll('.nc-treeview__item--branch').forEach(i => {
  i.setAttribute('aria-expanded', 'false');
});

BEM-Klassenübersicht

            
// ===== BEM-Klasse (kanonisch) =====

.nc-treeview                        // Block (nav Wrapper)
.nc-treeview__controls              // Expand/Collapse-All Buttons
.nc-treeview__list                  // ul (role="tree" / role="group")
.nc-treeview__item                  // li (role="treeitem")
.nc-treeview__node                  // Interaktive Zeile (div)
.nc-treeview__toggle                // Chevron-Button
.nc-treeview__icon                  // Icon-Slot (optional)
.nc-treeview__label                 // Text-Content
.nc-treeview__link                  // Externer Link (ersetzt label)

// Modifier
.nc-treeview__item--branch          // Hat Kinder (expandable)
.nc-treeview__item--leaf            // Kein Kinder (terminal)
.nc-treeview__item--selected        // Ausgewaehlt
.nc-treeview__item--disabled        // Deaktiviert

// State via ARIA
[aria-expanded="true"]              // Branch ist aufgeklappt
[aria-expanded="false"]             // Branch ist zugeklappt
[aria-selected="true"]              // Item ist selektiert

          


          
          

            
State Management

            

              States werden über ARIA-Attribute und CSS-Klassen gesteuert — kein data-state.
            

            

              
StateMechanismusCSS-Selektor

              
                
Expandedaria-expanded="true"[aria-expanded='true']

                
Collapsedaria-expanded="false":not([aria-expanded='true'])

                
Selected.nc-treeview__item--selectedKlasse + aria-selected

                
Disabled.nc-treeview__item--disabledKlasse + aria-disabled

                
HoverCSS :hover.nc-treeview__node:hover

                
FocusCSS :focus-visibleFocus-Ring Mixin

Accessibility Referenz

          

            Der TreeView implementiert das WAI-ARIA Tree-Pattern für vollständige Barrierefreiheit.
          


          
          

            
            

              
ARIA-Rollen

              
    
                
  • role="tree" auf dem Root-<ul>
    • 
                
  • role="treeitem" auf jedem <li>
    • 
                
  • role="group" auf verschachtelten <ul> (Kinder-Container)
    • 
                
  • aria-label auf dem <nav> für den Baum-Zweck
    • 
              

            

          


          
          

            
            

              
aria-expanded

              
    
                
  • Branch-Items erhalten aria-expanded="true/false"
    • 
                
  • Screenreader kündigen den Expand/Collapse-Status an
    • 
                
  • CSS nutzt [aria-expanded] für Chevron-Rotation und Children-Visibility
    • 
                
  • Leaf-Items haben kein aria-expanded
    • 
              

            

          


          
          

            
            

              
Keyboard-Navigation (WAI-ARIA TreeView Pattern)

              

                
TasteAktion

                
                  
↓ ArrowDownNächster sichtbarer Node

                  
↑ ArrowUpVorheriger sichtbarer Node

                  
→ ArrowRightBranch aufklappen / zum ersten Kind navigieren

                  
← ArrowLeftBranch zuklappen / zum Eltern-Node navigieren

                  
HomeErster Node im Baum

                  
EndLetzter sichtbarer Node im Baum

                  
Enter / SpaceNode aktivieren (Expand/Collapse oder Select)

                
              

            

          


          
          

            
            

              
Focus Management (Roving Tabindex)

              
    
                
  • Nur ein Node ist per Tab erreichbar (tabindex="0")
    • 
                
  • Alle anderen Nodes haben tabindex="-1"
    • 
                
  • Arrow-Keys verschieben den Fokus und aktualisieren tabindex
    • 
                
  • Beim Verlassen und Zurückkehren wird der zuletzt fokussierte Node angesteuert
    • 
              

            

          


          
          

            
            

              
Selection

              
    
                
  • aria-selected="true/false" kommuniziert den Auswahlstatus
    • 
                
  • Visueller Indikator: Left-Border + Background-Highlight
    • 
                
  • Single-Selection: Nur ein Node gleichzeitig selektiert
    • 
              

            

          


          
          

            
            

              
Externe Links

              
    
                
  • target="_blank" + rel="noopener noreferrer"
    • 
                
  • Visueller External-Arrow-Indikator für Sighted Users
    • 
                
  • Links innerhalb des Baums sind per Tab + Enter erreichbar
    • 
              

            

          


          
          

            
Best Practices

            
<!-- RICHTIG: Tree mit korrekten ARIA-Rollen -->
<nav class="nc-treeview" aria-label="Dateistruktur">
  <ul class="nc-treeview__list" role="tree">
    <li class="nc-treeview__item nc-treeview__item--branch"
        role="treeitem" aria-expanded="false">
      <div class="nc-treeview__node" tabindex="0">...</div>
      <ul class="nc-treeview__list" role="group">...</ul>
    </li>
  </ul>
</nav>

<!-- FALSCH: Kein role="tree" -->
<ul class="nc-treeview__list">
  <li>...</li>
</ul>

<!-- FALSCH: aria-expanded auf Leaf-Node -->
<li class="nc-treeview__item nc-treeview__item--leaf"
    role="treeitem" aria-expanded="false">
  <!-- Leaf-Nodes haben keine Kinder! -->
</li>

<!-- RICHTIG: Roving Tabindex -->
<div class="nc-treeview__node" tabindex="0">...</div>  <!-- Fokussiert -->
<div class="nc-treeview__node" tabindex="-1">...</div> <!-- Nicht direkt tabbbar -->

<!-- FALSCH: Alle Nodes tabbbar -->
<div class="nc-treeview__node" tabindex="0">...</div>
<div class="nc-treeview__node" tabindex="0">...</div>
