FAQ

Häufig gestellte Fragen mit ausklappbaren Antworten. Die Komponente nutzt native HTML-Disclosure-Elemente (<details> / <summary>) für vollständige Tastatur- und Screenreader-Unterstützung ohne JavaScript. Kanonische Klasse: .nc-faq (BEM).

Live Demo

FAQ-Komponente in verschiedenen Themes. Klicke auf eine Frage, um die Antwort ein- und auszublenden.

Was ist das NEO Design System?

Das NEO Design System ist eine Sammlung wiederverwendbarer Komponenten und Design-Token, die eine konsistente und barrierefreie Benutzeroberfläche ermöglicht.

Wie werden Themes gewechselt?

Themes werden über CSS-Klassen gesteuert. Setze .neo-light-theme, .neo-dark-theme, .customer-light-theme oder .customer-dark-theme auf das <html>-Element.

Werden alle Browser unterstützt?

Das System unterstützt alle modernen Browser (Chrome, Firefox, Safari, Edge) ab den jeweils letzten zwei Hauptversionen.

Code

<div class="nc-faq">
  <details class="nc-faq__item">
    <summary class="nc-faq__question">Frage lautet?</summary>
    <p class="nc-faq__answer">Die Antwort hierauf ist ...</p>
  </details>
</div>

Standard FAQ-Liste

Mehrere Einträge als eigenständige <details>-Elemente. Mehrere Einträge können gleichzeitig geöffnet sein.

Wie installiere ich die Komponenten?

Die Komponenten werden über npm installiert. Führe npm install @neo/design-system in deinem Projektverzeichnis aus.

Kann ich einzelne Komponenten importieren?

Ja, alle Komponenten sind einzeln importierbar. Importiere nur die SCSS-Datei der benötigten Komponente oder nutze Tree-Shaking im Build-Prozess.

Gibt es TypeScript-Unterstützung?

Alle JavaScript-Komponenten werden mit vollständigen TypeScript-Definitionen geliefert. Die Typen sind im Paket enthalten.

Accessibility Referenz

Die FAQ-Komponente basiert vollständig auf den nativen HTML-Elementen <details> und <summary>, die bereits vollständige Barrierefreiheit durch den Browser mitbringen. Kein zusätzliches ARIA oder JavaScript notwendig.

Native <details> / <summary>-Semantik

  • <details> hat nativ die Semantik eines Disclosure-Widgets
  • <summary> ist automatisch fokussierbar und hat die Rolle button
  • Der Zustand (geöffnet/geschlossen) wird dem Screenreader automatisch mitgeteilt
  • Kein aria-expanded oder aria-controls notwendig

Tastatur-Bedienung

  • Tab: Fokus zum nächsten <summary> bewegen
  • Enter / Space: Eintrag öffnen oder schließen
  • Alle Einträge sind vollständig per Tastatur bedienbar – ohne JavaScript

Strukturierung und Kontext

  • Wende eine übergeordnete Sektion mit Heading an, wenn die FAQ im Seitenkontext steht
  • Beispiel: <section aria-labelledby="faq-heading"><h2 id="faq-heading">Häufige Fragen</h2> <div class="nc-faq">...</div></section>
  • Die Antwort (.nc-faq__answer) darf strukturierten Inhalt (Listen, Links) enthalten
