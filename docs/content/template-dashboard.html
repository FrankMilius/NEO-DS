Template: Dashboard

Applikations-Layout mit fixer Sidebar, Sticky-Header und flexiblem Hauptbereich. Metric-Cards und Content-Karten nutzen Layer-Tokens für verschachtelte Hintergründe. Basisklasse: .t-dashboard.

Verwendungszweck

Das Dashboard-Template ist das Haupt-Applikationslayout für Verwaltungs- und Analyse-Interfaces. Es kombiniert eine persistente Sidebar-Navigation mit einem sticky Header und einem scrollbaren Hauptbereich für KPI-Karten, Tabellen und Diagramme. Die Layer-Tokens (--fnd-color-layer-01/02) erzeugen hierarchisch gestaffelte Hintergründe, die im Dunkelmodus automatisch korrekt invertiert werden.

Layout-Struktur

Das Template nutzt ein CSS-Grid mit 2 Spalten (260px 1fr) und 2 Reihen (auto 1fr). Die Sidebar spannt beide Reihen auf; Header und Main füllen die rechte Spalte.

Aktiver Navigationspunkt

  • [aria-current='page'] auf dem aktuell aktiven .t-dashboard__sidebar-link setzen.
  • Nicht aria-selected verwenden — das ist für Tab-Panels, nicht für Links.
  • Der aktive Zustand muss zusätzlich visuell erkennbar sein (Farbe + optional Icon/Bold).

Mobile Navigation

  • Die Sidebar wird unter 1024px mit display: none versteckt.
  • Die Navigation muss auf Mobile in anderer Form zugänglich sein (Hamburger-Menü, Bottom-Nav etc.).
  • Das versteckte Element darf nicht per Tab fokussiert werden (sichergestellt durch display: none).
