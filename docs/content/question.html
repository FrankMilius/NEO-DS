Question

Marquee-Frage-Sektion mit horizontal scrollendem Text und optionalem Action-Bereich. Der scrollende Text läuft als CSS-Keyframe-Animation und wechselt bei geraden/ungeraden Zeilen die Richtung. Kanonische Klasse: .question. Animations-Geschwindigkeit wird über --px-per-sec gesteuert.

Animiertes Marquee

Die Klasse .question-animate aktiviert die CSS-Keyframe-Animation. Gerade Zeilen laufen nach rechts (marquee), ungerade Zeilen nach links (marquee-reverse).
Die Animationsdauer berechnet sich aus: --marquise-el-width / --px-per-sec * 1s.

/* CSS-Custom-Property-Kalkulation */ .question-text-row { --marquise-time: calc(var(--marquise-el-width) / var(--px-per-sec) * 1s); } /* Gerade Zeilen (nth-of-type(2n)) */ .question-text-row.question-animate:nth-of-type(2n) { animation: marquee var(--marquise-time) linear infinite reverse; } /* Ungerade Zeilen (nth-of-type(odd)) */ .question-text-row.question-animate:nth-of-type(odd) { animation: marquee-reverse var(--marquise-time) linear infinite reverse; }

Action-Bereich: With-Text-Variante

Der Action-Bereich kann einen zusätzlichen Beschreibungstext enthalten. Mit der Modifikator-Klasse .with-text wechselt das Layout auf Flex-Row (ab Tablet-Breakpoint).

Accessibility Referenz

Laufender Text ist für viele Nutzer schwer lesbar. Die Marquee-Sektion muss daher mit besonderer Sorgfalt implementiert werden, um WCAG 2.1 AA einzuhalten.

Bewegter Inhalt (WCAG 2.2.2)

  • Laufender Text, der länger als 5 Sekunden anhält, muss angehalten, gestoppt oder verborgen werden können
  • Nutzer sollten die Animation mit Escape oder einem Pause-Button stoppen können
  • Alternativ: Animation nur auf Hover/Focus aktiv lassen
  • Bei prefers-reduced-motion: reduce muss die Animation deaktiviert werden

Screenreader: aria-hidden

  • Die scrollenden Marquee-Zeilen (.question-text-row) sollten aria-hidden="true" erhalten
  • Der Inhalt der Zeilen ist dekorativ — die eigentliche Botschaft wird durch die Buttons und den Begleittext vermittelt
  • Screenreader lesen sonst jeden wiederholten Loop-Eintrag vor, was sehr verwirrend ist
  • Stattdessen kann ein .u-sr-only-Element den semantischen Inhalt für Screenreader bereitstellen

prefers-reduced-motion

  • Die CSS-Animation muss bei @media (prefers-reduced-motion: reduce) deaktiviert werden
  • Die globale Implementierung in 02-generic/_animations.scss setzt animation-duration: 0.01ms global
  • Dies stoppt alle Marquee-Animationen effektiv für betroffene Nutzer
  • Testen Sie das Verhalten mit deaktivierter Systemanimation

Action-Buttons

  • Alle Buttons im Action-Bereich müssen klare, beschreibende Beschriftungen haben
  • Die column-reverse-Reihenfolge auf Mobile betrifft nur die visuelle Darstellung — die DOM-Reihenfolge bleibt logisch
  • Buttons müssen per Tab erreichbar und mit Enter/Space auslösbar sein
