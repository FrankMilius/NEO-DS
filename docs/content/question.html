Question

Marquee-Frage-Sektion mit horizontal scrollendem Text und optionalem Action-Bereich. Der scrollende Text läuft als CSS-Keyframe-Animation und wechselt bei geraden/ungeraden Zeilen die Richtung. Kanonische Klasse: .question. Animations-Geschwindigkeit wird über --px-per-sec gesteuert.

Animiertes Marquee

Die Klasse .question-animate aktiviert die CSS-Keyframe-Animation. Gerade Zeilen laufen nach rechts (marquee), ungerade Zeilen nach links (marquee-reverse).
Die Animationsdauer berechnet sich aus: --marquise-el-width / --px-per-sec * 1s.

/* CSS-Custom-Property-Kalkulation */ .question-text-row { --marquise-time: calc(var(--marquise-el-width) / var(--px-per-sec) * 1s); } /* Gerade Zeilen (nth-of-type(2n)) */ .question-text-row.question-animate:nth-of-type(2n) { animation: marquee var(--marquise-time) linear infinite reverse; } /* Ungerade Zeilen (nth-of-type(odd)) */ .question-text-row.question-animate:nth-of-type(odd) { animation: marquee-reverse var(--marquise-time) linear infinite reverse; }

Action-Bereich: With-Text-Variante

Der Action-Bereich kann einen zusätzlichen Beschreibungstext enthalten. Mit der Modifikator-Klasse .with-text wechselt das Layout auf Flex-Row (ab Tablet-Breakpoint).

<div class="question-action-section with-text"> <div class="question-paragraphs"> <p>Sprechen Sie mit einem unserer Experten und finden Sie die beste Lösung.</p> </div> <div class="question-buttons"> <button class="button">Demo anfragen</button> <button class="button">Kontakt</button> </div> </div>

DOM-Hinweise

  • Marquee-Lauftext: alternierend links/rechts scrollend (marquee/marquee-reverse).
  • Geschwindigkeit: --px-per-sec (80 mobile, 160 desktop). Icon-Separatoren zwischen Texten.
  • Action-Section: Buttons (.question-buttons > .nc-button: mobil volle Breite, ab Tablet halbe Breite plus Rinne) + Paragraphs. with-text Variante: side-by-side Layout ab Tablet.
