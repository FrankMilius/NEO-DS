Semantische Varianten

          

            

            
              
VarianteRoot-ElementInteraktivARIA

            
            
              
Informational<article>Nein—

              
Nav Entire<a href>Ja (Link)Implizites role="link"

              
Nav Partial<article>Interner Link—

              
Action<article>Buttons im Footer—

              
Selectable (Radio)<label>Ja (Input)Nativ via <input type="radio">

              
Selectable (Checkbox)<label>Ja (Input)Nativ via <input type="checkbox">

              
Expandable<details>Ja (Summary)Nativ via <details>/<summary>

              
Status<article>NeinStatus via Inhalt, nicht nur Farbe

            
          

        


          

            
            

              
Keine verschachtelten interaktiven Elemente

              
    
                
  • Navigational Entire: Root ist <a> — KEINE Buttons, Links oder Inputs innerhalb.
    • 
                
  • Navigational Partial: Root ist <article> — Link nur im Titel, Footer-Buttons erlaubt.
    • 
                
  • Selectable: Root ist <label> — keine weiteren interaktiven Elemente.
    • 
              

            

          


          

            
            

              
Fokus-Management

              
    
                
  • Navigational Entire: :focus-visible auf dem <a>-Root.
    • 
                
  • Selectable: Focus wird via :has(.nc-card__input:focus-visible) auf die Card übertragen.
    • 
                
  • Expandable: :focus-visible auf <summary> mit outline-offset: -2px.
    • 
                
  • Alle interaktiven Varianten nutzen @include focus-ring (themeable).
    • 
              

            

          


          

            
            

              
Tastatur-Unterstützung

              
    
                
  • Tab: Fokussiert interaktive Card-Varianten (Nav, Selectable-Input, Summary, Footer-Buttons).
    • 
                
  • Enter / Space: Aktiviert Link (Nav), togglet Radio/Checkbox (Selectable), öffnet/schließt Details (Expandable).
    • 
                
  • Pfeiltasten: Navigieren zwischen Radio-Cards in einer Gruppe (natives Radio-Verhalten).
    • 
              

            

          


          

            
            

              
Status nicht nur über Farbe

              
    
                
  • Status-Cards nutzen farbigen Border UND beschreibenden Text (Titel + Description).
    • 
                
  • Farbe allein reicht nicht aus (WCAG 1.4.1 — Use of Color).
    • 
                
  • Optional: Badge oder Icon im Header zur zusätzlichen Kennzeichnung.
    •
