Shadow & Elevation

5 Shadow-Stufen und 5 semantische Elevation-Aliases bilden das Tiefensystem. Alle Werte sind Dark-Mode-aware — im dunklen Theme werden Schatten automatisch verstaerkt fuer bessere Sichtbarkeit auf dunklen Hintergruenden.

Shadow Levels

5 abgestufte Schatten von --fnd-shadow-xs bis --fnd-shadow-xl. Jede Stufe erhoht Offset, Blur und Spread progressiv.

--fnd-shadow-xs
Subtiler Schatten fuer Buttons, Thumb-Elemente
0 1px 2px rgba(15, 23, 42, 0.06)
--fnd-shadow-sm
Leichter Schatten fuer Cards, Panels
0 4px 10px rgba(15, 23, 42, 0.08)
--fnd-shadow-md
Mittlerer Schatten fuer Dropdowns, Popovers
0 10px 24px rgba(15, 23, 42, 0.12)
--fnd-shadow-lg
Grosser Schatten fuer Overlays, Drawer
0 18px 40px rgba(15, 23, 42, 0.16)
--fnd-shadow-xl
Maximaler Schatten fuer Modals
0 30px 60px rgba(15, 23, 42, 0.20)

Semantic Elevation

5 semantische Elevation-Stufen mappen auf die Shadow-Levels. Verwende immer die Elevation-Tokens in Komponenten — die Shadow-Levels sind die darunterliegende Implementierung.

Inset Shadows

Fuer vertiefte oder gedrueckte Zustaende (z.B. aktive Inputs, eingedrueckte Buttons). 2 Stufen verfuegbar.

inset-sm
--fnd-shadow-inset-sm
Leichte Vertiefung (Inputs, Toggle-Tracks)
inset 0 1px 2px rgba(15, 23, 42, 0.08)
inset-md
--fnd-shadow-inset-md
Staerkere Vertiefung (Active-Buttons, Well-Container)
inset 0 2px 4px rgba(15, 23, 42, 0.12)

Dark Mode Behaviour

Im Dark Mode werden alle Shadow-Werte automatisch verstaerkt — hoehere Opacity-Werte kompensieren den dunklen Hintergrund. Die Elevation-Tokens aendern sich nicht, nur die darunterliegenden Shadow-Werte.

Light Mode
rgba(15, 23, 42, 0.08)
Dark Mode
rgba(0, 0, 0, 0.28)

SCSS Architecture

Die Shadow-Tokens werden aus design-tokens.json generiert und in _shadow.scss als CSS Custom Properties ausgegeben. 

// Datei: scss/scss/00-settings/_shadow.scss

// Token-Quellen
$shadow-levels: tokens.$token-shadow-levels;     // aus design-tokens.json
$shadow-levels-dark: ( ... );                     // manuell definiert
$shadow-inset: ( ... );                           // manuell definiert

// CSS Custom Properties Output
:root {
  --fnd-shadow-xs: 0 1px 2px rgba(15, 23, 42, 0.06);
  --fnd-shadow-sm: 0 4px 10px rgba(15, 23, 42, 0.08);
  // ...

  --fnd-elevation-base: var(--fnd-shadow-xs);
  --fnd-elevation-raised: var(--fnd-shadow-sm);
  // ...
}

// Dark Theme Override
.neo-dark-theme, .customer-dark-theme {
  --fnd-shadow-xs: 0 1px 2px rgba(0, 0, 0, 0.20);
  // ...
}

// Auto Dark Mode (prefers-color-scheme)
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) {
    --fnd-shadow-xs: 0 1px 2px rgba(0, 0, 0, 0.20);
    // ...
  }
}
