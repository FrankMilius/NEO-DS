Form Label

Token-basiertes Form-Label mit Required/Optional-Indikator, Info-Tooltip-Slot, Typografie-Hierarchie und erweitertem Klickbereich. Kanonische Klasse: .nc-form-label (BEM). Alle Werte kommen aus --nc-form-label-* Component-Tokens. Nicht zu verwechseln mit dem visuellen Pill-Label aus .nc-label.

Verwendung

Das Form-Label beschriftet Formular-Felder und stellt die Verbindung zum Input via for-Attribut her. Es unterstützt Pflichtfeld-Indikatoren, Info-Tooltips und verschiedene Typografie-Hierarchien.

Standard

<label class="nc-form-label" for="name">
  <span class="nc-form-label__text">Name</span>
</label>

Pflichtfeld (Required)

<label class="nc-form-label" for="email">
  <span class="nc-form-label__text">E-Mail</span>
  <span class="nc-form-label__required" aria-hidden="true">*</span>
</label>

Optional

<label class="nc-form-label" for="phone">
  <span class="nc-form-label__text">Telefon</span>
  <span class="nc-form-label__optional">(Optional)</span>
</label>

Mit Info-Tooltip

<label class="nc-form-label" for="iban">
  <span class="nc-form-label__text">IBAN</span>
  <button class="nc-form-label__info" type="button" aria-label="Hilfe zu IBAN">
    <svg viewBox="0 0 24 24"><circle cx="12" cy="12" r="10"/><line x1="12" y1="16" x2="12" y2="12"/><line x1="12" y1="8" x2="12.01" y2="8"/></svg>
  </button>
</label>

Typografie-Hierarchie

SM (kompakt), MD (Standard), Emphasis (hervorgehoben für Section-Labels).

<label class="nc-form-label nc-form-label--sm">...</label>
<label class="nc-form-label">...</label>  <!-- MD (Default) -->
<label class="nc-form-label nc-form-label--emphasis">...</label>

Inline (neben Input)

<label class="nc-form-label nc-form-label--inline" for="city">
  <span class="nc-form-label__text">Stadt</span>
</label>

Disabled

<label class="nc-form-label nc-form-label--disabled" for="locked">
  <span class="nc-form-label__text">Gesperrt</span>
</label>

DOM-Hinweise

  • Semantisch ein <label for="input-id"> Element.
  • Flexbox-Layout: Text + Indicator + Info-Icon inline, align-items: baseline.
  • Required-Sternchen: aria-hidden="true" — Screen Reader liest aria-required am Input.
  • Info-Icon: <button> mit aria-label, fokussierbar via Tab.
  • Klickbereich: padding-block + min-height vergrößern den Touch-Target (WCAG 2.5.8).
  • Im .nc-form-field Wrapper wird margin-bottom: 0 gesetzt (gap übernimmt).

Accessibility Referenz

<label for="input-id"> verknüpft Label mit Input. Klick auf Label fokussiert den Input. Klickbereich erfüllt WCAG 2.5.8 Target Size (24x24 Minimum).

Farbkontrast: WCAG AA normal text (4.5:1)

  • Primary-Text Farbe muss 4.5:1 Kontrast gegen den Hintergrund haben.

Pflicht: label[for]

  • Pflicht: Label muss via for-Attribut mit dem Input verknüpft sein.

Wenn: Required-Indikator

  • Pflicht: Sternchen ‘*’ muss aria-hidden="true" haben.
  • Pflichtfeld-Semantik liegt auf dem Input (aria-required="true").

Wenn: Info-Tooltip

  • Pflicht: Info-Button braucht aria-label="Hilfe zu {Feldname}".
  • Tooltip-Inhalt via aria-describedby oder role="tooltip" verknüpft.
