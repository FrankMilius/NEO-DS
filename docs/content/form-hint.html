Form Hint

Token-basierter Help/Hint-Text für Formular-Felder. Unterstützt Text-only, Icon, Inline-Link und Anforderungslisten. Kanonische Klasse: .nc-form-hint (BEM). Alle Werte kommen aus --nc-form-hint-* Component-Tokens.

Verwendung

Der Form-Hint liefert zusätzliche Hilfestellung unterhalb (oder oberhalb) eines Input-Feldes. Er wird via aria-describedby mit dem zugehörigen Input verknüpft.

  <span class="nc-form-hint__text">Wir senden Ihnen eine Bestätigung an diese Adresse.</span>
</span>

DOM-Hinweise

  • Flexbox-Layout: Icon + Text nebeneinander, align-items: flex-start.
  • Wird via aria-describedby am zugehörigen Input verknüpft (id="hint-{name}").
  • Kann vor oder nach dem Input im .nc-form-field Wrapper platziert werden.
  • Link-Slot: Inline-Anchor mit :focus-visible und focus-ring.
  • List-Support: .nc-form-hint__text kann eine <ul class="nc-form-hint__list"> enthalten.

Accessibility Referenz

Hint-Text wird via aria-describedby am Input referenziert (id="hint-{name}"). Rein informativ, kein role nötig. Icon ist dekorativ (aria-hidden="true").

Farbkontrast: WCAG AA normal text (4.5:1)

  • Sekundäre Textfarbe muss 4.5:1 Kontrast gegen den Hintergrund haben.
  • Muted-Variante (tertiäre Farbe) muss trotz reduzierter Prominenz 4.5:1 einhalten.

Pflicht: aria-describedby

  • Pflicht: Hint muss via aria-describedby mit dem zugehörigen Input verknüpft sein.

Wenn: Link im Hint

  • Pflicht: Links müssen :focus-visible mit focus-ring haben.
  • Link-Farbe (interactive-default) muss 4.5:1 Kontrast gegen den Hintergrund erfüllen.

Wenn: Anforderungsliste

  • Listen müssen als semantische <ul> mit <li> strukturiert sein.
  • Keine visuellen Pseudo-Listen mit Bullet-Zeichen im Text.
