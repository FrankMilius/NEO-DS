Slider

Range-Slider mit Custom Track und Thumb. Unterstützt Single-Value und optionalen Wert-Output. Kanonische Klasse: .nc-slider (BEM). Alle Werte kommen aus --nc-slider-* Component-Tokens.

Accessibility Referenz

Der Slider nutzt das native <input type="range">-Element und erbt dadurch alle nativen Accessibility-Features.

Natives Range-Input

  • Verwendet <input type="range"> — kein Custom-ARIA nötig
  • Tastatur-Navigation ist nativ: Pfeiltasten ändern den Wert
  • Fokus-Styling wird über :focus-visible auf dem Input gesetzt
  • Das Label sollte über ein <label>-Element oder aria-label zugewiesen werden

ARIA-Attribute

  • aria-valuemin — wird automatisch aus min-Attribut abgeleitet
  • aria-valuemax — wird automatisch aus max-Attribut abgeleitet
  • aria-valuenow — wird automatisch aus value-Attribut abgeleitet
  • aria-valuetext — optional, für zusätzliche Beschreibung des Werts (z.B. “50 Prozent”)
  • Bei deaktiviertem Slider: disabled-Attribut auf dem Input setzen (nicht nur CSS-Klasse)

Tastatur-Bedienung

  • Tab — Fokussiert den Slider
  • Pfeil rechts / Pfeil oben — Erhöht den Wert um einen Schritt
  • Pfeil links / Pfeil unten — Verringert den Wert um einen Schritt
  • Home — Setzt auf Minimum
  • End — Setzt auf Maximum
  • Page Up / Page Down — Ändert den Wert in größeren Schritten
