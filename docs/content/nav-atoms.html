Navigation

Atoms und Molecules für die globale Navigation: Links, Icons, Labels, Toggles, Suchpanel, Submenu, Mobile-Panel und Sprachtoggle. Kanonische Klassen: .nc-nav__* (Atoms), .nc-search-*, .nc-submenu__*, .nc-mobile-*, .nc-lang-toggle__* (Molecules). Quelldateien: scss/05-atoms/_nav-atoms.scss und scss/06-molecules/_nav-molecules.scss.

Nav Atoms: Icon & Label

Basis-Atome für Navigation. .nc-nav__icon ist ein 24×24 px Icon-Wrapper, .nc-nav__label ein Block-Element für Navigationstext. Beide erben font-size und font-weight vom Elternelement.

Startseite Suche 
<span class="nc-nav__icon">
  <svg aria-hidden="true">...</svg>
</span>
<span class="nc-nav__label">Startseite</span>

Nav Link — .nc-nav__link

Kombiniertes Link-Molecule: inline-flex mit Icon und Label in einer Zeile. Gap von 0.4rem zwischen Icon und Text. Erbt Schriftgröße und Gewicht.

Startseite 
<a class="nc-nav__link" href="/">
  <span class="nc-nav__icon">
    <svg aria-hidden="true">...</svg>
  </span>
  <span class="nc-nav__label">Startseite</span>
</a>

Nav Toggle — .nc-nav__toggle

Button-Reset mit background: transparent, border: none. Wird als Toggle für Dropdown-Navis genutzt. Kombinierbar mit .nc-nav__link. 

<button class="nc-nav__toggle nc-nav__link"
        aria-expanded="false" aria-haspopup="true">
  <span class="nc-nav__label">Produkte</span>
  <svg aria-hidden="true"><!-- Pfeil-Icon --></svg>
</button>

Submenu — .nc-submenu

Grid-basiertes Submenu-Layout. Jedes Item besteht aus einem Link mit optionaler Beschreibung. Wird typischerweise in einem Dropdown-Panel angezeigt.

      Design System

    </a>

</ul>

Mobile Navigation — .nc-mobile-*

Hamburger-Toggle (.nc-mobile-toggle) und aufklappbares Mobile-Panel (.nc-mobile-panel). Das Panel wird durch die Klasse .is-mobile-open auf .nc-header angezeigt. 

<!-- Hamburger Toggle -->
<button class="nc-mobile-toggle"
        aria-label="Menü öffnen"
        aria-expanded="false"
        aria-controls="mobile-panel">
  <span class="nc-mobile-toggle__icon" aria-hidden="true"></span>
  <span class="nc-nav__label">Menü</span>
</button>

<!-- Mobile Panel -->
<div class="nc-mobile-panel" id="mobile-panel">
  <div class="nc-mobile-panel__inner">
    <nav class="nc-mobile-links">
      <button class="nc-mobile-toggle-link">
        Produkte
        <svg aria-hidden="true">...</svg>
      </button>
      <div class="nc-mobile-submenu">
        <a class="nc-mobile-submenu__link" href="#">Unterseite</a>
      </div>
    </nav>
  </div>
</div>

Sprachtoggle — .nc-lang-toggle

Kompakter Sprachtoggle mit Label und Buttons. 48px Höhe (wie andere Tool-Buttons). Aktive Sprache erhält .is-active mit inversem Hintergrund.

  <span class="nc-lang-toggle__label">Sprache</span>
  <button class="nc-lang-toggle__button is-active" aria-pressed="true">DE</button>
  <button class="nc-lang-toggle__button" aria-pressed="false">EN</button>
</div>

Accessibility Referenz

Navigation ist eine der kritischsten Komponenten für Barrierefreiheit. Die folgenden WCAG-Kriterien sind besonders relevant.

ARIA Landmarks & Rollen (WCAG 1.3.1, 4.1.2)

  • Hauptnavigation in <nav aria-label="Hauptnavigation"> einschließen
  • Suche in <search> oder <div role="search"> einschließen
  • Mobile-Panel: aria-hidden="true" wenn geschlossen, aria-hidden="false" wenn geöffnet
  • Mehrere <nav>-Elemente müssen via aria-label unterschieden werden

Dropdown-Toggles (WCAG 4.1.2)

  • .nc-nav__toggle: aria-expanded="false" im geschlossenen, aria-expanded="true" im offenen Zustand
  • aria-haspopup="true" oder aria-haspopup="menu" signalisiert das Vorhandensein eines Submenus
  • aria-controls auf den Toggle zeigt auf die ID des Submenu-Containers
  • Escape-Taste schließt das Dropdown und gibt Fokus an den Toggle zurück

Mobile Navigation (WCAG 2.4.3)

  • Hamburger-Button: aria-expanded korrekt toggeln, aria-controls auf Panel-ID
  • Beim Öffnen des Mobile-Panels: Fokus auf das erste Element im Panel verschieben
  • Beim Schließen: Fokus auf Hamburger-Button zurückgeben
  • Mobile-Panel-Icon (.nc-mobile-toggle__icon) via CSS erzeugt — aria-hidden="true" setzen

Suche (WCAG 1.3.5, 4.1.2)

  • Sucheingabe: type="search", autocomplete="off" oder passender Wert, aria-label="Suchen"
  • Suchergebnisse: role="listbox" oder role="list", Anzahl via aria-live="polite" ankündigen
  • Close-Button: aria-label="Suche schließen" (kein sichtbarer Text vorhanden)
  • Leere Ergebnisliste (.nc-search__empty): Text muss für Screenreader verfügbar sein

Sprachtoggle (WCAG 3.1.1)

  • aria-pressed="true" auf der aktiven Sprach-Schaltfläche
  • aria-pressed="false" auf inaktiven Schaltflächen
  • Label der Buttons sollte vollständigen Sprachnamen enthalten: aria-label="Deutsch" statt nur “DE”
  • Den Sprachtoggle-Container mit aria-label="Sprachauswahl" versehen
