Drawer

Slide-in Panel basierend auf dem nativen <dialog>-Element. Unterstützt vier Richtungen (bottom, top, left, right) mit Handle, Header, scrollbarem Content und Footer. Kanonische Klasse: .nc-drawer (BEM). Verwendet --nc-drawer-* Component-Tokens. Inspiriert von shadcn Drawer / Vaul.

Live Demo

Wähle Richtung und Theme, um den Drawer live zu konfigurieren und zu öffnen.

Bottom Drawer (Default)

Standard-Drawer, der von unten einslided. Enthält Handle, Header, scrollbaren Content und Footer.

<dialog class="nc-drawer" aria-labelledby="d-title" aria-describedby="d-desc"> <div class="nc-drawer__handle"></div> <div class="nc-drawer__header"> <h2 class="nc-drawer__title" id="d-title">Einstellungen</h2> <p class="nc-drawer__description" id="d-desc">Passen Sie Ihre Präferenzen an.</p> </div> <div class="nc-drawer__content">...</div> <div class="nc-drawer__footer"> <button class="nc-button">Speichern</button> <button class="nc-button nc-button--outline">Abbrechen</button> </div> </dialog>

Top Drawer

Drawer, der von oben einslided. Ideal für Benachrichtigungen oder Suchleisten.

Right Drawer

Seitlicher Drawer von rechts. Ideal für Detail-Panels, Warenkörbe oder Einstellungen. Zeigt Close-Button statt Handle.

Left Drawer

Seitlicher Drawer von links. Ideal für Navigation oder Seitenmenüs. Zeigt Close-Button statt Handle.

JavaScript API

Die native <dialog>-API zum Öffnen, Schließen und Event-Handling.

// Öffnen (modal mit Backdrop + Focus-Trap) const drawer = document.querySelector('.nc-drawer'); drawer.showModal(); // Schließen drawer.close(); // Backdrop-Click schließt den Drawer drawer.addEventListener('click', (e) => { if (e.target === drawer) drawer.close(); }); // Event: Drawer wurde geschlossen drawer.addEventListener('close', () => { console.log('Drawer geschlossen'); }); // Event: ESC gedrückt drawer.addEventListener('cancel', (e) => { // Optional: e.preventDefault() um ESC zu blockieren });

DOM-Hinweise

  • Natives <dialog> mit showModal(). Slide-in von 4 Richtungen mit Spring-Animation.
  • Modifiers: --top, --right, --left (default: bottom).
  • Handle: 32×4px abgerundeter Balken, aria-hidden='true'. Nur bei bottom/top sichtbar. Signalisiert Swipe-to-Dismiss.
  • Content: scrollbar. Header und Footer bleiben sticky bei langen Listen.
  • Header Scroll-Border: JS setzt .is-scrolled Klasse bei gescrolltem Content — Header bekommt subtile Trennlinie.
  • Footer Scroll-Border: Gleiche Logik — Footer bekommt obere Trennlinie bei gescrolltem Content.
  • Light Dismiss: Klick auf ::backdrop schliesst Drawer. JS: dialog.addEventListener('click', e => { if (e.target === dialog) dialog.close() }).
  • Close-Button: Sichtbar auf allen Richtungen (v2.0: nicht mehr nur bei left/right). Absolut positioniert oben-rechts.
  • Mobile Prioritaet: Bottom-Sheet (direction=bottom) ist die bevorzugte Overlay-Variante fuer Touch-Geraete (Daumenzone).
  • Elevation: elevation-modal (L3) — gleiche Schattenstufe wie Modal. Ueberlagert gesamte Anwendungsebene.
  • Spring Animation: cubic-bezier(0.175, 0.885, 0.32, 1.275) fuer physisch-reaktionsschnelles Slide-in.
  • Body Scroll Lock: body:has(.nc-drawer[open]) { overflow: hidden }.
  • Side-Width: 380px (mobile) → 440px (tablet) → 500px (desktop) — responsive Breakpoints.

Accessibility Referenz

Natives <dialog>: role=dialog, aria-modal=true, Fokus-Trap, ESC-Close. aria-labelledby → Title, aria-describedby → Description. Light Dismiss: Klick auf Backdrop schliesst Drawer.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: Spezialbedingung

  • Empfohlen: swipe-to-dismiss
  • Bottom/Top Drawers: Handle signalisiert Swipe-to-Dismiss. JS: Touch-Geste erkennen und Drawer schliessen.
