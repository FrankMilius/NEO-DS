Schicht 1: Primitives

Rohe Farbpaletten mit 100–950 Shade-Skala. Stufe 500 ist die Basisfarbe. Hellere Stufen (100–400) werden mit Weiß gemischt, dunklere (600–950) mit Schwarz. Alle Paletten werden algorithmisch generiert.

Schicht 2: Semantic Tokens

Semantische Tokens binden Primitives an Bedeutungen. Sie wechseln automatisch beim Theme-Switch. Alte Token-Namen (z.B. text-high) werden per Compat-Layer auf die neuen (z.B. text-primary) gemappt.

Backward Compatibility

Alle bisherigen Token-Namen funktionieren weiterhin. Sie werden über einen Alias-Layer auf die neuen semantischen Tokens gemappt. Die alten Namen sind als @deprecated markiert.

text-mid→text-secondary
text-low→text-tertiary
text-state-disabled→text-disabled
border-high→border-strong

Customer Theming

Kunden können die Brand-Farben (Primary, Secondary, Accent) durch eigene Hex-Werte ersetzen. Die Shade-Skalen werden automatisch neu generiert.

/* In einer Customer-spezifischen Datei: */ $brand-source: 'customer'; $customer-primary-base: #e63946; /* Eigene Markenfarbe */ $customer-secondary-base: #1d3557; $customer-accent-base: #a8dadc; @use '00-settings'; /* → Alle Paletten werden automatisch neu generiert */ /* → Semantische Tokens referenzieren die neuen Primitives */
