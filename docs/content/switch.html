Switch

Toggle-Switch (An/Aus) mit Track und Thumb. Unterstützt button[role='switch'] und input[type='checkbox'] Pattern. Kanonische Klasse: .nc-switch (BEM). Alle Werte kommen aus --nc-switch-* Component-Tokens.

HTML-Struktur: Button Pattern

Bevorzugtes Pattern mit <button role="switch">. Zustand wird über aria-checked gesteuert.

<!-- Switch Off --> <div class="nc-switch [--sm]"> <button class="nc-switch__track" role="switch" aria-checked="false" aria-label="Benachrichtigungen"> <span class="nc-switch__thumb"></span> </button> <span class="nc-switch__label">Benachrichtigungen</span> </div> <!-- Switch On --> <div class="nc-switch"> <button class="nc-switch__track" role="switch" aria-checked="true" aria-label="Benachrichtigungen"> <span class="nc-switch__thumb"></span> </button> <span class="nc-switch__label">Benachrichtigungen</span> </div> <!-- Switch Disabled --> <div class="nc-switch"> <button class="nc-switch__track" role="switch" aria-checked="false" disabled> <span class="nc-switch__thumb"></span> </button> <span class="nc-switch__label">Deaktiviert</span> </div>

HTML-Struktur: Input Pattern

Alternatives Pattern mit nativem <input type="checkbox">. Der Input wird per sr-only versteckt, :checked steuert den Zustand.

<!-- Switch mit Checkbox-Input --> <label class="nc-switch [--sm]"> <input type="checkbox" class="nc-switch__input" role="switch" /> <span class="nc-switch__track"> <span class="nc-switch__thumb"></span> </span> <span class="nc-switch__label">Dark Mode</span> </label> <!-- Switch Checked --> <label class="nc-switch"> <input type="checkbox" class="nc-switch__input" role="switch" checked /> <span class="nc-switch__track"> <span class="nc-switch__thumb"></span> </span> <span class="nc-switch__label">Dark Mode</span> </label> <!-- Switch Disabled --> <label class="nc-switch"> <input type="checkbox" class="nc-switch__input" role="switch" disabled /> <span class="nc-switch__track"> <span class="nc-switch__thumb"></span> </span> <span class="nc-switch__label">Deaktiviert</span> </label>

Accessibility Referenz

Der Switch nutzt role="switch" und muss die WCAG 2.1 AA-Kriterien erfüllen.

role="switch"

  • Sowohl das Button- als auch das Input-Pattern verwenden role="switch"
  • Screen Reader erkennen den Switch als Toggle-Element
  • Der Zustand wird als “an” oder “aus” angesagt
  • Ohne role="switch" wird nur “Button” oder “Checkbox” angesagt

aria-checked

  • Beim Button-Pattern: aria-checked="true" oder aria-checked="false"
  • Muss per JavaScript bei Klick umgeschaltet werden
  • Beim Input-Pattern: das native checked-Attribut reicht aus
  • Der CSS-Zustand (Thumb-Position) leitet sich aus aria-checked bzw. :checked ab

Tastatur-Navigation (Space)

  • Tab fokussiert den Switch
  • Space schaltet den Switch um (an/aus)
  • Beim Button-Pattern: Enter schaltet ebenfalls um (natives Button-Verhalten)
  • Beim Input-Pattern: nur Space (natives Checkbox-Verhalten)
  • :focus-visible zeigt den Focus-Ring auf dem Track

Touch Target (WCAG 2.5.8)

  • Der Touch-Bereich muss mindestens 44x44px betragen
  • Das Label erweitert den klickbaren Bereich
  • Bei --sm auf ausreichende Touch-Größe achten

Best Practices
