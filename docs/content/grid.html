Grid Foundation

12-Column Grid auf einem 4px-Basegrid. Fluid, responsiv mit 6 Breakpoints. Alle Abstands- und Layoutwerte sind Vielfache von --fnd-base-unit: 4px.

Columns & Rows

12 gleichbreite Spalten bilden das Grundraster. Jede Spalte kann mit .o-col-{n} aufgespannt werden. Spalten verhalten sich fluid — ihre Breite passt sich automatisch dem Viewport an.

Margins

Container-Margins definieren den Abstand zwischen Seitenrand und Inhalt. Der container-padding Mixin steuert dies responsive — ab xxl (1920px) wird stattdessen eine feste max-width verwendet.

Inhalt innerhalb des Containers
Der grüne Bereich zeigt den Margin (Container-Padding)
Breakpoint Viewport Container-Padding Token

lg 1200px + 40px --fnd-spacing-08

/* SCSS Mixin */ @include container-padding; /* Erzeugt: */ margin-inline: auto; padding-inline: var(--fnd-spacing-04); /* xs */ @media (min-width: 768px) { padding-inline: var(--fnd-spacing-06); } /* sm */ @media (min-width: 960px) { padding-inline: var(--fnd-spacing-07); } /* md */ @media (min-width: 1200px) { padding-inline: var(--fnd-spacing-08); } /* lg */ @media (min-width: 1600px) { padding-inline: var(--fnd-spacing-09); } /* xl */ @media (min-width: 1920px) { padding-inline: 0; max-width: 1472px; } /* xxl */

Padding

Internes Padding von Komponenten nutzt die Spacing-Scale auf dem 4px-Grid. Utility-Klassen wie .u-p-06 oder .u-px-04 setzen das Padding direkt.

Inhalt mit padding: spacing-08 (40px)
Der grüne Bereich zeigt das Padding
Inhalt mit padding: spacing-04 (16px)
Inhalt mit padding: spacing-02 spacing-06 (8px 24px)
/* Utility-Klassen */ .u-p-04 { padding: var(--fnd-spacing-04); } /* 16px */ .u-px-06 { padding-inline: var(--fnd-spacing-06); } /* 24px */ .u-py-08 { padding-block: var(--fnd-spacing-08); } /* 40px */ /* Responsive Padding */ .u-p-04 .u-p-lg-08 → 16px auf Mobile, 40px ab 1200px

Gutters

Gutters sind die Zwischenräume zwischen den Grid-Spalten. Sie werden durch --grid-gap gesteuert und passen sich am Breakpoint lg (1200px) an.

Breakpoints

6 Breakpoints folgen einem mobile-first Ansatz. xs ist der Default ohne Media Query. Resize das Browserfenster, um den aktiven Breakpoint zu sehen.

xs: 0 sm: 768px md: 960px lg: 1200px xl: 1600px xxl: 1920px
Name Min-Width SCSS-Mixin Grid-Klasse Typischer Kontext
xs 0 @include mobile-only .o-col-{n} Smartphones (Portrait)
sm 768px @include tablet-up .o-col-sm-{n} Tablets, kleine Laptops
md 960px @include respond-to('md') — Tablets (Landscape)
lg 1200px @include desktop-up .o-col-lg-{n} Desktops, Laptops
xl 1600px @include large-desktop — Große Monitore
xxl 1920px @include full-desktop — Full-HD+ Monitore
