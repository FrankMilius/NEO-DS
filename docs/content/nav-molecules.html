DOM-Hinweise

  • Nav-Link: inline-flex, gap, padding, radius — Hover: BG-Wechsel + Textfarbe. Active: border-bottom accent.
  • Shared Interaction: Hover-BG und Active-Underline werden von navigation-menu__trigger wiederverwendet.
  • Mobile Toggle: Hamburger-Icon (3 Balken via box-shadow). Steuert .nc-mobile-panel Sichtbarkeit.
  • Mobile Panel: Vertikal gestapelte Links. Sichtbar via .nc-header.is-mobile-open.
  • Lang Toggle: Segmented Control fuer Sprachen. Active via .is-active (inverse colors).
  • Search Panel: Full-Width Overlay — Search-Component (06-molecules/_search.scss) nutzen fuer fortgeschrittene Suche.

Accessibility Referenz

Nav-Links: Keyboard-navigierbar via Tab. Active: aria-current='page'. Toggle: aria-expanded. Focus-Ring auf allen interaktiven Elementen.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: element = toggle

  • Empfohlen: aria-expanded
  • Empfohlen: aria-controls
  • Mobile Toggle: aria-expanded='true|false', aria-controls='mobile-panel-id'.
