Tabs

Horizontale und vertikale Tabs mit Line- und Contained-Variante, drei Größenstufen und Icon-Support. Inspiriert von Carbon Design System Tabs und shadcn Tabs. Kanonische Klasse: .nc-tabs (BEM). Verwendet --nc-tabs-* Component-Tokens.

Line Tabs (Default)

            

              Horizontale Tabs mit Underline-Indikator. Der aktive Tab wird durch eine farbige Unterstreichung hervorgehoben.
            

            

          


          
          

            
Contained Tabs

            

              Tabs mit gefülltem Hintergrund. Der aktive Tab bekommt einen erhöhten Hintergrund mit Shadow — ähnlich dem Segmented Control.
            

            

          


          
          

            
Vertikale Tabs (Line)

            

              Tabs in vertikaler Ausrichtung mit seitlichem Underline-Indikator. Die Tab-Leiste wird als Sidebar dargestellt.
            

            

          


          
          

            
Vertikale Contained Tabs

            

              Vertikale Tabs mit Contained-Variante. Aktiver Tab mit erhöhtem Hintergrund.
            

            

          


          
          

            
Tabs mit Icons

            

              Tabs mit Icon + Text-Kombination. Icons stammen aus dem Icon-Set und werden inline als SVG eingebettet.
            

            

          


          
          

            
Icon-only Tabs

            

              Tabs nur mit Icon — ohne sichtbaren Text. Jeder Tab benötigt ein aria-label für Barrierefreiheit.
            

            

          


          
          

            
Icon-only mit Tooltip

            

              Icon-only Tabs mit Tooltip beim Hovern. Das Label wird als Tooltip angezeigt, sodass der Nutzer die Bedeutung
              jedes Icons erkennen kann. Verwendet die bestehende .nc-tooltip-Komponente
              als Wrapper um jeden Tab-Trigger. Funktioniert horizontal und vertikal.
            

            

          


          
          

            
Scrollable Overflow

            

              Wenn die Anzahl der Tabs die Breite des Containers überschreitet, erscheinen links und rechts
              Scroll-Buttons (Chevrons). Per Klick wird die Tab-Liste um einen Schritt gescrollt.
              Die Buttons werden automatisch deaktiviert, wenn der Anfang bzw. das Ende erreicht ist.
              Nur für horizontale Orientierung.

Component Overview

          

            .nc-tabs ist eine rein CSS-basierte Tab-Komponente. Tab-Wechsel, Keyboard-Navigation und Panel-Sichtbarkeit werden per JavaScript gesteuert.

JavaScript API

          
// Tab-Wechsel per JavaScript
const tabs = document.querySelector('.nc-tabs');
const triggers = tabs.querySelectorAll('.nc-tabs__trigger');
const panels = tabs.querySelectorAll('.nc-tabs__panel');

function activateTab(trigger) {
  // Alle Tabs deaktivieren
  triggers.forEach(t => {
    t.setAttribute('aria-selected', 'false');
    t.setAttribute('tabindex', '-1');
  });
  panels.forEach(p => p.classList.remove('is-active'));

  // Ziel-Tab aktivieren
  trigger.setAttribute('aria-selected', 'true');
  trigger.setAttribute('tabindex', '0');
  trigger.focus();

  const panelId = trigger.getAttribute('aria-controls');
  document.getElementById(panelId)?.classList.add('is-active');
}

            Die Tabs-Komponente implementiert das WAI-ARIA Tabs-Pattern für vollständige Barrierefreiheit.

Focus Management

          

            Die Tabs verwenden das Roving Tabindex-Pattern: Nur der aktive Tab hat tabindex="0",
            alle anderen haben tabindex="-1". Arrow-Keys verschieben den Fokus und aktivieren gleichzeitig den Tab.
          


          
          
Icon-only Tabs

          

            Icon-only Tabs müssen ein aria-label besitzen, das den Tab-Inhalt beschreibt.
            Der visuelle Text wird per sr-only-Pattern versteckt, bleibt aber für Screenreader zugänglich.
          


          
          
Icon-only mit Tooltip

          

            Bei der Tooltip-Variante wird jeder Tab-Trigger in einen .nc-tooltip-Wrapper eingebettet.
            Der Tooltip erscheint automatisch bei :hover und :focus-within (CSS-only).
            Zusätzlich wird aria-describedby auf dem Trigger gesetzt, das auf die Tooltip-ID zeigt.
            So erhält auch der Screenreader den Tooltip-Text.
          


          
          
Scrollable Overflow

          

            Scroll-Buttons haben tabindex="-1" und sind nicht per Tastatur fokussierbar.
            Stattdessen werden Tabs über die Arrow-Keys navigiert, und der aktive Tab wird automatisch in den sichtbaren Bereich gescrollt.
            Scroll-Buttons haben aria-label für Screenreader-Nutzer.
            Buttons werden automatisch disabled, wenn der Rand erreicht ist.
          


          
          
Best Practices

          
    
            
  • Immer aria-label auf dem role="tablist"-Element setzen
    • 
            
  • Für vertikale Tabs aria-orientation="vertical" verwenden
    • 
            
  • Icon-only Tabs benötigen aria-label
    • 
            
  • Icon-only Tabs mit Tooltip: aria-describedby auf den Tooltip setzen
    • 
            
  • Scrollable Tabs: Scroll-Buttons mit aria-label und tabindex="-1"
    • 
            
  • Maximal 6–8 Tabs pro Tablist verwenden (oder Scrollable für mehr)
    • 
            
  • Tab-Labels kurz und beschreibend halten
    • 
            
  • Deaktivierte Tabs mit disabled oder aria-disabled="true" markieren
