Fluid Spacing

13-stufige Spacing-Scale auf dem 4px-Basegrid. Stufen 01–05 sind statisch, Stufen 06–13 skalieren fluid mit clamp() zwischen 320px und 1400px Viewport-Breite.

4px Base Unit

Alle Spacing-Werte sind Vielfache von --fnd-base-unit: 4px. Dies sorgt für ein konsistentes vertikales und horizontales Raster in der gesamten Anwendung. Die kleinste Einheit ist 4px (1×), die grösste 160px (40×).

4 blaue Quadrate = 16px (spacing-04) — 8 Quadrate = 32px (spacing-07)

/* CSS Custom Property */ --fnd-base-unit: 4px; /* SCSS Variable + Funktion */ $base-unit: 4px; snap-to-grid(17px) → 16px /* Rundet auf nächstes 4px-Vielfaches */ snap-to-grid(22px) → 24px

Semantische Tokens

Statt numerische Tokens direkt zu nutzen, erlauben semantische Tokens eine kontextbezogene Verwendung. So bleibt die Bedeutung erhalten, auch wenn sich die konkreten Werte ändern.

Abstände im Bauteil — keine Utility-Klassen

Das Design System hat keine Abstands-Utilities (mehr). Klassen wie .u-mb-04 oder .u-gap-04 wurden am 09.10.2026 entfernt: Sie hatten keinen Verwender, machten aber rund 44 KB des Stylesheets aus. Abstände werden dort festgelegt, wo sie hingehören — im SCSS des Bauteils, über die Spacing-Tokens.

Aufgabe Heutiger Weg Warum
Innenabstand eines Bauteils padding: var(--fnd-spacing-04) im Bauteil-SCSS Der Abstand ist Teil des Bauteils und wandert mit ihm in jedes Template.
Abstand zwischen Geschwistern gap: var(--fnd-spacing-06) am Flex-/Grid-Elternteil Kein Margin am Kind, keine Sonderregel für das letzte Element.
Abstand zwischen Sektionen --fnd-spacing-section bzw. die Sektions-Bauteile Fluid über clamp(), einheitlich auf allen Seiten.
Anderer Abstand ab einem Breakpoint @include respond-to(lg) im Bauteil Eine Stelle pro Bauteil statt Klassenketten im Markup.
Horizontal zentrieren margin-inline: auto bzw. Content-Width-Bauteile Teil des Layout-Bauteils, nicht des Inhalts.
// Bauteil-SCSS: Abstaende ueber Tokens .my-teaser { display: flex; flex-direction: column; gap: var(--fnd-spacing-04); // 16px zwischen den Kindern padding: var(--fnd-spacing-04); // 16px innen (Mobile) @include respond-to(lg) { padding: var(--fnd-spacing-08); // 32–40px ab 1200px } } // Markup bleibt frei von Abstandsklassen <article class="my-teaser">...</article>

Fluid Mechanik

Die fluid-Funktion interpoliert linear zwischen zwei Werten basierend auf der Viewport-Breite. Unter 320px wird der Minimalwert fixiert, über 1400px der Maximalwert.

320px
Viewport Min
1400px
Viewport Max
/* Formel */ clamp(MIN, INTERCEPT + SLOPE * 1vw, MAX) /* Beispiel: spacing-10 (48px → 64px) */ slope = (64 - 48) / (1400 - 320) = 0.0148 intercept = 48 - 0.0148 * 320 = 43.26px → clamp(48px, 43.26px + 1.48vw, 64px) /* SCSS */ @function fluid-spacing($min, $max) { /* Berechnet slope und intercept automatisch */ @return clamp(#{$min}, #{$intercept} + #{$slope} * 1vw, #{$max}); }
