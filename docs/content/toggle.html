Toggle

Toggle Buttons und Toggle Groups für Single-Select und Multi-Select Interaktionen. Einzelner Toggle Button via .nc-button--toggle (BEM, aria-pressed). Toggle Group via .nc-toggle-group (BEM) mit .nc-toggle-group__item Items. Alle Werte kommen aus --nc-toggle-group-* Component-Tokens.

Single Toggle Button

Ein einzelner Toggle Button basiert auf .nc-button--toggle (Outline-Basis) und schaltet via aria-pressed zwischen aktiv und inaktiv.

<button class="nc-button nc-button--toggle" aria-pressed="false"> Toggle Label </button> <button class="nc-button nc-button--toggle" aria-pressed="true"> Toggle Label (Aktiv) </button>

Toggle Group — Single-Select

Radiogroup-Pattern: role="radiogroup" auf dem Container, role="radio" + aria-checked auf den Items. Nur ein Item kann gleichzeitig selektiert sein. Arrow-Key-Navigation (Roving Tabindex).

<div class="nc-toggle-group" role="radiogroup" aria-label="Ansicht"> <button class="nc-toggle-group__item" role="radio" aria-checked="true" tabindex="0">Tag</button> <button class="nc-toggle-group__item" role="radio" aria-checked="false" tabindex="-1">Woche</button> <button class="nc-toggle-group__item" role="radio" aria-checked="false" tabindex="-1">Monat</button> </div>

Toggle Group — Multi-Select

Group-Pattern: role="group" auf dem Container, aria-pressed auf den Items. Mehrere Items können gleichzeitig aktiv sein. Tab-Navigation.

<div class="nc-toggle-group" role="group" aria-label="Textformat"> <button class="nc-toggle-group__item" aria-pressed="true">Fett</button> <button class="nc-toggle-group__item" aria-pressed="false">Kursiv</button> <button class="nc-toggle-group__item" aria-pressed="false">Unterstrichen</button> </div>

Größen

3 Größenstufen: SM (32px), MD (40px, Default), LG (48px). Größen-Modifier auf dem Container: .nc-toggle-group--sm / .nc-toggle-group--lg.

Toggle Button Token-Referenz

Der einzelne Toggle Button (.nc-button--toggle) nutzt die existierenden --nc-button-* Tokens. Basis ist die Outline-Variante. Im Zustand aria-pressed="true" wird der Primary-Hintergrund (--nc-button-primary-bg) angewendet.

Accessibility Referenz

Toggle-Komponenten müssen die WCAG 2.1 AA-Kriterien erfüllen. Die ARIA-Patterns unterscheiden sich für Single-Select und Multi-Select.

R3: Multi-Select — aria-pressed

  • Multi-Select Toggle Groups verwenden role="group" auf dem Container
  • Jedes Item erhält aria-pressed="true" oder "false"
  • Mehrere Items können gleichzeitig aktiv sein
  • Navigation via Tab-Taste zwischen den Items
  • Toggle via Space oder Enter

R4: Single-Select — radiogroup + radio + aria-checked

  • Single-Select Toggle Groups verwenden role="radiogroup" auf dem Container
  • Jedes Item erhält role="radio" und aria-checked
  • Nur ein Item kann aria-checked="true" haben
  • Navigation via Pfeiltasten (links/rechts) — Roving Tabindex
  • Das aktive Item hat tabindex="0", alle anderen tabindex="-1"
  • Selektion erfolgt automatisch beim Navigieren (focus-follows-selection)

Arrow Key Navigation (Single-Select)

  • ArrowRight / ArrowDown: Nächstes Item fokussieren und selektieren
  • ArrowLeft / ArrowUp: Vorheriges Item fokussieren und selektieren
  • Navigation ist zirkulär (vom letzten zum ersten und umgekehrt)
  • Home: Erstes Item fokussieren und selektieren
  • End: Letztes Item fokussieren und selektieren
  • Nur das fokussierte Item ist in der Tab-Reihenfolge (tabindex="0")

Tab Navigation (Multi-Select)

  • Alle Items sind individuell per Tab erreichbar
  • Jedes Item kann einzeln via Space oder Enter getoggelt werden
  • Der Toggle-Zustand wird via aria-pressed kommuniziert

R6: Icon-Only Items brauchen aria-label

  • Icon-Only Toggle Group Items müssen ein aria-label haben
  • Das Label beschreibt die Aktion, z.B. aria-label="Grid-Ansicht"
  • SVG-Icons innerhalb sind dekorativ und brauchen kein eigenes Label
  • Beispiel: <button class="nc-toggle-group__item" aria-label="Grid-Ansicht"><span class="nc-toggle-group__icon">...</span></button>
