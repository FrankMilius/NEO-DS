Container

Layout-Container für Seiteninhalte mit adaptivem, fluid-skalierendem Innenabstand. Der Container zentriert Inhalte, begrenzt die maximale Breite und setzt horizontales Padding mit clamp(). Implementiert als SCSS-Mixin container-padding und als Klassen .nc-container / .nc-container--wide.

Variante

Code

<div class="nc-container">...</div>

.nc-container

Standard-Container. Fluid-Padding von clamp(16px, 3.5vw, 48px). Ab dem xxl-Breakpoint (1920px): kein Padding, stattdessen max-width mit margin-inline: auto.

Inhalt innerhalb .nc-container

.nc-container--wide

Breiter Container mit width: min(1440px, 94vw). Verwendet container-padding-wide für eine größere maximale Breite am xxl-Breakpoint.

Inhalt innerhalb .nc-container--wide

Full-Bleed Kinder

Bestimmte Kind-Komponenten (z.B. .nc-hero, .nc-logo-wall, .nc-gallery) brechen aus dem Container-Padding aus und gehen von Rand zu Rand, indem sie margin-inline: calc(-1 * var(--container-pad)) und entsprechendes eigenes Padding nutzen.

Padding opt-out

Mit .no-container-pad kann das Container-Padding für einzelne Bereiche oder ganze Sections abgeschaltet werden (z.B. für Hero-Bereiche direkt in der Section).

KlasseAnwendungEffekt
.no-container-pad am inneren div Auf dem direkten Kind-Div des Block-Wrappers Setzt padding-inline: 0 und --container-pad: 0
.no-container-pad am Block-Wrapper Auf dem Block-Wrapper selbst (Section-Ebene) Alle inneren Divs (außer .full-width) erhalten kein Padding
.full-width am inneren div Opt-out vom Container-Max-Width max-width: 100%, box-sizing: border-box

Full-Bleed Formel

Kinder von .nc-container die aus dem Padding ausbrechen sollen, erhalten folgende Styles automatisch:

EigenschaftWertZweck
padding-inline var(--container-pad, 0px) Eigenes Padding entspricht dem Container-Padding
margin-inline calc(-1 * var(--container-pad, 0px)) Negatives Margin hebt das Container-Padding auf
width calc(100% + (var(--container-pad, 0px) * 2)) Breite wird entsprechend vergrößert

Betroffene Kinder: .nc-hero, .nc-logo-wall, .nc-feature-grid, .nc-benefit-grid, .nc-usecase-grid, .nc-news-grid, .nc-metric-grid, .nc-facts-grid, .nc-facts-list, .nc-gallery, .nc-marquee, .nc-slider, .nc-slider__track, .nc-pricing-grid, .nc-faq, .nc-cta__form, .nc-footer__columns.

DOM-Hinweise

  • Container zentriert Inhalt horizontal und begrenzt die maximale Breite.
  • Fluid Padding Inline skaliert von 16px (320px Viewport) bis 48px (1600px) via clamp().
  • Ab XXL (1920px) entfaellt das Inline-Padding, stattdessen greift max-width.
  • Full-bleed Kinder (z.B. .nc-hero) brechen per negativem Margin aus dem Container aus.
  • Vertical Spacing (padding-block) definiert den Abstand zur umgebenden Section/Shell.
  • Alignment steuert die horizontale Ausrichtung (zentriert, links, rechts).
  • Surface-Variante erlaubt Hintergrundfarbe und Schatten auf Layout-Ebene.
  • Vertical Spacing und Surface setzen padding-block; ein --vspace-* gewinnt gegen die Polsterung von --surface (steht spaeter im CSS).

CSS-Klassen

KlasseTypBeschreibung
.nc-container Block Standard-Container. Volle Breite mit fluid Padding. Empfohlen für Seiteninhalte.
.nc-container--wide Modifier Breiter Container. Begrenzt auf min(1440px, 94vw). Empfohlen für extra-breite Layouts.
.section--cq Utility / Modifier Aktiviert CSS Container-Query-Kontext auf einer Section (Opt-in).
.no-container-pad Utility Deaktiviert Container-Padding. Verwendbar auf Block-Wrapper- oder Inner-Div-Ebene.
.full-width Utility Inner div ohne max-width-Begrenzung. Setzt max-width: 100%.

SCSS Mixins

MixinParameterBeschreibung
container-padding — Fluid container padding mit clamp(). Basis-Mixin für alle Container.
container-padding-wide — Wie container-padding, aber mit größerer max-width am xxl-Breakpoint.
container-max-width — Nur max-width + margin-inline: auto, kein Padding. Für Sonderfälle.
container-max-width-wide — Wie container-max-width, mit breitem max-width. Für Sonderfälle.
container-context($name) $name: Bezeichner für @container-Regel Registriert ein Element als container query context (containment: inline-size).
