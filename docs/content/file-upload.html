File Upload

Datei-Upload mit Drag-and-Drop Dropzone, Browse-Button und Dateiliste. Kanonische Klasse: .nc-file-upload (BEM). Alle Werte kommen aus --nc-file-upload-* Component-Tokens.

Live Demo

Wähle Theme, Variante und State, um den File Upload live zu konfigurieren.

State

Code

<div class="nc-file-upload">...</div>

Dropzone

Die Standard-Dropzone bietet eine große Fläche für Drag-and-Drop sowie einen Browse-Button als Fallback. Das Icon und die Hinweistexte sind konfigurierbar.

Dateien hierher ziehen oder Dateien auswählen

Compact

Die kompakte Variante (.nc-file-upload--compact) zeigt nur einen einzeiligen Upload-Button ohne große Dropzone-Fläche.

Dateien auswählen

Dateiliste

Die Dateiliste (.nc-file-upload-list) zeigt hochgeladene Dateien mit Icon, Name, Größe und Entfernen-Button. Zustände: Uploading, Error, Fertig.

  • dokument.pdf 2.4 MB
  • foto.jpg 5.1 MB
  • archiv.zip Dateityp nicht erlaubt

Dragging State

Während ein Drag-Over aktiv ist, erhält die Dropzone den Modifier .nc-file-upload--dragging für visuelles Feedback.

Dateien loslassen Dateien werden hochgeladen

DOM-Hinweise

  • Dropzone: flex-column zentriert, gestrichelte Border (dashed), Hover wechselt Border + BG.
  • Icon: 40px Upload-Icon, dekorativ (aria-hidden).
  • Text: Hauptanweisung (z.B. 'Dateien hierher ziehen').
  • Subtext: Erlaubte Typen/Groesse (z.B. 'PNG, JPG bis 5MB').
  • Button: Optionaler Browse-Button, nutzt .nc-button Styling.
  • Input: <input type='file'> ist sr-only — visuell versteckt aber zugaenglich.
  • Compact-Variante: flex-row, solid Border, kleineres Icon, Subtext hidden.
  • Dragging-State: border-hover + bg-hover + 2px Border (JS via Drag-Events).
  • Error-State: border-error Farbe auf der Dropzone.
  • Disabled-State: opacity-disabled, not-allowed, pointer-events:none.
  • Dateiliste: Separate Komponente (.nc-file-upload-list), flex-column.
  • List-Item: flex-row mit Icon, Name (ellipsis), Size, Remove-Button.
  • Item--error: border-error + bg-danger auf einzelne fehlerhafte Datei.
  • Item--uploading: opacity-medium waehrend Upload.
  • Progress-Bar: 3px, interactive-default Farbe, border-radius-full.

Accessibility Referenz

Dropzone: role='button', tabindex='0', aria-label (z.B. 'Dateien hochladen'). <input type='file'> bleibt im DOM (sr-only) fuer native File-Picker. Keyboard: Enter/Space oeffnet File-Picker. Dateiliste: role='list'. Remove-Button: aria-label='Datei entfernen: {name}'.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: validation = error

  • Empfohlen: aria-invalid
  • Empfohlen: aria-describedby
  • Error: aria-invalid='true' auf dem Input. Fehlermeldung via aria-describedby (z.B. 'Datei zu gross').

Wenn: Spezialbedingung

  • Empfohlen: aria-disabled
  • Disabled: disabled-Attribut auf dem Input. Dropzone: aria-disabled='true'.
