Richtlinien

  • Semantisches <table>-Markup verwenden — Screenreader lesen Zeilen/Spalten-Beziehungen automatisch vor.
  • Jede Checkbox braucht ein aria-label mit Zeilen-Kontext.
  • Focus-Ring muss auf allen interaktiven Elementen sichtbar sein (via :focus-visible + @include focus-ring).
  • Sort-State per aria-sort auf <th> — Screenreader kuendigen “sorted ascending/descending” an.
  • Batch-Bar nutzt aria-live="polite" — Aenderungen werden automatisch angesagt.
  • prefers-reduced-motion deaktiviert Skeleton-Shimmer und Transition-Animationen.
