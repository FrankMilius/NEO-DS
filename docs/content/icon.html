DOM-Hinweise

  • Icon ist ein <span class='icon'> mit inline SVG als Kind-Element.
  • Default-Groesse: sm (20px). Kein md-Default — sm ist der Standard.
  • SVG nutzt fill: currentColor — Farbe wird via CSS color gesteuert.
  • Nicht-BEM Konvention: .icon statt .nc-icon (historisch gewachsen).
  • Deprecated: .icon--2xs (12px, altes xs), .icon--high/--mid/--low (alte Farbnamen).
  • Interactive-Modifier (.icon--interactive): min 44x44px Touch-Target via Padding, hover + focus-ring.
  • Interactive Icons brauchen ein umschliessendes <button> oder role='button' + tabindex.
  • Icon-Logo (.icon-logo): Spezialfall mit fester Groesse 88x22px.

Accessibility Referenz

Dekorative Icons sind aria-hidden='true'. Informative Icons brauchen aria-label oder role='img' + aria-label. Interactive Icons brauchen ein umschliessendes <button> oder role='button'.

Nicht interaktiv

  • Diese Komponente ist nicht fokussierbar und nicht klickbar.

Farbkontrast: WCAG AA non-text (3:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Wenn: interactive = interactive

  • Pflicht: hasAccessibleName
  • Pflicht: supportsKeyboard
  • Interactive Icons brauchen aria-label und muessen tastaturzugaenglich sein. Touch-Target mindestens 44x44px (WCAG 2.5.5).

Wenn: color = inverse

  • Inverse Icons brauchen dunklen Hintergrund fuer 3:1 Kontrast.
