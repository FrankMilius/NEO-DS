Spinner

Rotierender Lade-Indikator für asynchrone Operationen. Kanonische Klasse: .nc-spinner (BEM). Alle Werte kommen aus --nc-spinner-* Component-Tokens.

Alle Größen

5 Größen: XS (16px), SM (20px), MD (24px, Default), LG (40px), XL (56px).
