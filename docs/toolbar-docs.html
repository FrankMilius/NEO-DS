NEO Design System

Toolbar

Horizontale Aktionsleiste mit gruppierten Buttons, Separatoren, Spacer und Labels. Toolbars werden typischerweise über Tabellen, Editoren oder Content-Bereichen platziert. Kanonische Klasse: .nc-toolbar (BEM). Alle Werte kommen aus --nc-toolbar-* Component-Tokens.

Default Toolbar

Toolbar mit Button-Gruppen, Separator und Spacer. Buttons verwenden .nc-button--sm.

Zoom:

Code

<div class="nc-toolbar" role="toolbar" aria-label="Formatierung">
  <div class="nc-toolbar__group">
    <button class="nc-button nc-button--sm nc-button--secondary">B</button>
    <button class="nc-button nc-button--sm nc-button--secondary">I</button>
  </div>
  <div class="nc-toolbar__separator" aria-hidden="true"></div>
  <div class="nc-toolbar__group">...</div>
  <div class="nc-toolbar__spacer"></div>
  <div class="nc-toolbar__group">
    <span class="nc-toolbar__label">Label:</span>
    <button class="nc-button nc-button--sm">Aktion</button>
  </div>
</div>

Bordered

Die .nc-toolbar--bordered Variante fügt einen Rahmen und Hintergrund hinzu.

Compact

Die .nc-toolbar--compact Variante reduziert Höhe und Abstände.

Toolbar mit Label und Spacer

Der .nc-toolbar__spacer schiebt nachfolgende Elemente nach rechts. .nc-toolbar__label zeigt beschreibenden Text.

DOM-Hinweise

  • Root: role='toolbar', aria-label. Flex-Layout, flex-wrap, min-height 48px.
  • Group: Logische Zusammenfassung von Buttons/Inputs. Flex-Row mit gap.
  • Group--end: margin-inline-start:auto — drueckt Gruppe ans rechte Ende.
  • Spacer: flex:1 — flexibler Abstand zwischen Gruppen.
  • Separator: Vertikale Trennlinie, feste Hoehe (24px), align-self:center. Dekorativ (aria-hidden).
  • Label: Optionaler Text (z.B. 'Filter:', 'Ansicht:'), user-select:none.
  • Overflow-Trigger: Button fuer Priority-Based Overflow, oeffnet Dropdown mit ausgeblendeten Items.
  • Bordered: Border + Radius um die gesamte Toolbar.
  • Border-Bottom: Nur untere Grenzlinie (z.B. unter Header).
  • Floating: Card-aehnlich mit surface-elevated BG, Shadow, groesserem Radius. Ideal fuer Canvas-Editoren.
  • Blurred: Glassmorphism — halbtransparenter BG + backdrop-filter:blur. Fuer Shell-Integration.
  • Compact: 32px Desktop / 48px Mobile (Touch-Target Compliance).
  • Sticky: position:sticky, top:0. Schatten via .is-scrolled — setzt neo-behaviors toolbar, solange die Leiste angeheftet ist (IntersectionObserver auf der Leiste mit um top+1px verkleinertem Rahmen; ohne IO bleibt die Klasse aus).
  • Alignment: --align-center (zentriert), --align-justify (space-between).
  • Tastatur (Entscheidungen 03.10.2026): Tab aus einem Eingabefeld geht zum Nachbarn in der Leiste, am Rand raus (toolbar-tab); eingebettete Gruppen (Toggle-Group, Segmented) laufen flach mit (toolbar-gruppen); Ereignis toolbar-focus bleibt (toolbar-ereignis).

Accessibility Referenz

Root: role='toolbar', aria-label (z.B. 'Tabellen-Aktionen'). Keyboard: Roving tabindex — Arrow Left/Right navigiert zwischen Items, auch komplexe Elemente (Search-Input). Nur ein Item im Tab-Index (tabindex='0'), Rest tabindex='-1'. Separator dekorativ (aria-hidden). Label: rein visuell, nicht fokussierbar.

Farbkontrast: WCAG AA non-text (3:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: density = compact

  • Empfohlen: touch-target
  • Compact: Buttons mindestens 24px Target auf Desktop. Mobile: automatisch 48px via CSS Override.

Wenn: variant = blurred

  • Empfohlen: contrast-check
  • Blurred: Kontrast der Inhalte gegen wechselnden Hintergrund pruefen. Fallback auf solide Farbe bei prefers-contrast:more.
