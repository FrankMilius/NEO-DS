NEO Design System

Pagination

Seitennavigation für Listen, Suchergebnisse und Tabellen. Kanonische Klasse: .nc-pagination (BEM). Alle Werte kommen aus --nc-pagination-* Component-Tokens.

Vollständige Pagination

Prev/Next-Buttons, Seitenzahlen, Ellipsis und aktive Seite.

  4. …Weitere Seiten

Aktive Seite (Mitte)

Seite 5 von 12 aktiv — Ellipsis auf beiden Seiten.

  2. …
  6. …

Größe SM

.nc-pagination--sm für kompaktere Darstellung (28px Items).

Disabled Prev/Next

Am Anfang ist "Prev" disabled, am Ende "Next".

Erste Seite (Prev disabled)
Letzte Seite (Next disabled)

3 Alignment-Varianten: Center, End, Between.

Accessibility

RegelBeschreibung
R1<nav aria-label="Seitennavigation"> als Container
R2Seitenzahlen als <button> oder <a>
R3Aktive Seite: aria-current="page"
R4Disabled Prev/Next: disabled + aria-disabled="true"
R5Ellipsis: .u-sr-only mit "Weitere Seiten"
