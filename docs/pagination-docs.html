Pagination

Seitennavigation für Listen, Suchergebnisse und Tabellen. Kanonische Klasse: .nc-pagination (BEM). Alle Werte kommen aus --nc-pagination-* Component-Tokens.

Vollständige Pagination

Prev/Next-Buttons, Seitenzahlen, Ellipsis und aktive Seite.

  4. …Weitere Seiten

Aktive Seite (Mitte)

Seite 5 von 12 aktiv — Ellipsis auf beiden Seiten.

  2. …
  6. …

Größe SM

.nc-pagination--sm für kompaktere Darstellung (28px Items).

Disabled Prev/Next

Am Anfang ist "Prev" disabled, am Ende "Next".

DOM-Hinweise

  • Root: <nav aria-label='Seitennavigation'> — landmark fuer Screen Reader.
  • Seitenzahlen als <button> oder <a>. Aktive Seite: aria-current='page'.
  • Prev/Next: <button> mit SVG-Chevron. Am Rand: aria-disabled='true'.
  • Ellipsis: <span> mit .u-sr-only 'Weitere Seiten'.
  • Info: Minimal-Variante zeigt 'Seite X von Y' statt Seitenzahlen.
  • Jumper: <input type='number'> fuer direkte Seiteneingabe.
  • Touch-Target: unsichtbarer ::before min. 44px fuer Mobile-Tap.
  • tabular-nums: Gleichbreite Ziffern verhindern Layout-Sprung bei Seitenwechsel.

Accessibility Referenz

<nav> landmark mit aria-label. Aktive Seite: aria-current='page'. Disabled: aria-disabled='true'. Ellipsis: .u-sr-only 'Weitere Seiten'. Touch-Target min. 44px via ::before.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: Spezialbedingung

  • Empfohlen: aria-disabled="true"
  • Prev/Next am Rand: aria-disabled='true' statt disabled-Attribut fuer Screen-Reader-Ankuendigung.
