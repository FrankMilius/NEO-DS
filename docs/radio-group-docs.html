NEO Design System

Radio Group

Container für mehrere Radio-Buttons mit gemeinsamem Label und Gruppen-Semantik. Unterstützt vertikales, horizontales und Segmented-Control-Layout sowie Card-Variante. Kanonische Klasse: .nc-radio-group (BEM). Alle Werte kommen aus --nc-group-*, --nc-radio-segmented-* und --nc-radio-card-* Component-Tokens.

Verwendung

Die Radio-Group fasst mehrere Radio-Buttons in einer semantischen Gruppe zusammen. Pfeil-Tasten navigieren zwischen den Optionen. Gleiche Token-Struktur wie Checkbox-Group.

DOM-Hinweise

  • Flex-Column Container für mehrere .nc-radio Elemente (gleicher name-Attribut).
  • Segmented-Variante: Radio-Controls versteckt (sr-only), Labels als sichtbare Buttons.
  • Tastatur: Arrow Keys wechseln zwischen Radios (natives Browser-Verhalten).
  • Error propagiert border-error auf alle Radio-Controls.

Accessibility Referenz

role="radiogroup" + aria-labelledby. Arrow Keys Navigation. Einzelne Radios haben eigene A11y.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Varianten müssen 4.5:1 Kontrast einhalten.

Pflicht: role="radiogroup" + aria-labelledby

  • Pflicht: role="radiogroup" auf dem Container.
  • Pflicht: aria-labelledby verweist auf Legend oder Label.

Wenn: Error-State

  • Empfohlen: aria-describedby auf Gruppen-Error-Text.

Wenn: Segmented Control

  • Arrow Keys müssen wie bei normaler Radio-Gruppe funktionieren.
  • Visuelles Feedback auf fokussiertem Segment (focus-ring).
