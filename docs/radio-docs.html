Radio

DOM-Hinweise

  • Wrapper ist ein <label class='nc-radio'> — Klick auf Label aktiviert Input.
  • Native <input type='radio'> wird via sr-only versteckt, bleibt im DOM fuer Accessibility.
  • __control ist ein <span> mit border-radius: 50% (Kreis).
  • :checked → Dot via ::after pseudo-element, skaliert mit transform: scale(dot-scale).
  • :focus-visible auf dem Native Input delegiert den Focus-Ring auf __control.
  • Radio-Buttons in einer Gruppe teilen sich den gleichen name-Attribut. Nur einer kann gleichzeitig checked sein.
  • Error kann per .nc-radio--error gesetzt werden.
  • Alignment --top: Control obenbuendig bei mehrzeiligen Labels (margin-top: 0.15em).
  • Card-Variante (--card): Wrapper bekommt Padding, Border, Radius. Checked-State zeigt aktiven BG + Border.

DOM-Hinweise

  • Flex-Column Container fuer mehrere .nc-radio Elemente.
  • Gap via --nc-group-gap. Horizontal: flex-row, flex-wrap, --nc-group-gap-horizontal.
  • Size-Modifier (--sm / --lg) koppelt Gap an Radio-Groesse: sm=8px, md=12px (default), lg=16px.
  • Segmented-Variante: Pillen-Design, Radios nahtlos aneinanderliegend, Controls versteckt, Labels als Buttons.
  • Card-Variante: Jedes .nc-radio bekommt .nc-radio--card Modifier fuer eigene Box.
  • Hint-Slot: Enthaelt .nc-form-hint fuer Gruppen-Hilfetext. Verknuepft via aria-describedby auf dem Gruppen-Container.
  • Error: propagiert border-error auf alle Radio-Controls.
  • Disabled: opacity + pointer-events:none auf gesamte Gruppe.
  • Tastatur: Arrow Keys wechseln zwischen Radios.

Accessibility Referenz

Native <input type='radio'> bleibt im DOM (sr-only). Label via <label> Wrapper. Pfeil-Tasten navigieren innerhalb der Radio-Gruppe.

Farbkontrast: WCAG AA non-text (3:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: validation = error

  • Pflicht: aria-invalid
  • Pflicht: aria-describedby
  • Error-State braucht aria-invalid='true' auf dem Input und aria-describedby das auf die Fehlermeldung verweist.

Wenn: Spezialbedingung

  • Empfohlen: aria-disabled
  • aria-disabled='true' bevorzugt wenn Radio Teil eines sichtbaren Formulars ist.

Sub-Komponente: Radio Group

Accessibility Referenz

role='radiogroup' + aria-labelledby. Arrow Keys Navigation. Einzelne Radios haben eigene A11y.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: Spezialbedingung

  • Empfohlen: aria-describedby
  • Error: aria-describedby auf Gruppen-Error-Text.

Wenn: Spezialbedingung

  • Empfohlen: aria-describedby
  • Hint wird via aria-describedby auf dem Gruppen-Container verknuepft (id='hint-{groupname}').

Wenn: variant = segmented

  • Empfohlen: keyboard-arrows
  • Segmented Control: Arrow Keys muessen wie bei normaler Radio-Gruppe funktionieren. Visuelles Feedback auf fokussiertem Segment (focus-ring).
