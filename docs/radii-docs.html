NEO Design System

Border Radius

9-stufige Radius-Skala von 0px (sharp) bis 9999px (pill). Jeder Radius-Token ist als CSS Custom Property --fnd-radius-{size} verfügbar.

Die Skala umfasst 7 Kernstufen (null–2xl), eine Kompatibilitätsstufe (3xl) und den Sonderwert full für Pill-Shapes.

Code-Beispiele

CSS Custom Properties

/* Radius-Token als CSS Custom Property */ .card { border-radius: var(--fnd-radius-lg); /* 8px */ } .modal { border-radius: var(--fnd-radius-3xl); /* 16px */ } .badge { border-radius: var(--fnd-radius-full); /* 9999px → Pill */ } /* Button-Radius über Component-Token */ .custom-button { border-radius: var(--nc-button-radius-md); /* 6px */ }

SCSS-Getter

@use '../00-settings' as *; // SCSS-Funktion radius() liefert den px-Wert .element { border-radius: radius('lg'); // 8px } // Für Mixins, die einen Radius-Wert benötigen $my-radius: radius('md'); // 6px

Migrations-Leitfaden

Die alte 3-Stufen-Skala (s, m, l) wurde durch die neue 9-Stufen-Skala ersetzt. Für Abwärtskompatibilität existieren CSS-Aliases. Neue Entwicklungen sollten ausschließlich die neuen Token-Namen verwenden.

Alt (deprecated) Neu Wert Status
--fnd-radius-s --fnd-radius-sm 4px Alias aktiv, deprecated
--fnd-radius-m --fnd-radius-lg 8px Alias aktiv, deprecated
--fnd-radius-l --fnd-radius-3xl 16px Alias aktiv, deprecated
--fnd-radius-2xs --fnd-radius-null 0px Alias aktiv, deprecated
/* Im CSS: Aliases funktionieren weiterhin */ :root { --fnd-radius-s: var(--fnd-radius-sm); /* 4px */ --fnd-radius-m: var(--fnd-radius-lg); /* 8px */ --fnd-radius-l: var(--fnd-radius-3xl); /* 16px */ --fnd-radius-2xs: var(--fnd-radius-null); /* 0px */ } /* Alter Code funktioniert ohne Änderung: */ .legacy-card { border-radius: var(--fnd-radius-m); } /* = 8px */ /* Neuer Code verwendet neue Token: */ .new-card { border-radius: var(--fnd-radius-lg); } /* = 8px */

Design-Prinzipien

3-Schichten-Architektur

Foundation Token (--fnd-radius-*) → Component Token (--nc-{comp}-radius) → Page Override. Komponenten referenzieren nie direkt Foundation-Tokens, sondern immer Component-Tokens.

Proportionale Skalierung

Größere UI-Elemente erhalten proportional größere Radii. Ein XS-Button (24px Höhe) hat 2px Radius, ein 2XL-Button (80px) hat 12px. Dies sorgt für optische Konsistenz über alle Größen.

Customer Theming

Radius-Tokens können pro Scope überschrieben werden. Ein Kunde kann z.B. --fnd-radius-lg: 12px setzen, um alle Elemente runder zu gestalten. Component-Tokens fließen die Änderung automatisch durch.
