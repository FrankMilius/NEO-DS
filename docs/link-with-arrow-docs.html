Link with Arrow

Ein einfacher Inline-Link mit integriertem Pfeil-Icon — typisch als “Mehr erfahren”-Link oder als CTA am Ende von Text-Abschnitten. Kanonische Klasse: a.link-with-arrow. Farben kommen direkt aus Foundation-Tokens (--fnd-color-text-high / --fnd-color-text-mid).

Accessibility Referenz

Als interaktives <a>-Element gelten für Link with Arrow die vollen WCAG 2.1 AA-Anforderungen für Links.

Fokus & Tastaturnavigation

  • Als <a>-Element ist der Link nativ im Tab-Fokus enthalten
  • Der Fokusring wird durch globale Link-Stile (@include focus-ring) gesetzt
  • Kein zusätzliches tabindex nötig
  • Der Link muss ein gültiges href-Attribut haben

Pfeil-Icon

  • Das Pfeil-SVG ist dekorativ und muss aria-hidden="true" tragen
  • Der Linktext allein muss den Zweck des Links vermitteln (WCAG 2.4.6)
  • Kein role-Attribut am SVG nötig

Externe Links

  • Bei target="_blank" immer rel="noopener noreferrer" setzen
  • Screenreader-Nutzer müssen informiert werden: <span class="u-sr-only">(öffnet in neuem Tab)</span>

Farbkontrast (WCAG 1.4.3)

  • Linktext muss mindestens 4.5:1 Kontrast zum Hintergrund haben
  • --fnd-color-text-high erfüllt dies in allen 4 Themes
  • Die Hover-Farbe --fnd-color-text-mid muss ebenfalls kontrastreich bleiben
