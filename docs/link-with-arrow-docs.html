NEO Design System

Link with Arrow

Ein einfacher Inline-Link mit integriertem Pfeil-Icon — typisch als “Mehr erfahren”-Link oder als CTA am Ende von Text-Abschnitten. Kanonische Klasse: a.link-with-arrow. Farben kommen direkt aus Foundation-Tokens (--fnd-color-text-high / --fnd-color-text-mid).

Live Demo

Wähle Theme und Linktext, um den Link with Arrow live zu sehen.

Linktext

Code

<a href="#" class="link-with-arrow">
  Mehr erfahren
  <svg width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5">
    <path d="M5 12h14M12 5l7 7-7 7"/>
  </svg>
</a>

Standard-Verwendung

Der Link kombiniert Text und ein Pfeil-SVG. Das Pfeil-Icon folgt direkt nach dem Text.
