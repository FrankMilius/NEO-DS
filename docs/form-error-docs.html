Form Error

Token-basierte Validation/Error-Message für Formular-Felder. Zeigt Fehlermeldungen mit optionalem Icon an und wird via aria-describedby mit dem zugehörigen Input verknüpft. Kanonische Klasse: .nc-form-error (BEM). Alle Werte kommen aus --nc-form-error-* Component-Tokens.

Verwendung

Die Form-Error-Komponente zeigt Validierungsfehlermeldungen unterhalb eines Formular-Feldes an. Sie wird via aria-describedby mit dem Input verknüpft und nutzt role="alert" für sofortige Screenreader-Ansage.

Standard (mit Icon)

<div class="nc-form-error" role="alert" id="error-email">
  <span class="nc-form-error__icon" aria-hidden="true">
    <svg viewBox="0 0 24 24">
      <circle cx="12" cy="12" r="10"/>
      <line x1="12" y1="8" x2="12" y2="12"/>
      <line x1="12" y1="16" x2="12.01" y2="16"/>
    </svg>
  </span>
  <span class="nc-form-error__text">Bitte geben Sie eine gültige E-Mail-Adresse ein.</span>
</div>

Nur Text (ohne Icon)

<div class="nc-form-error" role="alert" id="error-name">
  <span class="nc-form-error__text">Dieses Feld ist erforderlich.</span>
</div>

Mit Input-Feld

Typischer Anwendungsfall: Error-Message unterhalb eines Input-Feldes mit aria-describedby-Verknüpfung.

<div class="nc-form-field nc-form-field--error">
  <label class="nc-form-label" for="email">E-Mail</label>
  <input class="nc-input nc-input--error" type="email" id="email"
         aria-invalid="true" aria-describedby="error-email" />
  <div class="nc-form-error" role="alert" id="error-email">
    <span class="nc-form-error__icon" aria-hidden="true">...</span>
    <span class="nc-form-error__text">Bitte geben Sie eine gültige E-Mail-Adresse ein.</span>
  </div>
</div>

DOM-Hinweise

  • Flexbox-Layout: Icon + Text nebeneinander, align-items: flex-start.
  • Icon ist ein SVG (stroke-basiert, 16px), optisch via margin-top: 0.1em an Text ausgerichtet.
  • Text erbt Styles vom Block (font-size, color, font-weight).
  • Wird via aria-describedby am zugehörigen Input verknüpft (id="error-{name}").
  • role="alert" für sofortige Screenreader-Ansage, aria-live="polite" für sanfte Updates.

Accessibility Referenz

Error-Message wird via aria-describedby am Input referenziert. role="alert" oder aria-live="polite" für dynamische Anzeige. Icon ist dekorativ (aria-hidden="true").

Farbkontrast: WCAG AA normal text (4.5:1)

  • Fehler-Farbe (Danger) muss 4.5:1 Kontrast gegen den Hintergrund haben.
  • Farbe ist nie alleiniges Signal — Icon und Text ergänzen.

Pflicht: aria-describedby

  • Pflicht: Error-Message muss via aria-describedby mit dem zugehörigen Input verknüpft sein.

Wenn: Severity = Error

  • Empfohlen: role="alert" für sofortige Screenreader-Ansage bei Validierungsfehlern.

Wenn: Warning/Success

  • Empfohlen: aria-live="polite" für sanftes Update ohne Unterbrechung.
