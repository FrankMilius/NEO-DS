NEO Design System

Table

Vergleichs- und Datentabelle für tabellarische Inhalte. Die Tabelle verwendet semantische Farben, Elevation und Border-Radius aus dem Foundation-Token-System. Kanonische Klasse: .nc-compare-table. Alle Werte kommen aus Foundation-Tokens (--fnd-*).

Live Demo

Interaktive Vorschau der Tabelle. Wähle ein Theme, um die Darstellung in verschiedenen Farbmodi zu prüfen.

Spalten

Code

<table class="nc-compare-table">...</table>

DOM-Hinweise

  • Einfache Vergleichstabelle mit inverser Header-Zeile.
  • Volle Breite, border-collapse, elevation-raised Shadow.
  • Header: inverse BG + Color. Zellen: variable Padding per Density.
  • Sortable: cursor pointer + Sort-Icon im Header. Selectable: Checkbox-Spalte.
  • Sticky-Header: position sticky mit Shadow beim Scrollen.

Accessibility Referenz

<table> mit <caption> oder aria-label. Semantisches <thead>/<tbody>/<tfoot>. scope='col' auf <th>.

Nicht interaktiv

  • Diese Komponente ist nicht fokussierbar und nicht klickbar.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: Spezialbedingung

  • aria-sort='ascending|descending|none' auf sortierbare <th>

Wenn: Spezialbedingung

  • aria-selected='true' auf selektierte <tr>
