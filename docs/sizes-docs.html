Alle Größen im Vergleich

Sieben Größen von XS (24px) bis 2XL (80px). LG (48px) ist die häufigste Größe in Software-Produkten.

Accessibility Referenz

Alle Button-Größen müssen die WCAG 2.1 AA-Anforderungen erfüllen. Die Größe beeinflusst vor allem das Touch-Target.

Touch-Target-Größe (WCAG 2.5.5)

  • WCAG 2.5.5 empfiehlt mindestens 44x44px Touch-Target
  • XS (24px) und SM (32px) sind unter diesem Wert — nur in nicht-touch-primären Kontexten verwenden
  • LG (48px) und größer erfüllen WCAG 2.5.5 vollständig
  • Für mobile Anwendungen mindestens MD (40px) bevorzugen

Größen-Kontext und Lesbarkeit

  • Größere Buttons erhalten i.d.R. auch größere Schrift — sicherstellen, dass Kontrast und Lesbarkeit erhalten bleiben
  • Inkonsistente Button-Größen auf einer Seite können kognitive Last erhöhen
  • Primäre Aktionen sollten die größte Button-Variante in einem Kontext verwenden
