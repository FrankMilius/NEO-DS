File Upload

Datei-Upload mit Drag-and-Drop Dropzone, Browse-Button und Dateiliste. Kanonische Klasse: .nc-file-upload (BEM). Alle Werte kommen aus --nc-file-upload-* Component-Tokens.

Dropzone

Die Standard-Dropzone bietet eine große Fläche für Drag-and-Drop sowie einen Browse-Button als Fallback. Das Icon und die Hinweistexte sind konfigurierbar.

Dateien hierher ziehen oder Dateien auswählen

Compact

Die kompakte Variante (.nc-file-upload--compact) zeigt nur einen einzeiligen Upload-Button ohne große Dropzone-Fläche.

Dateien auswählen

Dateiliste

Die Dateiliste (.nc-file-upload-list) zeigt hochgeladene Dateien mit Icon, Name, Größe und Entfernen-Button. Zustände: Uploading, Error, Fertig.

  • foto.jpg 5.1 MB
  • archiv.zip Dateityp nicht erlaubt

Dragging State

Während ein Drag-Over aktiv ist, erhält die Dropzone den Modifier .nc-file-upload--dragging für visuelles Feedback.

Accessibility Referenz

Die File-Upload-Komponente muss per Tastatur bedienbar und für Screenreader zugänglich sein (WCAG 2.1 AA).

role="button" auf Dropzone

  • Die Dropzone (<div>) erhält role="button" und tabindex="0"
  • Enter und Space müssen den versteckten File-Input triggern
  • Im Disabled-Zustand: aria-disabled="true" und tabindex="-1"
  • Label per aria-label oder sichtbaren Text bereitstellen

Verstecktes File-Input

  • Das <input type="file"> ist visuell versteckt (tabindex="-1")
  • Es wird programmatisch per .click() ausgelöst, wenn die Dropzone aktiviert wird
  • Das Input muss nicht direkt fokussierbar sein — der Focus liegt auf der Dropzone
  • Das accept-Attribut sollte erlaubte Dateitypen einschränken

Listen-Semantik

  • Die Dateiliste nutzt <ul> / <li> für korrekte Listenstruktur
  • Screenreader kündigen „Liste mit X Elementen“ an
  • Der Entfernen-Button braucht ein beschreibendes aria-label (z.B. „dokument.pdf entfernen“)
  • Für dynamische Updates: aria-live="polite" am Listen-Container

Drag-and-Drop Zugänglichkeit

  • Drag-and-Drop ist eine Erweiterung, kein Ersatz — der Browse-Button ist die primäre Interaktion
  • Tastaturnutzer müssen Dateien über Enter/Space + nativen File-Dialog auswählen können
  • Im Dragging-State sollte kein Focus-Trap entstehen
  • Statusänderungen (Upload-Start, Fortschritt, Fehler) per aria-live ankündigen
