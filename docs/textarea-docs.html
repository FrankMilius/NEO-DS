Textarea

Mehrzeilige Texteingabe mit optionalem Zeichenzähler und Auto-Resize. Kanonische Klasse: .nc-textarea (BEM). Alle Werte kommen aus --nc-textarea-* und --nc-input-* Component-Tokens.

Auto-Resize

Mit dem Modifier .nc-textarea--autosize wächst die Textarea automatisch mit dem Inhalt. Der Resize-Handle wird deaktiviert, die Höhe wird per JavaScript gesteuert.

DOM-Hinweise

  • Textarea ist ein natives <textarea class='nc-textarea'>. Kein JS fuer Basis-Funktion noetig.
  • Nutzt --nc-input-* Tokens als Basis (gleiche form-control Mixins wie Input).
  • Eigene --nc-textarea-* Tokens fuer min-height, max-height, padding, resize und Scrollbar.
  • height: auto ueberschreibt die feste Hoehe aus form-control-size.
  • max-height: Bei gesetztem Wert (nicht 'none') erzwingt overflow-y: auto einen Scrollbar.
  • scrollbar-width: 'thin' (Standard) fuer schmalere Scrollbars. Webkit-Fallback via ::-webkit-scrollbar.
  • Autosize (.nc-textarea--autosize): resize: none, overflow: hidden — JS steuert Hoehe.
  • Character Counter (__counter): Nutzt --nc-form-hint-* Tokens. --limit aendert auf Error-Farbe.
  • Actions-Slot (__actions): Flex-Container unterhalb der Textarea fuer interaktive Buttons (Copy, Clear, AI-Assist). Wrapper muss :has(.nc-textarea__actions) sein, damit Textarea unteren Radius verliert.
  • Empty vs. Focus-Within: :placeholder-shown kennzeichnet leere Textarea. Wrapper :focus-within steuert Actions-Sichtbarkeit — Actions werden ausgeblendet wenn Textarea leer UND nicht fokussiert.
  • Error via .nc-textarea--error ODER [aria-invalid='true'].

Accessibility Referenz

Natives <textarea> — inhaerent accessible. Braucht zugehoeriges <label> (via for/id) oder aria-label. Resize-Griff ist nativ tastaturzugaenglich.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: validation = error

  • Pflicht: aria-invalid
  • Pflicht: aria-describedby
  • Error-State braucht aria-invalid='true' und aria-describedby auf Fehlermeldung.

Wenn: Spezialbedingung

  • Empfohlen: aria-disabled
  • aria-disabled='true' bevorzugt wenn Textarea Teil eines sichtbaren Formulars ist.

Wenn: content = with-actions

  • Empfohlen: focusVisible
  • Empfohlen: aria-label-actions
  • Action-Buttons muessen :focus-visible mit focus-ring haben. Jeder Button braucht aria-label oder sichtbaren Text. Actions-Container kann role='toolbar' mit aria-label='Textarea Aktionen' haben.
