Textarea

Mehrzeilige Texteingabe mit optionalem Zeichenzähler und Auto-Resize. Kanonische Klasse: .nc-textarea (BEM). Alle Werte kommen aus --nc-textarea-* und --nc-input-* Component-Tokens.

Zeichenzähler

Mit maxlength und dem Element .nc-textarea__counter wird ein Zeichenzähler angezeigt. Bei Erreichen des Limits erhält der Zähler die Klasse .nc-textarea__counter--limit.

Auto-Resize

Mit dem Modifier .nc-textarea--autosize wächst die Textarea automatisch mit dem Inhalt. Der Resize-Handle wird deaktiviert, die Höhe wird per JavaScript gesteuert.

Accessibility Referenz

Die Textarea-Komponente ist ein interaktives Formularelement und muss die WCAG 2.1 AA-Kriterien erfüllen.

Tastatur-Navigation

  • Tab — Fokus auf die Textarea setzen / weiter zum nächsten Element
  • Shift+Tab — Fokus zurück zum vorherigen Element
  • Enter — Neue Zeile im Text (im Gegensatz zum Input-Feld)
  • Texteingabe, Pfeiltasten, Markierung funktionieren wie üblich
  • Bei disabled wird die Textarea übersprungen
  • Bei readonly bleibt die Textarea fokussierbar, Text kann markiert/kopiert werden

ARIA-Attribute

  • aria-invalid="true" — kennzeichnet ungültige Eingabe, aktiviert Error-Styling
  • aria-describedby — verweist auf Hilfetext, Fehlermeldung oder Zeichenzähler
  • aria-label — barrierefreies Label, wenn kein sichtbares <label> vorhanden ist
  • aria-required="true" — alternativ zu required Attribut
  • Immer ein sichtbares <label> mit for-Attribut oder aria-label verwenden

Screenreader-Ankündigungen

  • Label wird beim Fokussieren vorgelesen, gefolgt von “Textbereich” (oder “text area”)
  • Placeholder wird als zusätzlicher Kontext angekündigt, ersetzt aber kein Label
  • Bei aria-invalid="true" wird “ungültig” angekündigt
  • Bei required wird “erforderlich” angekündigt
  • Zeichenzähler mit aria-live="polite" für dynamische Aktualisierungen
  • Fehlermeldungen über aria-describedby verknüpfen

Focus-Visible

  • Sichtbarer Fokusring über :focus-visible via @include focus-ring
  • Fokusring verwendet --nc-input-border-focus (interaktive Focus-Farbe)
  • Der Fokusring ist bei allen Themes ausreichend kontrastreich
  • Kein Fokusring bei Maus-Klick (nur bei Tastatur-Navigation)
