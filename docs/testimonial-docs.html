Accessibility Referenz

Testimonials sind primär statische Zitat-Inhalte. Die korrekte semantische HTML-Auszeichnung ist entscheidend für Screenreader-Nutzer.

Semantisches Zitat-Element

  • <blockquote> ist das korrekte HTML-Element für Zitate
  • Screenreader können den Inhalt als Zitat ankkündigen
  • Alternativ: <figure> + <figcaption> für Zitat mit Attribution
  • Kein <div> für semantisch bedeutsame Zitate verwenden

Avatar-Bilder

  • Autoren-Avatar-Bilder sind dekorativ — alt="" (leer) setzen
  • Der Name des Autors steht bereits als Text in .nc-testimonial__name
  • width und height-Attribute setzen, um Cumulative Layout Shift zu vermeiden

Slider-Bedienung

  • Bei horizontalem Slider: Navigation-Buttons mit aria-label (z.B. “Vorheriges Testimonial”) anbieten
  • Der Scroll-Container sollte role="region" + aria-label erhalten
  • Tastatur-Navigation per Tab (Fokus auf Inhalte) muss reibungslos funktionieren
