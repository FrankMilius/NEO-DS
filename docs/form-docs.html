NEO Design System

Form

Token-basiertes Form-Layout das mehrere Form-Fields in einem konsistenten vertikalen, horizontalen oder Grid-Layout anordnet. Kanonische Klasse: .nc-form (BEM). Alle Werte kommen aus --nc-form-* Component-Tokens.

Verwendung

Die Form-Komponente ist der äußere Container für Formulare. Sie stellt konsistente Abstände zwischen allen Kindern sicher und bietet verschiedene Layout-Optionen.

Vertical (Standard)

<form class="nc-form" aria-label="Registrierung" novalidate>
  <div class="nc-form-field">...</div>
  <div class="nc-form-field">...</div>
  <div class="nc-form-actions nc-form-actions--end">
    <button class="nc-button" type="submit">Absenden</button>
  </div>
</form>

Inline

Alle Felder und Buttons nebeneinander. Nützlich für Such- oder Filter-Formulare.

<form class="nc-form nc-form--inline" aria-label="Suche">
  <div class="nc-form-field">
    <input class="nc-input" type="search" placeholder="Suchen..." />
  </div>
  <button class="nc-button" type="submit">Suchen</button>
</form>

Two-Column (Grid)

Responsives 2-Spalten CSS-Grid: Mobile = 1 Spalte, ab md Breakpoint = 2 Spalten.

<form class="nc-form nc-form--two-column" aria-label="Kontaktformular">
  <div class="nc-form-field">...</div>  <!-- Spalte 1 -->
  <div class="nc-form-field">...</div>  <!-- Spalte 2 -->
  <fieldset class="nc-fieldset">...</fieldset>  <!-- Volle Breite (grid-column: 1/-1) -->
  <button class="nc-button" type="submit">Absenden</button>  <!-- Volle Breite -->
</form>

Disabled

<form class="nc-form nc-form--disabled" aria-label="Gesperrt" aria-disabled="true">
  <div class="nc-form-field">...</div>
</form>

DOM-Hinweise

  • Root: <form> mit flex-column Layout. Gap via --nc-form-gap (24px).
  • Enthält .nc-form-field, .nc-fieldset, .nc-form-section, .nc-form-actions.
  • Inline: flex-row, flex-wrap. Fields auto-width. Submit am Ende.
  • Two-Column: CSS Grid, 1fr mobile → repeat(2,1fr) ab md. Fieldsets/Buttons: grid-column 1/-1.
  • novalidate + Custom-Validation empfohlen.

Accessibility Referenz

<form> mit aria-label oder aria-labelledby. novalidate empfohlen für Custom-Validation. Enter submitted das Formular. Screen Reader: Landmark ‘Formular’.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle enthaltenen Komponenten müssen 4.5:1 Kontrast einhalten.

Pflicht: <form> + aria-label

  • Pflicht: <form> Element mit aria-label oder aria-labelledby.

Wenn: Disabled

  • Empfohlen: aria-disabled="true" auf dem <form> plus disabled auf allen Controls.

Two-Column Layout

  • Tab-Reihenfolge folgt DOM (row-by-row), nicht column-by-column.
  • Fieldsets und Buttons spannen die volle Breite (grid-column: 1 / -1).
