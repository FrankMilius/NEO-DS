NEO Design System

Banner

Prominente systemweite Nachrichten, die als volle Breite am oberen Rand erscheinen. Banner eignen sich für Wartungshinweise, Cookie-Konsent, Feature-Ankündigungen oder kritische Warnungen. Kanonische Klasse: .nc-banner (BEM). Alle Werte kommen aus --nc-banner-* Component-Tokens.

Alle Varianten

4 Varianten: Info, Warning, Danger, Success. Jede als volle Breite mit Icon, Text, Link und Close-Button.

Neue Funktionen verfügbar — Entdecke die neuesten Updates im Dashboard. Mehr erfahren
Geplante Wartung am 28. Februar von 02:00 bis 04:00 Uhr. Details anzeigen
Kritischer Systemfehler — einige Dienste sind derzeit nicht erreichbar. Status-Seite
Migration erfolgreich abgeschlossen. Alle Daten wurden übertragen.

Code

<div class="nc-banner nc-banner--info" role="status">
  <span class="nc-banner__icon" aria-hidden="true">
    <svg>...</svg>
  </span>
  <div class="nc-banner__content">
    <span class="nc-banner__text">Nachricht...</span>
    <a class="nc-banner__link" href="#">Mehr erfahren</a>
  </div>
  <button class="nc-banner__close" aria-label="Banner schließen">
    <svg>...</svg>
  </button>
</div>

Minimal (nur Text)

Banner kann auch ohne Link und ohne Close-Button verwendet werden.

Diese Seite befindet sich im Beta-Stadium.

Sticky Banner

Mit .nc-banner--sticky bleibt das Banner beim Scrollen am oberen Rand fixiert. Diese Variante verwendet position: sticky; top: 0; und einen erhöhten z-index. 

<div class="nc-banner nc-banner--warning nc-banner--sticky" role="status">
  ...
</div>
