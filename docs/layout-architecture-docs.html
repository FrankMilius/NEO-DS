NEO Design System

Layout Architecture

Das NEO Layout Composition System verbindet vier Primitive — Spacing, Grid, Container und Section — zu einem kompositionsbasierten Layoutsystem. Section fungiert als Orchestrator und referenziert die drei anderen Primitive über Presets. Layouts können per extends + overrides abgeleitet werden.

Composition Graph

Die vier Layout-Primitive bilden einen gerichteten Kompositions-Graphen. Jedes Primitiv hat eine klare Verantwortung und referenziert nur Primitive auf tieferen Ebenen.

Schichten-Architektur

SchichtPrimitivCSS-KlasseToken-PräfixVerantwortung
1 (Foundation)Spacing—--fnd-spacing-*13-Stufen-Skala auf 4px-Basegrid, semantische Rollen
2 (Object)Grid.o-grid--nc-grid-*12-Spalten-System, Gaps, Alignment
3 (Object)Container.nc-container--nc-container-*Horizontale Begrenzung, Zentrierung, Fluid Padding
4 (Object)Section.section--nc-section-*Vertikaler Rhythmus, Hintergrund, Orchestrierung

Prinzipien

  • Policy over Mechanism: Section sagt was (compact, spacious, wide), nicht wie (Pixel-Werte).
  • Tokens-First: Alle Layout-Werte sind als CSS Custom Properties konfigurierbar.
  • Komposition über Vererbung: Layouts werden aus Primitiv-Presets zusammengesetzt, nicht durch Klassen-Kaskade.
  • Ableitung per extends: Neue Layouts erben alle Werte eines Basis-Layouts und überschreiben nur Abweichungen.

LayoutSpec

Ein LayoutSpec verbindet die vier Primitive zu einem wiederverwendbaren Layout. Jedes Primitiv wird per ref auf ein Preset gemappt, optionale overrides überschreiben einzelne Token-Werte.

Struktur

{
  "meta": { "id": "layout-marketing", "label": "Marketing", "templateClass": ".t-marketing" },
  "container": { "ref": "container.wide" },
  "grid":      { "ref": "grid.default", "overrides": { "--nc-grid-gap": "var(--nc-grid-gap-lg)" } },
  "spacing":   { "ref": "spacing.section" },
  "section":   { "ref": "section.spacious" }
}

Layouts ableiten mit extends

Neue Layouts werden von bestehenden Basis-Layouts abgeleitet. Das extends-Feld in meta referenziert ein Basis-Layout. Alle Werte des Basis-Layouts werden übernommen — nur Abweichungen müssen angegeben werden.

Beispiel: Wide Docs Layout

{
  "meta": {
    "id": "layout-docs-wide",
    "label": "Documentation Wide",
    "extends": "layout-docs",           // ← erbt alles von layout-docs
    "templateClass": ".t-docs-wide"
  },
  "container": { "ref": "container.wide" },  // ← Änderung: wide statt standard
  "grid":      { "ref": "grid.default" },    // geerbt
  "spacing":   { "ref": "spacing.component" }, // geerbt
  "section":   { "ref": "section.default" }   // geerbt
}

Auflösungskette

layout-docs-wide
  → extends: layout-docs
    → container: container.standard  ← überschrieben mit container.wide
    → grid: grid.default             ← geerbt
    → section: section.default       ← geerbt

Ergebnis:
  classList: ["section", "nc-container", "nc-container--wide", "o-grid", "t-docs-wide"]
  tokens: { "--nc-container-max-width": "1440px", "--nc-grid-gap": "clamp(12px,1.5vw,24px)", ... }

Eigenes Layout erstellen

  1. Wähle ein Basis-Layout: layout-docs, layout-marketing, etc.
  2. Erstelle eine JSON-Datei in data/layout-{name}.json
  3. Setze meta.extends auf die Basis-Layout-ID
  4. Überschreibe nur die Primitive die sich ändern sollen
  5. Optional: overrides für einzelne Token-Werte
  6. Registriere das Layout in useRecipeLoader.js (Theme Configurator)

SDK-Nutzung (JavaScript)

import { loadLayoutSpec, resolveLayoutExtends, layoutSpecToTokens }
  from 'recipe-sdk'

// 1. Extends-Kette auflösen
const registry = { 'layout-docs': docsSpec, 'layout-docs-wide': docsWideSpec }
const resolved = resolveLayoutExtends('layout-docs-wide', registry)

// 2. Presets + Overrides anwenden
const result = loadLayoutSpec(resolved)
console.log(result.classList)  // ["section", "nc-container", "nc-container--wide", "o-grid", "t-docs-wide"]
console.log(result.tokens)     // { "--nc-container-max-width": "1440px", ... }

// 3. CSS-Output generieren
const css = layoutSpecToTokens(result)
// "--nc-container-max-width: 1440px;\n  --nc-grid-gap: clamp(12px, 1.5vw, 24px); ..."
