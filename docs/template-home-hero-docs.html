NEO Design System

Template: Home Hero

Vollbreite Hero-Sektion für die Homepage. Zeichenweise Einlauf-Animation, Highlight-Rotation und optionaler Globe-Effekt. Basisklasse: .home-hero.

Verwendungszweck

Das Home-Hero-Template bildet den ersten sichtbaren Bereich der Homepage (above the fold). Es verbindet eine große typografische Aussage mit einer kontrollierten Einlauf-Animation (.show-Klasse) und einer optionalen Highlight-Rotation für wechselnde Schlagwörter. Der Globe-Effekt (.world) kann für Marken-Storytelling eingesetzt werden.

Animations-Sequenz

Die Animation wird durch JavaScript gesteuert. Klassen werden sequenziell auf .home-hero gesetzt:

KlasseEffekt
.animateGlobe fährt von unten herein (.world-Element)
.showZeichen-Einlauf (.char), Links und Skip-Button sichtbar
.has-paragraphJustiert Globe-Endposition wenn Paragraph vorhanden
.home-hero--visitedAlternativer Zustand für Wiederkehr-Besucher

Layout-Struktur

Das Template hat kein festes CSS-Grid; stattdessen nutzt es flex-column für den Inhalt und positioniert optionale Elemente (.fragment-wrapper, .world) absolut.

.home-hero-wrapper // Hintergrund-Wrapper (background-base) .home-hero // min-height: 100vh - --nav-height; overflow: hidden > div // flex-column (Tool-Mixin) h1 // heading(xl), color: text-low; z-index: 1 .highlights-wrapper // grid-template-areas: highlight .highlights // Wechselnde Textblöcke .char-wrapper .char // transition: transform 300ms ease p // z-index: 1; visibility via .show .button-container // margin-block-start: spacing-08 p.skip-button // abs. pos. auf Tablet+ (left/bottom) .fragment-wrapper // abs. pos. bottom/right; visibility via :has(.show) .world // abs. pos.; opacity: 0 → 1 via .animate .home-hero-bottom // height: 1px; Abstandskorrektur

Zeichen-Splitting und Screenreader

  • Jedes .char-Span enthält einen einzelnen Buchstaben — Screenreader lesen diese fragmentiert vor.
  • Den vollständigen Text zusätzlich in einem .u-sr-only-Element oder via aria-label auf dem <h1> bereitstellen.
  • Alternativ: Alle .char-Spans mit aria-hidden="true" versehen und ein verstecktes <span class="u-sr-only"> mit dem Volltext einfügen.

Animationen und prefers-reduced-motion

  • Alle .char-Transitionen werden via globales @media (prefers-reduced-motion) auf transition-duration: 0.01ms gesetzt.
  • Globe-Transition (1500ms) und Skip-Button-Animation werden ebenfalls unterbunden.
  • JavaScript sollte window.matchMedia('(prefers-reduced-motion: reduce)') prüfen und .show sofort setzen.

Skip-Button

  • p.skip-button enthält einen Link zum Überspringen der Animation („Zum Inhalt springen“).
  • Dieser Link muss das erste fokussierbare Element auf der Seite sein oder direkt nach dem <a class="nc-skip-link"> erscheinen.
  • Ziel-Ankerpunkt (id="content" oder ähnlich) muss im DOM vorhanden sein.
