NEO Design System

Notification

Seitenbreiter Benachrichtigungs-Banner, der am oberen Rand der Seite klebt (position: sticky). Wird eingesetzt für systemweite Hinweise, Wartungsmeldungen oder wichtige Status-Informationen. Kanonische Klasse: .notification. Sichtbarkeit wird über die Zustands-Klasse .show gesteuert. Alle Farb- und Abstandswerte kommen aus Foundation-Tokens --fnd-*.

Live Demo

Wähle Theme und Optionen, um den Notification-Banner live zu konfigurieren. Der Banner erscheint am oberen Rand des Demo-Containers.

Code

<div class="notification show" role="status" aria-live="polite">...</div>

Basis

Der Notification-Banner in seiner einfachsten Form — nur mit Text und einem Close-Button. Die Klasse .show macht den Banner sichtbar.

Wartungsfenster: Am Freitag, 21. Februar, von 22:00 bis 02:00 Uhr steht das System nicht zur Verfügung.

Mit Secondary Action

Ein zusätzlicher Link oder Button (.secondary) direkt nach dem Beschreibungstext ermöglicht eine Handlungsaufforderung, z.B. „Mehr erfahren“ oder „Jetzt aktualisieren“. Auf Desktop erscheint er inline, auf Mobile darunter.

Neue Version verfügbar: Version 3.4 des Design Systems ist jetzt live.

Changelog lesen

Ohne Close-Button

Für Meldungen, die nicht schließbar sein sollen, kann der Close-Button weggelassen werden. Verwendung z.B. bei kritischen Systemhinweisen.

Kritischer Systemfehler: Bitte speichern Sie Ihre Arbeit und laden Sie die Seite neu.

Versteckter Zustand

Ohne die Klasse .show ist der Banner vollständig ausgeblendet (height: 0, opacity: 0, visibility: hidden) und nimmt keinen Platz ein. Er bleibt dabei im DOM und kann per JS jederzeit wieder eingeblendet werden. 

<!-- Banner im DOM, aber nicht sichtbar -->
<div class="notification" role="status" aria-live="polite">
  <div class="notification-body">
    <p>Dieser Banner ist verborgen.</p>
  </div>
</div>

<!-- Banner sichtbar -->
<div class="notification show" role="status" aria-live="polite">
  <div class="notification-body">
    <p>Dieser Banner ist sichtbar.</p>
  </div>
</div>

DOM-Hinweise

  • Floating-Card Surface: surface-elevated BG + elevation-overlay Schatten (L2). Gleiche Ebene wie Popover.
  • role='article' auf jedem Notification-Item. aria-label mit Titel + Zeitstempel.
  • Media-Slot: 48×48 Thumbnail oder Avatar. Optional. Flexibles img/svg/div.
  • Header: Titel (semibold) + Meta-Zeile (Zeitstempel, Kategorie). Auf gleicher Zeile mit space-between.
  • Footer: Action-Links (CTA). Optional. Horizontale Anordnung mit gap.
  • Unread-Dot: 8px Kreis in Akzentfarbe. aria-hidden='true' — Status per aria-label am Root.
  • Unread-BG: Subtiler Akzent-Hintergrund (6% Mix der interaktiven Farbe) bei --unread Modifier.
  • Priority High: 4px Akzent-Border links. Farbe per Type-Variante steuerbar.
  • Type-Varianten setzen Akzentfarbe fuer Unread-Dot UND Priority-Border: feature (blau), system (gelb), promo (gruen).
  • Interaction: 'dismissible' zeigt Close-Button, 'permanent' versteckt ihn.
  • Close-Button: Absolut positioniert oben-rechts. aria-label='Benachrichtigung schliessen'.
  • Dismiss-Animation: max-height + padding + opacity → 0. JS fuegt .is-dismissing hinzu.
  • Shell-Integration: In Notification-Panel (Popover/Drawer) als Liste von .nc-notification Items.
  • Read-Receipt JS: Unread-Status per localStorage oder API. JS entfernt --unread Modifier nach Klick/Lesen.
  • Keyboard: Tab durchlaeuft Header → Actions → Close. Fokus-Ring auf interaktiven Elementen.

Accessibility Referenz

role='article' auf jedem Item. aria-label mit Titel. Unread-Dot ist aria-hidden — Status wird per aria-label am Root kommuniziert. Close: aria-label. Actions: fokussierbar mit focus-ring.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: Spezialbedingung

  • Empfohlen: aria-label-unread
  • Ungelesene Items: aria-label enthaelt 'Ungelesen:' Praefix oder aria-live Region fuer Zaehler-Update.
