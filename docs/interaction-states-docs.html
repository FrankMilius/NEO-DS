NEO Design System

Interaction States

Systematische Zustandsverwaltung für alle interaktiven Komponenten. Farb-Ableitung über color-mix(), Fokus via @include focus-ring, Disabled über --fnd-opacity-disabled.

Vollständige State-Taxonomie

Jede interaktive Komponente im NEO Design System durchläuft definierte Zustände. Die folgende Tabelle zeigt alle 9 States mit zugehörigem CSS-Selektor, Token/Mixin und Anwendungsbereich.

State CSS-Selektor Token / Mixin Gilt für
Default — var(--nc-{component}-*) Alle Komponenten
Hover :hover color-mix() Overlay Interaktive
Active / Pressed :active color-mix() tieferes Overlay Interaktive
Focus :focus-visible @include focus-ring Interaktive
Disabled [disabled], [aria-disabled="true"] opacity: var(--fnd-opacity-disabled) Interaktive
Error .nc-{c}--error, [aria-invalid="true"] --fnd-color-feedback-danger-* Formular
Success .nc-{c}--success --fnd-color-feedback-success-* Formular
Selected [aria-selected="true"], [aria-checked="true"] Komponentenspezifische Tokens Selektierbare
Loading .nc-{c}--loading Spinner + Disabled-State Interaktive

State-Rangfolge (Precedence)

Wenn mehrere Zustände gleichzeitig zutreffen, gewinnt der höherrangige. Die Reihenfolge von höchster zu niedrigster Priorität:

disabled > error > loading > selected > active > hover > focus > default
Wichtig: disabled überschreibt immer alle anderen Zustände. Ein deaktivierter Button zeigt weder Hover- noch Error-Styles. Jeder State muss visuell unterscheidbar sein (WCAG 1.4.11 Non-text Contrast).

Visuelle Indikatoren

Jeder Zustand muss über mindestens einen visuellen Kanal erkennbar sein (Farbe, Form, Icon, Opacity). Sich nur auf Farbe zu verlassen reicht nicht aus (WCAG 1.4.1 Use of Color).

Hover
Abdunklung / Aufhellung via color-mix()
Active
Stärkere Abdunklung + optionale Scale-Transformation
Focus

color-mix() Formeln

Alle Hover- und Active-Zustände werden über color-mix(in srgb, ...) abgeleitet. Das Grundprinzip: Die Basisfarbe wird mit einer Kontrastfarbe gemischt. Im Light Mode wird zum Abdunkeln always-dark verwendet, im Dark Mode zum Aufhellen always-light.

Light Mode

State Formel Mix-Anteil
Hover color-mix(in srgb, var(--base), var(--fnd-color-always-dark) 8%) 8%
Active color-mix(in srgb, var(--base), var(--fnd-color-always-dark) 16%) 16%

Dark Mode

State Formel Mix-Anteil
Hover color-mix(in srgb, var(--base), var(--fnd-color-always-light) 12%) 12%
Active color-mix(in srgb, var(--base), var(--fnd-color-always-light) 20%) 20%
Dark Mode: Hover/Active mischen immer Richtung always-light (nicht always-dark). So bleiben Elemente auf dunklem Hintergrund sichtbar und der Kontrast steigt.

Warum color-mix() statt rgba()?

Das Design System verwendet konsequent color-mix() anstelle von rgba() Overlays.

Do: color-mix(in srgb, ...)
Konsistentes Overlay-Verhalten, kein Alpha-Channel-Stacking, saubere Dark-Mode-Unterstützung.
Don't: rgba(0, 0, 0, 0.08)
Alpha-Channels stapeln sich bei verschachtelten Elementen, unberechenbar im Dark Mode. 
/* Do: color-mix() fuer State-Overlay */
--nc-button-bg-hover: color-mix(
  in srgb,
  var(--nc-button-bg),
  var(--fnd-color-always-dark) 8%
);

/* Don't: rgba() fuer State-Overlay */
--nc-button-bg-hover: rgba(0, 0, 0, 0.08);

Focus Ring Spezifikation

Alle interaktiven Elemente verwenden den focus-ring Mixin aus 01-tools/_mixins-a11y.scss. Die Fokus-Anzeige erscheint nur bei Tastatur-Navigation (:focus-visible), nicht bei Maus-Klicks (:focus).

Eigenschaft Wert Token
Outline-Stil 2px solid —
Outline-Farbe Interaktive Focus-Farbe var(--fnd-color-interactive-focus)
Outline-Offset 2px —
Pseudo-Klasse :focus-visible (nur Tastatur) — 
/* Mixin-Verwendung in Komponenten-SCSS */
.nc-button {
  @include focus-ring;
}

/* Generiertes CSS */
.nc-button:focus-visible {
  outline: 2px solid var(--fnd-color-interactive-focus);
  outline-offset: 2px;
}

Transition-Timing

Alle State-Wechsel verwenden den transition-quick() Mixin mit 150ms ease-out. Der Mixin akzeptiert eine einzelne Sass-Liste als Argument.

Do: Einzelne Sass-Liste als Argument
@include transition-quick((color, background-color, border-color));
Don't: Mehrere Argumente
@include transition-quick(color, background-color, border-color); 
/* Korrekte Verwendung von transition-quick() */
.nc-button {
  @include transition-quick((color, background-color, border-color, box-shadow));
}

/* Generiertes CSS */
.nc-button {
  transition: color 150ms ease-out,
              background-color 150ms ease-out,
              border-color 150ms ease-out,
              box-shadow 150ms ease-out;
}

State-Deklaration in Komponenten

Jede Komponente deklariert ihre unterstützten States und deren Rangfolge über Component Tokens im _component-tokens.scss. 

/* Beispiel: Button Component Tokens */
:root {
  --nc-button-bg:         var(--fnd-color-interactive-default);
  --nc-button-bg-hover:   color-mix(in srgb, var(--nc-button-bg), var(--fnd-color-always-dark) 8%);
  --nc-button-bg-active:  color-mix(in srgb, var(--nc-button-bg), var(--fnd-color-always-dark) 16%);
  --nc-button-color:      var(--fnd-color-text-on-interactive);
}

/* Dark-Mode Override in _component-tokens.scss */
[data-theme="neo-dark-theme"],
.neo-dark-theme {
  --nc-button-bg-hover:  color-mix(in srgb, var(--nc-button-bg), var(--fnd-color-always-light) 12%);
  --nc-button-bg-active: color-mix(in srgb, var(--nc-button-bg), var(--fnd-color-always-light) 20%);
}
