Aspect Ratio

Layout-Primitive für konsistente Seitenverhältnisse bei Bildern, Videos und beliebigen Inhalten. Der Wrapper erzwingt ein festes Ratio — der Inhalt füllt den Container via object-fit: cover. Kanonische Klasse: .nc-aspect-ratio (BEM). Alle Werte kommen aus --nc-aspect-ratio-* Component-Tokens und --fnd-image-ratio-* Foundation-Tokens.

Basis-Verwendung (16:9 Image)

Der Wrapper .nc-aspect-ratio mit dem Modifier .nc-aspect-ratio--16-9 erzwingt ein 16:9-Verhältnis. Das Bild füllt den Container via object-fit: cover. 

<div class="nc-aspect-ratio nc-aspect-ratio--16-9">
  <img class="nc-aspect-ratio__content" src="foto.jpg" alt="Beschreibung" />
</div>

Video Embed (16:9)

Videos und Iframes lassen sich genauso einbetten. Der Modifier bleibt gleich — das Kind-Element erhält .nc-aspect-ratio__content. 

<div class="nc-aspect-ratio nc-aspect-ratio--16-9">
  <video class="nc-aspect-ratio__content" src="video.mp4" muted loop playsinline></video>
</div>

Portrait (9:16)

Hochformat-Verhältnisse wie 9:16 eignen sich für Story-Formate und Mobile-Previews. 

<div class="nc-aspect-ratio nc-aspect-ratio--9-16">
  <img class="nc-aspect-ratio__content" src="portrait.jpg" alt="Beschreibung" />
</div>

Custom Ratio (CSS Override)

Für nicht vordefinierte Verhältnisse kann --nc-aspect-ratio-ratio per Inline-Style überschrieben werden. 

<div class="nc-aspect-ratio" style="--nc-aspect-ratio-ratio: 21 / 9;">
  <img class="nc-aspect-ratio__content" src="ultrawide.jpg" alt="Beschreibung" />
</div>

CSS Custom Properties

Das zentrale Token --nc-aspect-ratio-ratio steuert das Seitenverhältnis. Es wird durch die Ratio-Modifier auf den passenden Foundation-Token gesetzt. Für nicht vordefinierte Ratios kann es per Inline-Style überschrieben werden.

TokenDefaultBeschreibung
--nc-aspect-ratio-ratio var(--fnd-image-ratio-16-9) Aktives Seitenverhältnis. Wird auf aspect-ratio angewendet.

Override-Beispiel

<!-- Inline Override für ein 21:9 Ultrawide-Format -->
<div class="nc-aspect-ratio" style="--nc-aspect-ratio-ratio: 21 / 9;">
  <img class="nc-aspect-ratio__content" src="ultrawide.jpg" alt="..." />
</div>

<!-- Override via eigene CSS-Klasse -->
<style>
  .my-cinema { --nc-aspect-ratio-ratio: 2.35 / 1; }
</style>
<div class="nc-aspect-ratio my-cinema">
  <img class="nc-aspect-ratio__content" src="cinema.jpg" alt="..." />
</div>

Slots / Element-Struktur

Das Element .nc-aspect-ratio__content akzeptiert jedes HTML-Element als Kind: <img>, <video>, <iframe> oder beliebige Block-Elemente. Das Kind-Element wird via object-fit: cover und absoluter Positionierung in den Wrapper eingepasst.

<!-- Bild --> <div class="nc-aspect-ratio [--ratio]"> <img class="nc-aspect-ratio__content" src="..." alt="..." /> </div> <!-- Video --> <div class="nc-aspect-ratio [--ratio]"> <video class="nc-aspect-ratio__content" src="..."></video> </div> <!-- Iframe (z.B. YouTube) --> <div class="nc-aspect-ratio [--ratio]"> <iframe class="nc-aspect-ratio__content" src="..." title="..."></iframe> </div> <!-- Beliebiger Inhalt --> <div class="nc-aspect-ratio [--ratio]"> <div class="nc-aspect-ratio__content"> <p>Beliebiger HTML-Inhalt</p> </div> </div>

Accessibility Referenz

Die AspectRatio-Komponente ist ein reines Layout-Primitive ohne eigene Semantik oder Interaktivität. Sie benötigt keine speziellen ARIA-Attribute — die Accessibility-Anforderungen liegen bei den Kind-Elementen.

Semantik

  • Der Wrapper (.nc-aspect-ratio) ist ein <div> ohne semantische Rolle — ein reines Layout-Element
  • Keine ARIA-Attribute auf dem Wrapper erforderlich
  • Die Semantik wird durch das Kind-Element bestimmt: <img> braucht alt, <video> braucht <track>, <iframe> braucht title
  • Der Wrapper darf nicht mit role="img" oder ähnlichen Rollen versehen werden

Kind-Element-Anforderungen

  • <img> — immer ein aussagekräftiges alt-Attribut setzen (WCAG 1.1.1)
  • <video> — Untertitel via <track kind="captions"> anbieten (WCAG 1.2.2)
  • <iframe> — ein beschreibendes title-Attribut setzen
  • Dekorative Bilder: alt="" (leerer Alt-Text) und optional role="presentation"

Best Practices

<!-- RICHTIG: Bild mit alt-Text --> <div class="nc-aspect-ratio nc-aspect-ratio--16-9"> <img class="nc-aspect-ratio__content" src="hero.jpg" alt="Berglandschaft bei Sonnenuntergang" /> </div> <!-- RICHTIG: Video mit Untertiteln --> <div class="nc-aspect-ratio nc-aspect-ratio--16-9"> <video class="nc-aspect-ratio__content" controls> <source src="video.mp4" type="video/mp4" /> <track kind="captions" src="captions.vtt" srclang="de" label="Deutsch" /> </video> </div> <!-- RICHTIG: Dekoratives Bild --> <div class="nc-aspect-ratio nc-aspect-ratio--4-3"> <img class="nc-aspect-ratio__content" src="pattern.jpg" alt="" role="presentation" /> </div> <!-- FALSCH: Bild ohne alt-Text --> <div class="nc-aspect-ratio nc-aspect-ratio--16-9"> <img class="nc-aspect-ratio__content" src="hero.jpg" /> </div> <!-- Fehlender alt-Text verletzt WCAG 1.1.1 -->

Keyboard

Keine Keyboard-Interaktion nötig

  • Die AspectRatio-Komponente ist nicht interaktiv und wird nicht fokussiert
  • Kind-Elemente wie <video controls> oder <iframe> verwalten ihre eigene Keyboard-Interaktion
  • Kein tabindex auf dem Wrapper setzen
