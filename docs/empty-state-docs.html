NEO Design System

Empty State

Platzhalter-Ansicht für leere Inhalte, fehlende Suchergebnisse oder Erstnutzungs-Szenarien. Der Empty State führt den Benutzer mit Icon, Beschreibung und optionaler Aktion weiter. Kanonische Klasse: .nc-empty-state (BEM). Alle Werte kommen aus --nc-empty-state-* Component-Tokens.

Default Empty State

Standardansicht mit zentriertem Icon, Titel, Beschreibung und optionaler Aktions-Schaltfläche.

Keine Ergebnisse gefunden

Versuche es mit anderen Suchbegriffen oder passe deine Filter an.

Code

<div class="nc-empty-state">
  <div class="nc-empty-state__icon" aria-hidden="true">
    <svg ...></svg>
  </div>
  <h3 class="nc-empty-state__title">Keine Ergebnisse gefunden</h3>
  <p class="nc-empty-state__description">Versuche es mit anderen Suchbegriffen.</p>
  <div class="nc-empty-state__actions">
    <button class="nc-button nc-button--sm">Filter zurücksetzen</button>
  </div>
</div>

Compact

Die .nc-empty-state--compact Variante reduziert Abstände und Icon-Größe für eingebettete Bereiche.

Keine Dateien

Lade eine Datei hoch, um zu beginnen.

Full

Die .nc-empty-state--full Variante nutzt die volle Container-Höhe und zentriert vertikal.

Willkommen!

Erstelle dein erstes Projekt, um loszulegen.

Anwendungsbeispiele

Typische Szenarien: leere Suche, Erstnutzung, Fehlerzustand.

Leere Suche

Keine Ergebnisse

Für «xyz» wurden keine Treffer gefunden. Prüfe die Schreibweise oder verwende einen anderen Begriff.

Erstnutzung

Noch keine Einträge

Erstelle deinen ersten Eintrag, um die Übersicht zu füllen.

Fehlerzustand

Laden fehlgeschlagen

Die Daten konnten nicht geladen werden. Bitte versuche es erneut.
