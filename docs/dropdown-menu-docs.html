NEO Design System

Dropdown Menu

Generisches Action-/Kontextmenü mit Items, Icons, Separators und Gruppen. Kanonische Klasse: .nc-dropdown (BEM). Alle Werte kommen aus --nc-dropdown-* Component-Tokens.

Einfaches Menü

Statisch geöffnetes Dropdown mit einfachen Text-Items.

Items mit Icons

.nc-dropdown__item-icon für ein Leading-Icon in jedem Item.

Danger Item

.nc-dropdown__item--danger für destruktive Aktionen wie "Löschen".

Gruppen & Separatoren

.nc-dropdown__separator und .nc-dropdown__group-label strukturieren das Menü in logische Abschnitte.

Navigation
Einstellungen

Keyboard-Shortcuts in Items

.nc-dropdown__item-shortcut zeigt Tastenkombinationen rechts im Item an.

Disabled Items

Items mit disabled oder aria-disabled="true".

HTML-Struktur

Vollständiges Dropdown

<div class="nc-dropdown">
  <button class="nc-dropdown__trigger nc-button"
          aria-haspopup="true" aria-expanded="false">
    Aktionen
  </button>
  <div class="nc-dropdown__menu nc-dropdown__menu--bottom-start"
       role="menu" hidden>
    <span class="nc-dropdown__group-label">Bearbeitung</span>
    <button class="nc-dropdown__item" role="menuitem">
      <span class="nc-dropdown__item-icon"><svg>…</svg></span>
      <span class="nc-dropdown__item-label">Bearbeiten</span>
      <span class="nc-dropdown__item-shortcut">⌘E</span>
    </button>
    <button class="nc-dropdown__item" role="menuitem">
      <span class="nc-dropdown__item-label">Duplizieren</span>
    </button>
    <hr class="nc-dropdown__separator" />
    <button class="nc-dropdown__item nc-dropdown__item--danger"
            role="menuitem">
      <span class="nc-dropdown__item-icon"><svg>…</svg></span>
      <span class="nc-dropdown__item-label">Löschen</span>
    </button>
  </div>
</div>

Accessibility

RegelBeschreibung
R1Trigger: aria-haspopup="true" + aria-expanded
R2Menu: role="menu"
R3Items: role="menuitem"
R4Keyboard: Arrow Up/Down navigiert, Enter/Space aktiviert, Escape schließt
R5Focus-Management: Erstes Item erhält Focus beim Öffnen
