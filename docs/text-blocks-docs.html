NEO Design System

Text Blocks

Wiederverwendbare Text-Primitive für Section-Titles, Eyebrows und Lead-Paragraphen. Drei Klassen: .nc-section-title, .nc-eyebrow, .nc-lead. Alle Farben und Abstände kommen aus Foundation-Tokens. Typischerweise verwendet in Hero-Sektionen, Abschnittsköpfen und Marketing-Layouts.

Type Scale

nc-section-title und nc-lead skalieren über die --type-scale Custom Property. Der Standardwert ist 1. Ein übergeordnetes Element kann diesen Wert überschreiben.

Accessibility Referenz

Text-Block-Klassen sind rein visuelle Styles — die semantische Bedeutung muss durch das HTML-Element selbst gegeben werden.

Heading-Hierarchie

  • .nc-section-title soll auf einem semantisch korrekten Heading-Element stehen (<h2>, <h3> etc.)
  • Nie <h1> für Abschnittsköpfe verwenden — <h1> ist der Seitentitel
  • Die visuelle Erscheinung der Klasse ist unabhängig vom semantischen Level — das Heading-Level richtig wählen, auch wenn das visuelle Design abweicht

Eyebrow-Semantik

  • .nc-eyebrow ist visuell über dem Titel, ist aber kein Heading
  • Als <p> implementieren — Screenreader lesen es in der DOM-Reihenfolge
  • Der Eyebrow-Text sollte immer sichtbar und kurz sein — kein rein dekorativer Text

Farbkontrast (WCAG 1.4.3)

  • --fnd-color-text-secondary (Eyebrow, Lead) erfüllt WCAG AA in allen Themes
  • Section-Title erbt Farbe vom Kontext — sicherstellen, dass der Kontext ausreichend Kontrast bietet
  • Großer Text (≥ 18pt / 24px) benötigt nur 3:1 Kontrast (WCAG AA Large)
