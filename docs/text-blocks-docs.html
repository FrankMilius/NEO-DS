NEO Design System

Text Blocks

Wiederverwendbare Text-Primitive für Section-Titles, Eyebrows und Lead-Paragraphen. Drei Klassen: .nc-section-title, .nc-eyebrow, .nc-lead. Alle Farben und Abstände kommen aus Foundation-Tokens. Typischerweise verwendet in Hero-Sektionen, Abschnittsköpfen und Marketing-Layouts.

Live Demo

Wähle Theme, um die Text-Blöcke in verschiedenen Themes zu sehen.

Code

<p class="nc-eyebrow">Produkt</p>
<h2 class="nc-section-title">Abschnittsüberschrift</h2>
<p class="nc-lead">Eine Einleitung, die den Abschnitt eröffnet und die wichtigsten Punkte zusammenfasst.</p>

Einzelne Elemente

nc-eyebrow

Overline / Kicker — Uppercase, tracked, sekundte Textfarbe. Steht üblicherweise über der Haupttitel.

Neue Funktion

nc-section-title

Section-Titel — Große Heading-Schrift, Heading-Font-Family, großer unterer Abstand. Skaliert über --type-scale Custom Property.

Unsere Vision für modernes Lernen

nc-lead

Lead-Paragraph — Etwas größere Schrift, sekundäre Textfarbe, begrenzte Zeilenbreite (56ch).

NEOCOSMO entwickelt innovative Lösungen für digitales Lernen und Wissensmanagement. Unsere Plattform unterstützt Unternehmen dabei, das Potenzial ihrer Mitarbeiter voll auszuschöpfen.

Kombinierte Verwendung

Alle drei Text-Blöcke zusammen — typisches Abschnittskönig-Pattern.

Lernen neu gedacht

Mit unserer integrierten Lösung verbinden Sie Lernen, Wissen und Zusammenarbeit auf einer einzigen Plattform. Flexibel, skalierbar und auf Ihre Bedürfnisse zugeschnitten.

Type Scale

nc-section-title und nc-lead skalieren über die --type-scale Custom Property. Der Standardwert ist 1. Ein übergeordnetes Element kann diesen Wert überschreiben.

DOM-Hinweise

  • Text-Primitives: Section-Title (.nc-section-title), Eyebrow (.nc-eyebrow), Lead (.nc-lead).
  • Section-Title: font-heading, fs-3xl, margin-bottom 4rem.
  • Eyebrow: uppercase, fs-xs, letter-spacing 0.2em, text-secondary.
  • Lead: fs-lg, text-secondary, max-width 56ch.

Accessibility Referenz

Semantisches HTML: Section-Title als H2/H3, Eyebrow als span/p, Lead als p.
