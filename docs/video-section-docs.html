NEO Design System

Video Section

Zweispaltiges Layout mit Video-Player (links) und Begleit-Content (rechts). Der Video-Bereich zeigt eine Play-Overlay-Schaltfläche mit animiertem Icon und wechselt bei Wiedergabe in den .is-playing-Zustand. Kanonische Klasse: .nc-video (BEM).

Live Demo

Zweispaltiges Layout: links das Video-Medium mit Play-Overlay, rechts der Begleit-Content. Das Overlay verschwindet bei Zustand .is-playing auf dem Media-Container.

So funktioniert unsere Plattform

In diesem kurzen Video zeigen wir Ihnen, wie Sie in wenigen Minuten starten können und sofort produktiv werden.

Code

<div class="nc-video">
  <div class="nc-video__media">
    <video src="..." poster="..."></video>
    <button class="nc-video__overlay" aria-label="Video abspielen">
      <span class="nc-video__overlay-icon" aria-hidden="true"></span>
    </button>
  </div>
  <div class="nc-video__content">
    <h2 class="nc-video__title">...</h2>
    <p class="nc-video__text">...</p>
  </div>
</div>

Overlay-Zustände

Das Overlay blendet sich aus, wenn .is-playing auf .nc-video__media gesetzt wird.

Overlay sichtbar (Standard)

Overlay ausgeblendet (.is-playing)

Mit nativen Video-Element

Statt eines Vorschaubilds (<img>) kann ein natives <video>-Element eingesetzt werden.

<div class="nc-video__media"> <video src="/pfad/zum/video.mp4" poster="/pfad/zum/poster.jpg" preload="metadata" playsinline ></video> <button class="nc-video__overlay" aria-label="Video abspielen"> <span class="nc-video__overlay-icon" aria-hidden="true"></span> </button> </div>

DOM-Hinweise

  • 2-Spalten Grid: media + content, gap 4rem. Single-Column unter 900px.
  • Media: 16:9 aspect-ratio, always-dark BG, radius-sm, overflow hidden.
  • Play-Overlay: Gradient-Overlay, 72×72 runder Button mit Play-Triangle.
  • is-playing: Overlay ausblenden (opacity 0, pointer-events none).

Accessibility Referenz

Play-Button: role button, aria-label. Video: captions. always-light Text auf dark BG Kontrast. Overlay-Icon: 3:1 gegen Gradient.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.
