NEO Design System

Form Actions

Action-Bar für Formular-Buttons (Submit, Cancel, Reset). Positioniert Buttons am Ende eines Formulars mit verschiedenen Ausrichtungs- und Layout-Optionen. Kanonische Klasse: .nc-form-actions (BEM). Alle Werte kommen aus --nc-form-actions-* Component-Tokens.

Verwendung

Die Form-Actions-Bar positioniert Formular-Buttons konsistent. Primary Action (Submit) steht immer an erster Stelle im DOM.

Rechts ausgerichtet (Standard)

<div class="nc-form-actions nc-form-actions--end" role="group" aria-label="Formular-Aktionen">
  <button class="nc-button nc-button--primary" type="submit">Speichern</button>
  <button class="nc-button nc-button--secondary" type="button">Abbrechen</button>
</div>

Ausrichtungs-Varianten

<div class="nc-form-actions nc-form-actions--start">...</div>   <!-- Links -->
<div class="nc-form-actions nc-form-actions--center">...</div>  <!-- Zentriert -->
<div class="nc-form-actions nc-form-actions--end">...</div>     <!-- Rechts -->
<div class="nc-form-actions nc-form-actions--spread">...</div>  <!-- Space-between -->

Spread (Cancel links, Submit rechts)

<div class="nc-form-actions nc-form-actions--spread nc-form-actions--bordered"
     role="group" aria-label="Formular-Aktionen">
  <button class="nc-button nc-button--primary" type="submit">Speichern</button>
  <button class="nc-button nc-button--ghost" type="button">Abbrechen</button>
</div>

Sticky (haftet am unteren Rand)

Für lange Formulare: Buttons bleiben am unteren Viewport-Rand sichtbar.

<div class="nc-form-actions nc-form-actions--end nc-form-actions--sticky">
  <button class="nc-button nc-button--primary" type="submit">Speichern</button>
</div>

Stacked (Mobile)

Vertikal gestapelt mit voller Breite. Auch automatisch via --responsive.

<div class="nc-form-actions nc-form-actions--stacked">
  <button class="nc-button nc-button--primary" type="submit">Speichern</button>
  <button class="nc-button nc-button--secondary" type="button">Abbrechen</button>
</div>

<!-- Oder: automatisch stacked unter 479px -->
<div class="nc-form-actions nc-form-actions--end nc-form-actions--responsive">...</div>

Mit Trennlinie (Bordered)

<div class="nc-form-actions nc-form-actions--end nc-form-actions--bordered">
  <button class="nc-button nc-button--primary" type="submit">Speichern</button>
</div>

DOM-Hinweise

  • Flex-Container mit flex-wrap für Umbruch bei Platzmangel.
  • Primary Action (Submit) an erster Stelle im DOM.
  • Sticky: position: sticky; bottom: 0 mit BG + Shadow + border-top.
  • Stacked: Buttons volle Breite, mindestens 44px Touch-Target.

Accessibility Referenz

role="group" mit aria-label="Formular-Aktionen". Primary Action an erster Stelle im DOM. Buttons haben eigene A11y.

Farbkontrast: WCAG AA non-text (3:1)

  • Buttons müssen eigene Kontrastanforderungen erfüllen.

Pflicht: role="group" + aria-label

  • Pflicht: Container: role="group" + aria-label="Formular-Aktionen".
  • Primary Action (Submit) an erster Stelle im DOM — Screen Reader liest Submit zuerst.

Stacked / Mobile

  • Buttons volle Breite, mindestens 44px Höhe (Touch-Target).
  • Primary Action oben.
