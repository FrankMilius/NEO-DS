Accessibility Referenz

Select-Komponenten nutzen das native <select>-Element und müssen die WCAG 2.1 AA-Kriterien erfüllen.

Label-Zuordnung

  • Jedes Select muss ein zugehöriges <label>-Element haben
  • Das for-Attribut des Labels muss auf die id des Selects verweisen
  • Alternativ kann das Select innerhalb des Labels platziert werden (implizite Zuordnung)
  • Kein Select ohne sichtbares Label verwenden — aria-label nur als Notlösung

Tastaturnavigation

  • Tab fokussiert das Select-Element
  • Space / Enter öffnet das Dropdown
  • ↑ / ↓ navigiert durch die Optionen
  • Escape schließt das Dropdown
  • Bei multiple: Shift + Klick für Bereichsauswahl, Ctrl/Cmd + Klick für Einzeltoggle

Fehlerbehandlung

  • Bei .nc-select--error zusätzlich aria-invalid="true" setzen
  • Fehlermeldung mit aria-describedby verknüpfen
  • Farbe nie als alleiniges Signal verwenden — immer einen Fehlertext bereitstellen (WCAG 1.4.1)
  • Bei .nc-select--success optional aria-describedby für Erfolgsmeldung

Farbkontrast (WCAG 1.4.3)

  • Select-Text muss mindestens 4.5:1 Kontrast zum Hintergrund haben
  • Der Dropdown-Pfeil muss mindestens 3:1 Kontrast haben (UI-Komponente)
  • Rahmenfarben müssen 3:1 Kontrast zum Hintergrund erfüllen
  • Disabled-State ist von den Kontrastanforderungen ausgenommen (WCAG 1.4.3)
