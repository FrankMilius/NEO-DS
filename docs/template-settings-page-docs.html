NEO Design System

Template: Settings Page

Einstellungsseite mit seitlicher Navigationsleiste und gestapelten Inhalts-Sektionen. Navigation ist auf Tablet+ sticky; auf Mobile horizontal scrollend. Basisklasse: .t-settings.

Verwendungszweck

Das Settings-Page-Template ist für Benutzereinstellungen, Account-Verwaltung und Konfigurationsseiten optimiert. Die vertikale Navigationsleiste (220px) bleibt auf Tablet+ sticky und ermöglicht direktes Springen zu Abschnitten innerhalb der Seite. Jede Setting-Row zeigt Titel, optionale Beschreibung und ein Aktionselement (Toggle, Button, Select).

Setting-Row: Aktion und Label verbinden

  • Das Aktions-Element (.t-settings__row-action) muss mit .t-settings__row-title verbunden sein.
  • Toggle-Buttons: aria-label="E-Mail-Benachrichtigungen aktivieren" oder aria-labelledby auf den Row-Titel.
  • Button „Bearbeiten“: aria-label="Anzeigename bearbeiten" für eindeutigen Kontext.
  • .t-settings__row-description via aria-describedby mit dem Toggle/Button verbinden.

Toggle-Switches

  • Toggle-Switches müssen entweder als <input type="checkbox"> mit passendem <label> oder als <button role="switch" aria-checked="true/false"> implementiert werden.
  • Rein visuell dargestellte Toggles (wie in der Vorschau) sind für Screenreader nicht verwendbar.
  • Der Toggle-Zustand muss auch in der Row-Beschriftung kommuniziert werden („Derzeit aktiviert“).

Mobile Navigation

  • Die horizontale Nav-Leiste auf Mobile (overflow-x: auto) ist per Tastatur scrollbar — sicherstellen, dass keine Elemente durch overflow: hidden verdeckt werden.
  • white-space: nowrap auf den Links verhindert Umbruch; Kontrast auch im gescrollten Bereich gewährleisten.
