NEO Design System

Opacity, Z-Index & Motion

Foundation-Tokens fuer zustandsbasierte Transparenz, globale Stacking-Hierarchie und konsistente Ein-/Ausblend-Animationen. Alle Motion-Keyframes respektieren prefers-reduced-motion.

Opacity

Zustandsbasierte Transparenz-Tokens fuer konsistente Interaktions-Darstellung. Verwende immer Tokens statt hardcoded Werte.

--fnd-opacity-disabled
0.5
Fuer deaktivierte Elemente
--fnd-opacity-hover
0.08
Hover-Overlay-Staerke
--fnd-opacity-focus
0.12
Focus-Overlay-Staerke
--fnd-opacity-pressed
0.12
Pressed/Active-Overlay
--fnd-opacity-dragged
0.16
Drag-Overlay-Staerke
/* Do: Opacity-Token verwenden */
opacity: var(--fnd-opacity-disabled);

/* Don't: Hardcoded Opacity */
opacity: 0.5;

Z-Index

Globale Stacking-Hierarchie mit 10 Stufen. Lokale Stacking-Contexts (z.B. z-index: 1 innerhalb einer Komponente) brauchen keine Foundation-Tokens.

--fnd-z-base
1
--fnd-z-dropdown
2
--fnd-z-sticky
3
--fnd-z-fixed
9
--fnd-z-header
100
--fnd-z-sidebar
200
--fnd-z-drawer
300
--fnd-z-notification
400
--fnd-z-toast
500
--fnd-z-skip-link
9999
/* Do: Z-Index Token verwenden */
z-index: var(--fnd-z-drawer);

/* Don't: Hardcoded z-index */
z-index: 300;

Motion / Keyframes

Foundation-Keyframes fuer konsistente Ein-/Ausblend-Animationen. Alle respektieren prefers-reduced-motion — bei aktivierter Einstellung werden Animationen automatisch unterdrueckt.

fnd-fade-in / fnd-fade-out
Opacity 0 → 1 / 1 → 0
fnd-slide-up / down / left / right
8px translate + fade
fnd-scale-in / fnd-scale-out
Scale 0.95 → 1 + fade
fnd-spin
360-Grad-Rotation (Spinner)
fnd-dialog-enter / exit
Scale + fade + translateY(4px)
fnd-dropdown-enter
Slide down + fade
fnd-toast-enter
Slide up 16px + fade
Do: animation: fnd-dialog-enter 0.2s var(--fnd-motion-ease-focused) forwards;
