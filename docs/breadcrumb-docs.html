Breadcrumb

Semantische Breadcrumb-Navigation mit <nav> + <ol> für hierarchische Seitenstrukturen. Kanonische Klasse: .nc-breadcrumb (BEM). Alle Werte kommen aus --nc-breadcrumb-* Component-Tokens.

Accessibility Referenz

Breadcrumb-Navigation muss die WCAG 2.1 AA-Kriterien erfüllen. Semantisches HTML (<nav> + <ol>) ist entscheidend für Screenreader.

nav + aria-label

  • Die Breadcrumb muss in ein <nav aria-label="Breadcrumb"> eingebettet sein
  • Das aria-label identifiziert die Navigation für Screenreader
  • Nur ein Breadcrumb-<nav> pro Seite verwenden

Geordnete Liste

  • Eine <ol> (ordered list) vermittelt die hierarchische Reihenfolge der Seiten
  • Screenreader kündigen die Anzahl der Items und deren Position an (z.B. “Item 2 von 4”)
  • Niemals <div> oder <ul> verwenden — die Reihenfolge ist semantisch relevant

aria-current="page"

  • Das letzte Item der Breadcrumb kennzeichnet die aktuelle Seite
  • Das Attribut aria-current="page" auf einem <span> (nicht <a>) setzen
  • Die aktuelle Seite soll nicht verlinkt sein — Nutzer sind bereits dort

Separator aria-hidden

  • Separatoren (Chevrons, Slashes) sind rein dekorativ
  • Immer aria-hidden="true" setzen, damit Screenreader sie überspringen
  • Die semantische Reihenfolge wird bereits durch die <ol>-Struktur vermittelt

Ellipsis-Button

  • Der Ellipsis-Button muss ein <button>-Element sein
  • Ein beschreibendes aria-label="Weitere Seiten anzeigen" ist Pflicht
  • Das visuelle “…”-Icon allein ist nicht ausreichend für Screenreader
  • Der Button wird per Tab, Enter oder Space aktiviert
