NEO Design System

Navigation Menu

shadcn-inspiriertes NavigationMenu mit Viewport-Pattern, Chevron-Trigger, Callout-Bereich und Content-Animationen. Kanonische Klasse: .nc-navigation-menu (BEM). Alle Werte kommen aus internen --_nav-menu-* Component-Tokens.

Live Demo

Hover über die Trigger-Buttons, um die Dropdown-Panels mit Callout und Links zu sehen. Klick auf direkte Links zeigt den aktiven Zustand.

Variante

Code

<nav class="nc-navigation-menu">...</nav>

Default Navigation Menu

Zwei Dropdown-Trigger (Produkte, Services) mit Two-Column Callout-Layout und drei direkte Links.

Simple Navigation Menu

Nur direkte Top-Level-Links, ohne Dropdowns. Für einfache Navigationsstrukturen.

Komponenten-Struktur

Die NavigationMenu-Komponente folgt dem shadcn/Radix-UI Composition-Pattern.

<nav class="nc-navigation-menu"> <ul class="nc-navigation-menu__list" role="menubar"> <!-- Item mit Dropdown --> <li class="nc-navigation-menu__item" role="none"> <button class="nc-navigation-menu__trigger" role="menuitem" aria-haspopup="true" aria-expanded="false" data-state="closed"> <span>Produkte</span> <span class="nc-navigation-menu__trigger-icon"> <svg viewBox="0 0 12 12"> <polyline points="2 4 6 8 10 4"/> </svg> </span> </button> <div class="nc-navigation-menu__content nc-navigation-menu__content--two-col" data-state="closed" role="menu"> <div class="nc-navigation-menu__content-grid"> <a class="nc-navigation-menu__callout" href="#"> <div class="nc-navigation-menu__callout-title">Produkte</div> <p class="nc-navigation-menu__callout-desc">Beschreibung</p> </a> <div class="nc-navigation-menu__content-grid"> <a class="nc-navigation-menu__link" href="#" role="menuitem"> <div class="nc-navigation-menu__link-title">Feature A</div> <p class="nc-navigation-menu__link-desc">Beschreibung</p> </a> </div> </div> </div> </li> <!-- Direkter Link --> <li class="nc-navigation-menu__item" role="none"> <a class="nc-navigation-menu__link--top" href="#" role="menuitem">Kunden</a> </li> </ul> <!-- Indicator --> <div class="nc-navigation-menu__indicator" data-state="hidden"> <div class="nc-navigation-menu__indicator-arrow"></div> </div> <!-- Viewport --> <div class="nc-navigation-menu__viewport-wrapper"> <div class="nc-navigation-menu__viewport" data-state="closed"> <!-- Content wird hier dynamisch eingefügt --> </div> </div> </nav>

Keyboard-Navigation

EscapeGeöffnetes Dropdown schließen, Fokus zurück zum Trigger

Motion & Reduced Motion

Die Komponente wird auf Screens unter 1200px ausgeblendet (display: none) und durch das Mobile-Panel ersetzt. Animationen nutzen CSS transition und @keyframes, die via prefers-reduced-motion deaktiviert werden können.
