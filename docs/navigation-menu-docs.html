NEO Design System

Navigation Menu

shadcn-inspiriertes NavigationMenu mit Viewport-Pattern, Chevron-Trigger, Callout-Bereich und Content-Animationen. Kanonische Klasse: .nc-navigation-menu (BEM). Alle Werte kommen aus internen --_nav-menu-* Component-Tokens.

Live Demo

Hover über die Trigger-Buttons, um die Dropdown-Panels mit Callout und Links zu sehen. Klick auf direkte Links zeigt den aktiven Zustand.

Variante

Code

<nav class="nc-navigation-menu">...</nav>

Default Navigation Menu

Zwei Dropdown-Trigger (Produkte, Services) mit Two-Column Callout-Layout und drei direkte Links.

Simple Navigation Menu

Nur direkte Top-Level-Links, ohne Dropdowns. Für einfache Navigationsstrukturen.

DOM-Hinweise

  • Radix-UI Pattern: nav > ul > li > trigger/content.
  • Data-Attributes: [data-state=open|closed] auf Trigger/Content, [data-active] auf Links.
  • Viewport: animierter Container fuer Dropdown-Inhalte, teilt Tokens mit Popover.
  • Indicator: 2px Unterstrich-Balken mit layout-transition (sanftes Hergleiten statt Springen).
  • Mega-Menu: --mega Modifier, Grid mit konfigurierbaren Spalten (default 2).
  • Featured Item: Grafischer Highlight-Slot, volle Breite im Grid (grid-column: 1 / -1).
  • Callout: Highlight-Bereich im Mega-Menu (linke Spalte, Gradient-BG).
  • Trigger-Mode: data-trigger='hover' (Desktop) vs 'click' (Touch/komplexe Menus).

Accessibility Referenz

nav mit aria-label. Trigger: aria-expanded, aria-haspopup. Keyboard: Arrow-Keys, Escape, Tab. Focus-Ring auf allen interaktiven Elementen.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: trigger = hover

  • Empfohlen: hover-delay
  • Hover: Leichte Verzoegerung (150ms) beim Oeffnen um versehentliches Triggern zu vermeiden.
