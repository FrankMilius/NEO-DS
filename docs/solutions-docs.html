NEO Design System

Solutions

Solutions-Sektion mit Accordion, Side-Content und mobiler Tab-Navigation. Auf Desktop: dreispaltiges Grid (Accordion | Gutter | Side). Auf Mobile: horizontales Scroll-Accordion mit Snap-Verhalten und Tab-Leiste. Kanonische Klasse: .solutions. Wrapper: .solutions-wrapper.

Strukturübersicht

Die Solutions-Komponente ist ein komplexes Desktop/Mobile-adaptives Layout. Auf dem Desktop zeigt ein dreispaltiges Grid den Accordion links und Side-Content rechts. Auf Mobile werden die Accordion-Items horizontal gescrollt, begleitet von einer Tab-Leiste.

Schema: Desktop-Layout

.accordion (accordion--solutions)

Accordion-Items mit Fortschrittsanzeige

>:nth-child(1) [side]

Gestapelte Side-Panels (grid-area: 1/1)

Schema: Mobile-Layout

.solutions-wrapper > div:first-child

Mobile Tab-Leiste (48px, horizontal scrollbar)

.accordion--solutions

Horizontal gescrollt (scroll-snap, 100% Breite pro Item)

Code

<div class="solutions-wrapper">
  <!-- Mobile Tab-Leiste -->
  <div>
    <ul><li class="selected"><span>Tab 1</span></li></ul>
  </div>

  <!-- Solutions-Container -->
  <div class="solutions">
    <!-- 1. Kind = Side-Panel -->
    <div> ... </div>

    <!-- Accordion -->
    <div class="accordion accordion--solutions">
      <details class="accordion-item">...</details>
    </div>

    <!-- Letztes Kind = Content-Panel -->
    <div> ... </div>
  </div>
</div>

Accordion-Item (Desktop)

Auf dem Desktop zeigt das Accordion eine schmale Titelzeile (h2). Das geöffnete Item hebt den Titel mit primärer Textfarbe hervor. Die Inhalte (.accordion-item-content) sind auf Desktop ausgeblendet, da der Side-Content separat angezeigt wird. Ein Fortschrittsbalken (.accordion-progress) zeigt die aktive Auswahl.

<!-- Accordion-Item Struktur --> <details class="accordion-item" open> <summary class="accordion-item-summary"> <!-- Mobile: Sichtbar --> <!-- Desktop: Summary-Icon ausgeblendet (.accordion-item-summary-icon display:none) --> </summary> <h2>Lösungs-Titel</h2> <p>Kurzbeschreibung (auf Desktop ausgeblendet)</p> <div class="accordion-item-content"> <!-- Auf Desktop nicht sichtbar, nur Mobile --> <p>Detail-Text</p> </div> <div class="accordion-progress"></div> </details>

Labels & Button-Container

Innerhalb der .solutions-Sektion können Label-Gruppen (.labels-container) und Buttons (.button-container) eingesetzt werden, die spezifisches Spacing erhalten.

<div class="labels-container"> <span class="label">Tag 1</span> <span class="label">Tag 2</span> </div> <div class="button-container"> <button class="button button--primary">Mehr erfahren</button> </div>

DOM-Hinweise

  • Desktop: 3-Spalten Grid (6+1+5) mit grid-areas accordion/side/content.
  • Mobile: Horizontal-Scroll Accordion mit scroll-snap, Tabs oben.
  • Accordion-Items: Details/Summary, progress-bar Animation (12s linear).
  • Side/Content Panels: nur Desktop sichtbar, grid-area overlay.

Accessibility Referenz

Accordion: details/summary nativ. Mobile Tabs: scroll-snap, selected-Indicator. Progress-Animation: reduced-motion.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.
