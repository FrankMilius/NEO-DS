Stepper

Numerischer Stepper mit Increment/Decrement-Buttons für präzise Zahleneingabe. Kanonische Klasse: .nc-stepper (BEM). Alle Werte kommen aus --nc-stepper-* und --nc-input-* Component-Tokens.

Live Demo

Wähle Theme, Größe und Zustand, um den Stepper live zu konfigurieren.

Größe

Code

<div class="nc-stepper" role="group" aria-label="Menge">
  <button class="nc-stepper__decrement" type="button" aria-label="Wert verringern">
    <svg><!-- minus icon --></svg>
  </button>
  <input class="nc-stepper__input" type="number" value="1"
         min="0" max="99" aria-label="Menge"
         aria-valuenow="1" aria-valuemin="0" aria-valuemax="99" readonly />
  <button class="nc-stepper__increment" type="button" aria-label="Wert erhöhen">
    <svg><!-- plus icon --></svg>
  </button>
</div>

DOM-Hinweise

  • Inline-Flex Container: Decrement-Button | Input | Increment-Button.
  • Nahtlose Borders: Input hat margin-inline: -1px, decrement hat rechte Ecken 0, increment hat linke Ecken 0.
  • Buttons: quadratisch (32px default), SVG-Icons (50% der Button-Groesse).
  • Input: zentrierter Text, Spinner-Arrows entfernt, readonly optional.
  • Border kommt von shared --nc-input-* Tokens (border-width, border-color).
  • Hover: bg-hover + border-hover auf den Buttons.
  • Focus: focus-ring + border-focus. Input bekommt z-index: base bei Focus (ueberlappt Buttons).
  • Error: Alle drei Teile erhalten border-error Farbe.
  • Disabled: Alle Teile ausgegraut — opacity, disabled-bg, disabled-border.
  • SM/LG: Nutzen Input-Height-Tokens fuer konsistente Hoehe mit anderen Form-Controls.

Accessibility Referenz

Buttons: aria-label='Wert verringern' / 'Wert erhoehen'. Input: role='spinbutton' (nativ bei type='number'), aria-valuenow, aria-valuemin, aria-valuemax. Keyboard: ArrowUp/ArrowDown auf dem Input (JS). Buttons am Min/Max: aria-disabled='true'.

Farbkontrast: WCAG AA non-text (3:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: validation = error

  • Empfohlen: aria-invalid
  • Empfohlen: aria-describedby
  • Error: aria-invalid='true' auf dem Input. Fehlermeldung via aria-describedby.

Wenn: Spezialbedingung

  • Empfohlen: aria-disabled
  • Disabled: disabled-Attribut auf Input und Buttons. Oder aria-disabled='true' auf dem Container.
