Stepper

Numerischer Stepper mit Increment/Decrement-Buttons für präzise Zahleneingabe. Kanonische Klasse: .nc-stepper (BEM). Alle Werte kommen aus --nc-stepper-* und --nc-input-* Component-Tokens.

Live Demo

Wähle Theme, Größe und Zustand, um den Stepper live zu konfigurieren.

Größe

Code

<div class="nc-stepper" role="group" aria-label="Menge">
  <button class="nc-stepper__decrement" type="button" aria-label="Wert verringern">
    <svg><!-- minus icon --></svg>
  </button>
  <input class="nc-stepper__input" type="number" value="1"
         min="0" max="99" aria-label="Menge"
         aria-valuenow="1" aria-valuemin="0" aria-valuemax="99" readonly />
  <button class="nc-stepper__increment" type="button" aria-label="Wert erhöhen">
    <svg><!-- plus icon --></svg>
  </button>
</div>

Accessibility Referenz

Der Stepper ist ein Spinbutton-Widget nach ARIA-Muster. Alle drei Teile müssen vollständig per Tastatur bedienbar und für Screenreader verständlich sein.

Tastatur-Bedienung

  • Tab: Fokus auf Decrement-Button, dann Input, dann Increment-Button
  • Space / Enter: Aktiviert den fokussierten Button
  • ArrowUp / ArrowDown: Auf dem Input den Wert erhöhen/verringern (JS-seitig implementieren)
  • Fokus-Ring muss an allen drei Teilen sichtbar sein (WCAG 2.4.7)

ARIA-Attribute

  • Container: role="group" + aria-label="Menge" (oder passender Label)
  • Input: aria-valuenow, aria-valuemin, aria-valuemax immer aktuell halten
  • Buttons: aria-label="Wert verringern" / aria-label="Wert erhöhen"
  • Error-State: aria-invalid="true" auf dem Input
  • Disabled: disabled-Attribut auf Buttons und Input (kein reines CSS-Disabled)

Screenreader-Verhalten

  • Screenreader lesen den Input als Spinbutton: “Menge, Drehfeld, 1, Minimum 0, Maximum 99”
  • Nach Wertänderung sollte aria-valuenow per JS aktualisiert werden
  • Readonly-Input: verhindert manuelle Texteingabe, erlaubt aber programmatische Änderungen via JS
