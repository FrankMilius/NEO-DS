Item

Listenelement<li> in <ul>Mit .nc-item-group als <ul>

Empfehlungen

  • Verwende <a> für navigierbare Items, <button> für Aktionen.
  • Bei .nc-item-group als <ul>/<li> rendern für Screenreader.
  • Farbe nie als einziges Unterscheidungsmerkmal verwenden — immer mit Text/Icon kombinieren.
  • Truncated Titles mit title-Attribut oder aria-label ergänzen.
  • Focus-Ring wird automatisch über :focus-visible angezeigt.
