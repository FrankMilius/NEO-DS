NEO Design System

Byline

Autorenzeile eines Artikels: rundes Foto oder Initialen, Name, darunter Lesezeit und Datum mit Trennpunkt. Das Foto ist der vorhandene Avatar. Kein „Folgen“-Knopf. Kanonische Klasse: .nc-byline, Variante .nc-byline--sm für Karten.

Regeln

  • Das Foto ist ein .nc-avatar mit .nc-byline__photo; die Größe setzt die Byline über --mod-avatar-size-md aus --nc-byline-photo-size.
  • Bild mit alt="", Initialen mit aria-hidden="true" – der Name steht als Text daneben und wird einmal vorgelesen.
  • Lesezeit und Datum in .nc-byline__meta, das Datum als <time datetime>. Der Punkt dazwischen kommt aus CSS und hat einen leeren Alternativtext.
  • Die Lesezeit wird in Drupal aus dem Text berechnet (FeedKarte::lesezeit(), Phase 5), nicht gepflegt.

DOM-Hinweise

  • Das Foto ist dekorativ (alt=""), der Name steht als Text daneben. Die Initialen tragen aria-hidden="true", damit der Name nicht doppelt vorgelesen wird.
  • Mehrere Autorinnen und Autoren: erste Person gross, weitere Namen im selben __name mit „und“ (Drupal: Feld field_author, Phase 5).
