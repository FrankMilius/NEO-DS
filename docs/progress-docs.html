NEO Design System

Progress

Fortschrittsbalken für determinierte und indeterminierte Ladezustände. Kanonische Klasse: .nc-progress (BEM). Alle Werte kommen aus --nc-progress-* Component-Tokens.

Determiniert

Fortschrittsbalken bei 0%, 25%, 50%, 75% und 100%. Die Breite des Fill-Elements wird über Inline-Styles gesteuert.

0%
25%
50%
75%
100%

Größen

4 Größen: XS (2px), SM (4px, Default), MD (8px), LG (12px).

XS — 2px
SM — 4px (Default)
MD — 8px
LG — 12px

Feedback-Varianten

Farb-Varianten für kontextbezogenen Fortschritt: Success, Warning, Danger, Info.

Default
Success
Warning
Danger
Info

Indeterminiert

.nc-progress--indeterminate zeigt eine endlose Slide-Animation für unbekannten Fortschritt.

Progress mit Label

.nc-progress-labeled zeigt Label und Prozentwert über dem Balken.

Upload 73%
Speicherplatz 92%

HTML-Struktur

Determiniert

<div class="nc-progress" role="progressbar"
     aria-valuenow="50" aria-valuemin="0" aria-valuemax="100"
     aria-label="Fortschritt">
  <div class="nc-progress__fill" style="width: 50%;"></div>
</div>

Indeterminiert

<div class="nc-progress nc-progress--indeterminate"
     role="progressbar" aria-label="Wird geladen">
  <div class="nc-progress__fill"></div>
</div>

Mit Label

<div class="nc-progress-labeled">
  <div class="nc-progress-labeled__header">
    <span class="nc-progress-labeled__label">Upload</span>
    <span class="nc-progress-labeled__value">73%</span>
  </div>
  <div class="nc-progress nc-progress--md"
       role="progressbar" aria-valuenow="73"
       aria-valuemin="0" aria-valuemax="100"
       aria-label="Upload-Fortschritt">
    <div class="nc-progress__fill" style="width: 73%;"></div>
  </div>
</div>

DOM-Hinweise

  • Progress ist ein <div class='nc-progress' role='progressbar' aria-valuenow='X' aria-valuemin='0' aria-valuemax='100'>.
  • Fill ist ein Kind-Element <div class='nc-progress__fill' style='width: X%'>.
  • Fortschritt wird via inline style width auf __fill gesteuert — kein JS-Framework noetig.
  • Indeterminiert (.nc-progress--indeterminate): kein aria-valuenow, endlose Slide-Animation.
  • prefers-reduced-motion: Indeterminate-Animation stoppt, Fill wird 100% mit reduzierter Opacity.
  • Labeled Wrapper (.nc-progress-labeled): Flex-Column mit Header (Label + Value) und Gap.
  • Value-Anzeige nutzt font-variant-numeric: tabular-nums fuer stabile Breite.
  • Pill-Shape via --fnd-radius-full (border-radius: 9999px).

Accessibility

RegelBeschreibung
R1Natives <progress> oder role="progressbar"
R2aria-valuenow, aria-valuemin="0", aria-valuemax="100"
R3aria-label oder sichtbares Label
R4Indeterminiert: kein aria-valuenow (= unbekannter Fortschritt)

Accessibility Referenz

role='progressbar' mit aria-valuenow (0–100), aria-valuemin='0', aria-valuemax='100'. Braucht aria-label oder sichtbares Label via aria-labelledby.

Nicht interaktiv

  • Diese Komponente ist nicht fokussierbar und nicht klickbar.

Farbkontrast: WCAG AA non-text (3:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: mode = indeterminate

  • Pflicht: accessible-name
  • Indeterminiert: KEIN aria-valuenow setzen — Screen Reader kuendigt 'unbekannter Fortschritt' an. aria-label bleibt Pflicht.

Wenn: color = danger

  • Danger-Farbe nie als einziges Signal. Zusaetzlich Text oder Icon fuer Fehlerzustand.
