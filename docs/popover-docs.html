NEO Design System

Popover

Schwebendes Panel für kontextuelle Inhalte, Aktionen oder Formulare. Popover erscheint relativ zu einem Trigger-Element und enthält Header, Body und Footer. Kanonische Klasse: .nc-popover (BEM). Alle Werte kommen aus --nc-popover-* Component-Tokens.

Default Popover

Statisch geöffnetes Popover mit Header (Titel + Close-Button), Body und Footer. Im produktiven Einsatz wird das Panel via JavaScript und hidden-Attribut gesteuert.

Einstellungen

Hier können Einstellungen vorgenommen werden. Der Body-Bereich kann beliebige Inhalte enthalten.

Code

<div class="nc-popover">
  <div class="nc-popover__header">
    <span class="">Einstellungen</span>
    <button class="nc-popover__close" aria-label="Schließen">
      <svg>...</svg>
    </button>
  </div>
  <div class="nc-popover__body">
    <p>Inhalt...</p>
  </div>
  <div class="nc-popover__footer">
    <button class="nc-button nc-button--sm">Speichern</button>
  </div>
</div>

Minimales Popover

Nur mit Body-Inhalt, ohne Header und Footer — für einfache Hinweise.

Positionierung

Das Popover kann über Modifier-Klassen in verschiedene Richtungen positioniert werden. Standard ist unten-links (.nc-popover--bottom-start).

ModifierPosition
.nc-popover--top-startOben links
.nc-popover--top-endOben rechts
.nc-popover--bottom-startUnten links (Default)
.nc-popover--bottom-endUnten rechts
.nc-popover--leftLinks
.nc-popover--rightRechts
