NEO Design System

Breakpoints

6-stufige responsive Breakpoint-Scale. Mobile-First-Ansatz: XS ist der Ausgangspunkt, hoehere Breakpoints erweitern das Layout.

Breakpoint Scale

NameMin-WidthTypische GeraeteVerwendung
xs0Smartphones (Portrait)Default, mobile-first Basis
sm768pxTablets (Portrait)2-Spalten-Layouts, Sidebar-Navigation
md960pxTablets (Landscape)Erweiterte Grid-Layouts, Navigation Flyout
lg1200pxDesktopVolle Layouts, Dashboard-Ansichten
xl1600pxLarge DesktopErweiterte Inhalts-Breite, zusaetzliche Spalten
xxl1920pxUltra-WideMax-Width Container, keine weitere Skalierung

Verwendung (SCSS Mixin)

// Mobile-First: Styles gelten ab dem angegebenen Breakpoint aufwaerts
@include respond-to('md') {
  .my-component {
    flex-direction: row;
    gap: var(--fnd-spacing-06);
  }
}

// Kombinierte Breakpoints
@include respond-to('sm') {
  .my-grid { grid-template-columns: repeat(2, 1fr); }
}
@include respond-to('lg') {
  .my-grid { grid-template-columns: repeat(4, 1fr); }
}

Design-Entscheidungen

  • Mobile-First: Alle Styles beginnen bei XS und werden fuer groessere Screens erweitert.
  • Fluid Spacing: Spacing-Tokens (06–13) skalieren automatisch mit dem Viewport — separate Breakpoint-Anpassungen sind meist nicht noetig.
  • Fluid Typography: Font-Sizes skalieren ebenfalls via clamp() — Heading-Groessen muessen nicht pro Breakpoint angepasst werden.
  • Content-driven Breakpoints: Breakpoints sind am Content ausgerichtet, nicht an Geraeten. sm markiert den Punkt ab dem 2-Spalten-Layouts funktionieren.
