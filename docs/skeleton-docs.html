NEO Design System

Skeleton

Lade-Platzhalter mit Shimmer-Animation. Ersetzt Inhalt während asynchroner Daten geladen werden. Kanonische Klasse: .nc-skeleton (BEM). Alle Werte kommen aus --nc-skeleton-* Component-Tokens.

Text-Zeilen (Standard)

Der Standard-Skeleton ist eine Textzeile in voller Breite. 4 Größen-Stufen verfügbar: XS (12px), SM (16px, Default), MD (24px), LG (48px).

XS — 12px
SM — 16px (Default)
MD — 24px
LG — 48px

Heading-Variante

.nc-skeleton--heading zeigt einen breiteren Platzhalter (60% Breite, MD-Höhe) für Überschriften.

Circle-Variante

.nc-skeleton--circle erstellt einen runden Platzhalter für Avatare (48px × 48px).

Rect-Variante

.nc-skeleton--rect für Flächen-Platzhalter (Bilder, Cards). Volle Breite, mindestens 8rem Höhe.

Skeleton Group

.nc-skeleton-group stapelt mehrere Zeilen mit Abstand. Die letzte Zeile wird automatisch auf 80% Breite gekürzt.

Komposition: Card-Skeleton

Kombination aus Circle, Heading und Text-Zeilen für einen typischen Card-Platzhalter.
