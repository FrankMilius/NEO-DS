NEO Design System

Text Only

Text-Only-Sektion mit scroll-getriggerter Farbanimation für einzelne Wort-Spans. Geeignet für Missionstatements, Hero-Texte und impactreiche Überschriften-Abschnitte. Kanonische Klassen: .text-only und .text-only-wrapper. Alle Farben kommen aus Foundation-Tokens.

Live Demo

Die Animation wird durch das Hinzufügen der Klasse .visible auf dem <p>-Element ausgelöst (typischerweise via IntersectionObserver). Klicke den Button, um die Animation auszulösen.

Wir glauben, dass gutes Design nicht kompliziert sein muss.

Code

<div class="text-only-wrapper">
  <section class="text-only">
    <div>
      <div>
        <p>
          <span>Wort 1</span>
          <span>Wort 2</span>
          <span>Wort 3</span>
        </p>
        <!-- Optional: Button-Container -->
        <p class="button-container">
          <a href="#" class="nc-btn nc-btn--primary">CTA</a>
        </p>
      </div>
    </div>
  </section>
</div>

Standard-Ansicht

Ohne .visible-Klasse sind die Spans in --fnd-color-text-transparency-low (gedämpft) dargestellt. Mit .visible läuft die change-color-Animation.

Standard: gedämpfte Textfarbe

Mit Button-Container

.button-container positioniert sich im Desktop-Layout ebenfalls im Grid (Spalten 1–8) unterhalb des Haupt-Paragraphen.

Dein Design-System für skalierbare Produkte.

Element-Struktur

<div class="text-only-wrapper"> <section class="text-only"> <div> <!-- Outer container --> <div> <!-- Inner grid container (desktop: 12 cols) --> <!-- Haupt-Paragraph mit animierten Spans --> <p> <!-- .visible wird via JS hinzugefügt --> <span>Wort 1</span> <span>Phrase 2</span> <span>Satzende 3.</span> </p> <!-- CTA (optional) --> <p class="button-container"> <a href="/start" class="nc-btn nc-btn--primary">Jetzt starten</a> </p> </div> </div> </section> </div> <!-- JS: Animation via IntersectionObserver --> <script> const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { entry.target.classList.add('visible'); } }); }, { threshold: 0.3 }); document.querySelectorAll('.text-only p:not(.button-container)') .forEach(p => observer.observe(p)); </script>

Accessibility Referenz

Die Farbwechsel-Animation muss für Nutzer mit Bewegungsempfindlichkeit respektvoll behandelt werden. Die globale prefers-reduced-motion-Regel des Design-Systems greift automatisch.

Reduced Motion

  • Die globale prefers-reduced-motion: reduce-Regel in _reset.scss deaktiviert Animationen systemweit
  • Bei Reduced Motion werden die Spans direkt in voller Textfarbe angezeigt — kein Farbwechsel
  • Der Textinhalt ist in beiden Zuständen vollständig lesbar
  • WCAG 2.3.3 (Animation from Interactions, AAA) wird eingehalten

Farbkontrast der gedämpften Spans

  • Der initiale Zustand nutzt --fnd-color-text-transparency-low
  • Sicherstellen, dass dieser Wert mindestens 4.5:1 Kontrast gegenüber dem Hintergrund hat (WCAG 1.4.3)
  • Der Endzustand nach Animation nutzt die Standard-Textfarbe — immer WCAG-konform

IntersectionObserver

  • Die Animation wird durch JS ausgelöst — sie ist nicht essenziell für das Verständnis des Inhalts
  • Bei deaktiviertem JavaScript ist der Text weiterhin lesbar (gedämpfte Farbe, aber voller Inhalt)
  • Der Observer sollte auch prefers-reduced-motion prüfen und die Animation überspringen

Best Practices
