Basis-Liste

Jedes .nc-security-list__item hat einen weißen Hintergrund (--fnd-color-background-base), runde Ecken (--fnd-radius-3xl) und einen sekundären Rahmen.

  • Zwei-Faktor-Authentifizierung
  • Automatische Sicherheitsupdates
  • Penetrationstests durch Dritte

Mit Icons und Beschreibungen

Der Inhalt der Items ist frei gestaltbar. Icons, Titel und Beschreibungen lassen sich flexibel kombinieren.

  • SOC 2 Typ II Jährliche Audits durch unabhängige Prüfer
  • AES-256 Verschlüsselung Alle Daten im Ruhezustand und bei der Übertragung verschlüsselt

Zwei-Spalten-Layout

.nc-security-list ist ein CSS-Grid. Mit grid-template-columns auf dem Container entsteht ein Mehrspalten-Layout.

Accessibility Referenz

Die Security-Liste ist ein statisches Listen-Element. Korrekte HTML-Semantik gewährleistet die Navigierbarkeit für Screenreader-Nutzer.

Semantische Listen-Auszeichnung

  • <ul> und <li> verwenden — niemals <div>
  • Screenreader kündigen die Listenlänge an (z.B. “Liste mit 4 Elementen”)
  • CSS setzt list-style: none — dies entfernt in Safari die Listenrole; bei Bedarf role="list" auf <ul> setzen

Dekorative Icons

  • Icons in den Items sind dekorativ — aria-hidden="true" setzen
  • Der zugehörige Beschreibungstext muss immer als sichtbarer Text vorhanden sein
  • Kein reines Icon ohne sichtbaren Text in einem List-Item verwenden
