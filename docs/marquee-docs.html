NEO Design System

Marquee

Horizontaler Text- oder Logo-Ticker für kontinuierlich scrollende Inhalte. Die Scrollbewegung wird per CSS-Animation oder JavaScript gesteuert. Die Komponente respektiert prefers-reduced-motion. Kanonische Klassen: .nc-marquee (Wrapper), .nc-marquee__track (scrollende Spur), .nc-marquee__text (einzelnes Element).

Text-Ticker

Gleichförmig scrollender Text-Ticker. Inhalte werden verdoppelt, um einen nahtlosen Loop zu erzeugen. Der Track muss mindestens die doppelte Container-Breite haben.

Geschwindigkeit

Die Geschwindigkeit wird über die animation-duration-Eigenschaft gesteuert. Längere Werte ergeben langsamere Bewegung.

Accessibility Referenz

Bewegte Inhalte stellen besondere Anforderungen an die Barrierefreiheit. WCAG 2.2.2 (Pause, Stop, Hide) fordert, dass automatisch scrollende Inhalte pausiert werden können.

prefers-reduced-motion (WCAG 2.3.3)

  • Die Animation muss bei prefers-reduced-motion: reduce deaktiviert werden
  • Empfehlung: @media (prefers-reduced-motion: reduce) { .nc-marquee__track { animation: none; } }
  • Ohne diese Einstellung kann der Ticker für Menschen mit vestibulären Störungen problematisch sein

aria-hidden für dekorativen Inhalt

  • Wenn der Marquee rein dekorativ ist, muss aria-hidden="true" gesetzt werden
  • Duplikate im Track müssen immer aria-hidden="true" tragen
  • Wenn der Inhalt informativ ist, den Volltext als .u-sr-only-Span ergänzen

WCAG 2.2.2: Pause, Stop, Hide

  • Automatisch scrollende Inhalte über 5 Sekunden Länge brauchen eine Pause-Möglichkeit
  • Empfehlung: Pause bei :hover und :focus-within via animation-play-state: paused
  • Optionaler Pause-Button für vollständige WCAG 2.2.2 Konformität
