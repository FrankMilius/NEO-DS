Tooltip

CSS-only Tooltip-Komponente mit 4 Positionierungen und Arrow. Erscheint bei Hover und Focus. Kanonische Klasse: .nc-tooltip (BEM). Alle Werte kommen aus --nc-tooltip-* Component-Tokens.

Einstellungen

Langer Text

Tooltip mit mehrzeiligem Text. Die maximale Breite ist auf 280px begrenzt (--nc-tooltip-max-width).

Dies ist ein längerer Tooltip-Text, der zeigt, wie mehrzeilige Tooltips dargestellt werden.

Disabled Button Pattern

Tooltip auf einem deaktivierten Button. Der Wrapper <span tabindex="0"> macht den Tooltip per Tastatur erreichbar.

Accessibility Referenz

Tooltip-Komponenten müssen die WCAG 2.1 AA-Kriterien erfüllen und dürfen nur ergänzende Informationen enthalten.

role="tooltip"

  • Das Content-Element (.nc-tooltip__content) bekommt role="tooltip"
  • Screenreader erkennen das Element dadurch als Tooltip und kündigen es entsprechend an
  • Jeder Tooltip muss eine eindeutige id haben

aria-describedby

  • Der Trigger (Button, Link etc.) referenziert die Tooltip-ID über aria-describedby
  • Dadurch wird der Tooltip-Text als Beschreibung des Triggers vorgelesen
  • Beispiel: <button aria-describedby="tip-1">

Keyboard-Support

  • :focus-within zeigt den Tooltip, wenn der Trigger per Tab fokussiert wird
  • ESC schließt den Tooltip (optional, erfordert JS)
  • Der Tooltip darf den Fokus nicht einfangen — er ist rein informativ
  • Tab navigiert zum nächsten fokussierbaren Element, nicht in den Tooltip hinein

Disabled-Button Pattern

  • Deaktivierte Buttons (disabled) sind nicht fokussierbar
  • Lösung: Wrapper <span class="nc-tooltip" tabindex="0"> macht den Tooltip per Tastatur erreichbar
  • Der tabindex="0" auf dem Wrapper ermöglicht :focus-within
  • Alternativ: aria-disabled="true" statt disabled verwenden

Ergänzend, nie essenziell

  • Tooltip-Inhalt muss ergänzend sein — die Kernfunktion muss auch ohne Tooltip verständlich bleiben
  • Keine essenziellen Informationen, Formularbeschriftungen oder Fehlermeldungen in Tooltips
  • Tooltips sind auf Mobilgeräten nicht zuverlässig erreichbar (kein Hover)
  • Maximale Textlänge beachten — für längere Inhalte Popover oder Inline-Text verwenden
