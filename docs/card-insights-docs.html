Logo-Karten Sonderfall

          
Bilder mit Dateinamen-Muster /logo-*.svg werden als Logos behandelt: inverser Hintergrund, zentriert, SVG-Filter für Theme-Anpassung.

          

            
<!-- Logo-Karte (automatisch erkannt via CSS :has()) -->
<picture>
  <img src="/assets/screen-1.svg" alt="Logo des Partners XY" />
</picture>

<!-- Theme-Modifier bei abweichendem Hintergrund -->
<picture class="light-secondary-theme">
  <img src="/assets/screen-1.svg" alt="Logo des Partners XY" />
</picture>

          


        


        
        
        
        


          
Semantik & Struktur

          

            
              
ElementEmpfehlung

            
            
              
<img alt>Artikel-Bild: Beschreibung des Bildinhalts. Logo: Name des Unternehmens (z.B. alt="Logo von Partner XY")

              
.button-container aLinktext muss das Ziel klar beschreiben — nicht "Mehr" oder "Weiter"

              
.headingNicht als echtes Heading (<h2>) ausgezeichnet — Hierarchie im Kontext prüfen

              
line-clampVollständiger Text bleibt im DOM (Screenreader lesen alles)

              
Logo SVG-FilterCSS-Filter ändert nur Darstellung, kein semantisches Problem

            
          


          

            
            

              
Lese-Link-Beschriftung

              
    
                
  • Statt "Artikel lesen" besser: "Artikel lesen: Token-Migration in 5 Schritten" oder aria-label="Token-Migration in 5 Schritten lesen" auf dem <a>.
    • 
                
  • Screenreader lesen alle Links auf einer Seite isoliert — der Text muss auch ohne Kontext verständlich sein.
    • 
              

            

          


          

            
            

              
Logo-Kontrast

              
    
                
  • Logos auf inversem Hintergrund: Sicherstellen, dass das Logo ausreichend Kontrast zum Hintergrund hat (mindestens 3:1 für grafische Elemente, WCAG 1.4.11).
    • 
                
  • Der CSS-Filter invertiert SVG-Farben — nach dem Filter den Kontrast visuell prüfen.
    • 
              

            

          


          

            
            

              
Icon-Pfeile im Link

              
    
                
  • Pfeil-Icons im Lese-Link müssen aria-hidden="true" tragen (dekorativ).
    • 
                
  • Der Linktext alleine muss das Ziel verständlich beschreiben.
    •
