NEO Design System

Code Snippet

Code-Anzeige mit farbigem Syntax-Highlighting in drei Varianten: Inline, Single-Line und Multi-Line. Kanonische Klasse: .nc-code-snippet (BEM). Alle Werte kommen aus --nc-cs-* Component-Tokens. Syntax-Highlighting via Prism.js mit theme-aware Farben.

Inline

Für kurze Code-Referenzen im Fließtext. Kein Copy-Button. Nutzt .nc-code-snippet--inline.

Verwende var(--fnd-color-text-primary) für die primäre Textfarbe. Der Befehl npm run build:css kompiliert die SCSS-Dateien. Nutze die Funktion setupCodeSnippets() für Auto-Initialisierung.

Single-Line

Für einzelne Befehle oder kurze Codezeilen. Horizontaler Scroll bei Überlänge. Nutzt .nc-code-snippet--single. 

npm install --save-dev prismjs && npm run build:css
const theme = document.documentElement.getAttribute('data-theme') || 'neo-light-theme';

Multi-Line

Für längere Code-Blöcke mit optionalem Sprach-Label und Show More/Less. Nutzt .nc-code-snippet--multi.

JavaScript 
/**
 * Code Snippet – Vanilla JS Controller
 * Syntax-Highlighting, Copy-to-Clipboard, Show More/Less.
 */
const setupCodeSnippet = (container) => {
  const ac = new AbortController();
  const signal = ac.signal;
  const codeEl = container.querySelector('.nc-code-snippet__code');
  const copyBtn = container.querySelector('.nc-code-snippet__copy');

  // Prism Highlighting
  if (codeEl && typeof Prism !== 'undefined') {
    Prism.highlightElement(codeEl);
  }

  // Copy to Clipboard
  if (copyBtn && codeEl) {
    copyBtn.addEventListener('click', async () => {
      const text = codeEl.textContent;
      await navigator.clipboard.writeText(text);
      copyBtn.classList.add('nc-code-snippet__copy--success');
      setTimeout(() => {
        copyBtn.classList.remove('nc-code-snippet__copy--success');
      }, 2000);
    }, { signal });
  }

  return { destroy: () => ac.abort() };
};

Python 
class TokenGenerator:
    """Generiert Design-Tokens aus einer JSON-Konfiguration."""

    def __init__(self, config_path: str):
        self.config = self._load_config(config_path)
        self.tokens = {}

    def generate(self) -> dict:
        for category, values in self.config.items():
            self.tokens[category] = {
                f"--fnd-{category}-{k}": v
                for k, v in values.items()
            }
        return self.tokens

    @staticmethod
    def _load_config(path: str) -> dict:
        with open(path, 'r') as f:
            return json.load(f)

ORDER BY c.category, t.name;

DOM-Hinweise

  • Inline: <code class='nc-code-snippet nc-code-snippet--inline'>. Kein Copy-Button.
  • Single: <div class='nc-code-snippet nc-code-snippet--single'><pre><code>. Copy-Button oben rechts.
  • Multi: <div class='nc-code-snippet nc-code-snippet--multi'><pre><code>. Copy-Button + Show-More.
  • Copy-Button: aria-label='Code kopieren'. Dual-Icon Pattern (Copy → Check bei Erfolg).
  • Copy-Tooltip: .nc-code-snippet__copy-tooltip — erscheint bei Erfolg unter dem Copy-Button.
  • Show-More: aria-expanded='true/false'. Gradient-Fade im collapsed Zustand.
  • Header: optionale Titelleiste mit Dateiname. Plain/macOS/Window-Varianten.
  • macOS-Dots: .nc-code-snippet__header-dot--close/--minimize/--maximize. Dekorativ.
  • Zeilennummern: CSS-Counter auf .nc-code-snippet__line::before. user-select:none.
  • Zeilen-Highlight: .nc-code-snippet__line--highlighted — farbige Hervorhebung.
  • Wrap: white-space:pre-wrap statt horizontalem Scroll.
  • Sprach-Label (optional): Badge oben links mit Sprach-Kennung (z.B. 'HTML', 'SCSS').
  • Syntax-Highlighting via Prism.js — .token-Klassen werden auf --nc-cs-syntax-* Tokens gemappt.
  • Verhalten (neo-behaviors code-snippet): Kopieren setzt .nc-code-snippet__copy--success und aria-label='Kopiert!' fuer 2 s; Mehr anzeigen schaltet .nc-code-snippet--expanded und aria-expanded; passt der Code in die eingeklappte Hoehe, ist der Knopf [hidden].

Accessibility Referenz

Code-Snippet ist primaer nicht-interaktiv. Copy- und Show-More-Buttons sind interaktive Sub-Elemente mit eigener a11y.

Nicht interaktiv

  • Diese Komponente ist nicht fokussierbar und nicht klickbar.

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: variant = single, multi

  • Empfohlen: aria-label
  • Copy-Button braucht aria-label='Code kopieren'. Erfolgs-Feedback sollte ueber aria-live kommuniziert werden.

Wenn: Spezialbedingung

  • Empfohlen: aria-expanded
  • Show-More-Button braucht aria-expanded='true/false'. Button-Text wechselt zwischen 'Mehr anzeigen' und 'Weniger anzeigen'.

Wenn: features = with-line-numbers

  • Zeilennummern via CSS-Counter sind dekorativ (user-select:none). Screen Reader ignoriert sie.
