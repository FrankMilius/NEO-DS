NEO Design System

Search

Suchkomponente mit Eingabefeld, Ergebnis-Panel, gruppierten Treffern und Highlight-Markierung. Kanonische Klasse: .nc-search (BEM). Alle Werte kommen aus --nc-search-* Component-Tokens.

Sucheingabe

Das Suchfeld mit Icon. Der Basis-Zustand ohne geöffnetes Ergebnis-Panel.

Ergebnis-Panel (statisch offen)

Das Ergebnis-Panel zeigt gruppierte Treffer. Hier statisch geöffnet für Demo-Zwecke.

Komponenten
Button Interaktive Schaltfläche mit verschiedenen Varianten Button Micro Kompakte Schaltfläche für enge Bereiche
Foundation
Button Tokens Component-Tokens für die Button-Komponente

Highlight-Markierung

Treffer werden mit .nc-search__highlight hervorgehoben.

Die Suchkomponente ermöglicht schnelles Finden von Inhalten. Der Suchbegriff wird farblich markiert.

Code

<span class="nc-search__highlight">Suchbegriff</span>

Keine Ergebnisse

Wenn keine Treffer gefunden werden, zeigt das Panel einen Empty State.

Keine Ergebnisse für «xyzqwerty»

Full Width

Die .nc-search--full Variante dehnt die Suche auf die volle Breite des Containers.

DOM-Hinweise

  • Root: role='combobox', aria-haspopup='listbox', aria-expanded='true|false', data-state='closed|open'.
  • Input-Wrapper: relative Container. Enthält Icon (links), Input (mitte), Clear-Trigger (rechts, bedingt), Shortcut-Hint (rechts, bedingt).
  • Clear-Trigger: button[aria-label='Suche zuruecksetzen']. Nur sichtbar wenn input.value.length > 0. Klick: value='', focus auf Input.
  • Escape-Verhalten (3-stufig): 1. Loescht Ghost-Text falls aktiv. 2. Schliesst Results-Panel (data-state='closed'). 3. Blur vom Input.
  • Outside-Click: Schliesst Results-Panel und setzt data-state='closed' auf Root.
  • Type-to-Select: ArrowDown navigiert sofort in die Results. Enter waehlt den fokussierten Treffer.
  • History-First: Bei leerem Input (value='') zeigt Results-Panel die letzten 5 Suchanfragen.
  • Recent/Popular: Falls keine History vorhanden, werden 'Beliebte Suchbegriffe' als Kaltstart angezeigt.
  • Ghost: position:absolute, pointer-events:none. Text beginnt mit aktuellem Input-Wert. ArrowRight uebernimmt.
  • Mobile Full-Screen (< 768px): position:fixed, inset:0, z-index:modal. Header wird durch .nc-search__mobile-header ersetzt.
  • Mobile Results: height:100dvh - input-height, overflow-y:auto, scroll fuer lange Listen.
  • Navigation-Integration: Results-Panel top-offset = var(--nc-nav-height). Backdrop hinter Results, vor Header-Content.
  • Backdrop: position:fixed, inset:0, bg:rgba(0,0,0,var(--nc-search-backdrop-opacity)). Klick = Close.

Accessibility Referenz

Root: role='combobox', aria-haspopup='listbox', aria-expanded. Input: aria-autocomplete='list', aria-controls. Results: role='listbox'. Items: role='option', aria-selected. Clear-Trigger: aria-label='Suche zuruecksetzen'. Keyboard: ArrowDown/Up navigiert, Enter waehlt, Escape schliesst (3-stufig: Ghost → Results → Blur).

Farbkontrast: WCAG AA normal text (4.5:1)

  • Alle Farbvarianten erfüllen dieses Kontrastziel im Default-Theme.
  • Bei Custom-Überschreibungen den Kontrast manuell prüfen.

Zugänglicher Name erforderlich

  • Komponente muss einen zugänglichen Namen haben (via Text-Inhalt, aria-label oder aria-labelledby).

Wenn: resultsState = empty

  • Empfohlen: aria-live
  • Empty-State: 'Keine Ergebnisse' via aria-live='polite' ankuendigen.

Wenn: resultsState = loading

  • Empfohlen: aria-busy
  • Loading-State: aria-busy='true' auf dem Results-Container.

Wenn: scope = scoped

  • Empfohlen: aria-label
  • Scope-Trigger: aria-label beschreibt aktuellen Suchbereich.

Wenn: width = viewport

  • Pflicht: focus-trap
  • Pflicht: aria-modal
  • Mobile Full-Screen: Focus-Trap aktiv, aria-modal='true', Escape schliesst.

Wenn: Spezialbedingung

  • Pflicht: aria-label
  • Clear-Trigger: aria-label='Suche zuruecksetzen'. Nur sichtbar bei value.length > 0.
