NEO Design System

Border

6-stufige Border-Width-Skala von 0px (null) bis 8px (xl/bold) plus 3 Border-Styles. Alle Tokens sind als CSS Custom Properties --fnd-border-width-{size} und --fnd-border-style-{name} verfügbar.

Border-Width-Skala

6 Stufen (null–xl), ergänzt durch semantische Aliases für sprechende Benennung. Default ist sm (2px).

null 0px --fnd-border-width-null
xs 1px --fnd-border-width-xs
sm (default) 2px --fnd-border-width-sm
md 4px --fnd-border-width-md
lg 6px --fnd-border-width-lg
xl 8px --fnd-border-width-xl

Button-Border-Width-Mapping

Buttons verwenden ein 2-Stufen-System: kleine Buttons (XS/SM/MD) erhalten xs (1px), große Buttons (LG) erhalten sm (2px).

XS (24px) --nc-button-border-width-sm → 1px Stufe 1
SM (32px) --nc-button-border-width-sm → 1px Stufe 1
MD (40px) --nc-button-border-width-sm → 1px Stufe 1
LG (48px) --nc-button-border-width-lg → 2px Stufe 2
Button-Größe Stufe Component Token Foundation Token Wert
XS / SM / MD Stufe 1 --nc-button-border-width-sm --fnd-border-width-xs 1px
LG Stufe 2 --nc-button-border-width-lg --fnd-border-width-sm 2px

Code-Beispiele

CSS Custom Properties

/* Border-Width-Token als CSS Custom Property */ .card { border: var(--fnd-border-width-xs) solid var(--fnd-color-border-primary); } /* Semantischen Alias verwenden */ .divider { border-bottom: var(--fnd-border-width-hairline) solid var(--fnd-color-border-secondary); } /* Default-Width */ .panel { border: var(--fnd-border-width-default) solid var(--fnd-color-border-primary); /* = 2px */ } /* Border-Style-Token */ .dashed-box { border: var(--fnd-border-width-sm) var(--fnd-border-style-dashed) var(--fnd-color-border-primary); }

SCSS-Getter

@use '../00-settings' as *; // SCSS-Funktion border-width() liefert den px-Wert .element { border-width: border-width('sm'); // 2px } // Semantischer Alias .element-alt { border-width: border-width('hairline'); // 1px } // SCSS-Funktion border-style() .element-dashed { border-style: border-style('dashed'); // dashed }

Design-Prinzipien

Scale + Aliases

Die numerische Skala (null–xl) definiert die konkreten Werte. Semantische Aliases (hairline, thin, light, medium, bold, thick) bieten sprechende Namen für häufig verwendete Kombinationen.

2-Stufen Button-Modell

Kleine Buttons (XS/SM/MD) nutzen 1px Border, große Buttons (LG) 2px. Der visuelle Sprung ist subtil, sorgt aber für optische Harmonie bei größeren Button-Flächen.

Theming-fähig

Wie bei Radii können Border-Width-Tokens pro Scope überschrieben werden. Z.B. --fnd-border-width-xs: 2px für ein Theme mit dickeren Borders.

Migrations-Leitfaden

Die alte Named-Skala (hairline, thin, medium, thick) wurde durch eine numerische Skala (null–xl) mit semantischen Aliases ersetzt.

Alt Neu (Scale) Alias verfügbar Wert
hairline (1px) --fnd-border-width-xs --fnd-border-width-hairline 1px
thin (1px) --fnd-border-width-xs --fnd-border-width-thin 1px
medium (2px) --fnd-border-width-sm — 2px (Wert geändert: war 2px, medium zeigt jetzt auf lg=6px)
thick (4px) --fnd-border-width-md --fnd-border-width-thick 4px
/* Alter Code (funktioniert über Aliases): */ .legacy { border-width: var(--fnd-border-width-hairline); } /* = 1px */ .legacy { border-width: var(--fnd-border-width-thick); } /* = 4px */ /* Neuer Code (Scale-Tokens bevorzugt): */ .modern { border-width: var(--fnd-border-width-xs); } /* = 1px */ .modern { border-width: var(--fnd-border-width-md); } /* = 4px */
