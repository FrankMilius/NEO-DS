Segmented Control

Single-Select Segmented Control zum Umschalten zwischen zusammengehörigen Ansichten oder Filtern. Immer genau ein Segment ist aktiv. Kanonische Klasse: .nc-segmented-control (BEM). Alle Werte kommen aus --nc-segmented-control-* Component-Tokens.

Accessibility Referenz

Segmented Controls müssen die WCAG 2.1 AA-Kriterien erfüllen. Die Komponente nutzt das radiogroup-Pattern.

R4: Radiogroup + Radio + aria-checked (Pflicht)

  • Der Container muss role="radiogroup" haben
  • Jedes Segment muss role="radio" haben
  • Genau ein Segment hat aria-checked="true", alle anderen aria-checked="false"
  • Der Container sollte ein aria-label besitzen, das den Zweck der Gruppe beschreibt
<div class="nc-segmented-control" role="radiogroup" aria-label="Ansichtsmodus"> <button class="nc-segmented-control__item nc-segmented-control__item--active" role="radio" aria-checked="true" tabindex="0"> Raster </button> <button class="nc-segmented-control__item" role="radio" aria-checked="false" tabindex="-1"> Liste </button> </div>

Arrow Key Navigation (Roving Tabindex)

  • Tab setzt den Fokus auf das aktive Segment (das mit tabindex="0")
  • ArrowRight / ArrowDown bewegt den Fokus und die Selektion zum nächsten Segment
  • ArrowLeft / ArrowUp bewegt den Fokus und die Selektion zum vorherigen Segment
  • Navigation ist zyklisch: nach dem letzten Segment kommt das erste
  • Nur das aktive Segment hat tabindex="0", alle anderen tabindex="-1"
  • Disabled Segmente werden bei der Pfeiltasten-Navigation übersprungen

Exklusive Selektion

  • Zu jedem Zeitpunkt ist genau ein Segment aria-checked="true"
  • Wenn ein Segment ausgewählt wird, werden alle anderen automatisch auf aria-checked="false" gesetzt
  • Das aktive Segment erhält die Klasse .nc-segmented-control__item--active
  • Es darf nie mehr als ein aktives Segment geben — und nie keines

R6: Icon-Only Segmente brauchen aria-label

  • Segmente die nur ein Icon und keinen sichtbaren Text enthalten, müssen ein aria-label haben
  • Das aria-label beschreibt die Aktion oder Ansicht, z.B. aria-label="Rasteransicht"
  • SVG-Icons erben currentColor — Kontrast wird automatisch gewährleistet
<!-- RICHTIG: Icon-Only Segment mit aria-label --> <button class="nc-segmented-control__item" role="radio" aria-checked="false" aria-label="Listenansicht"> <svg class="nc-segmented-control__icon">...</svg> </button> <!-- FALSCH: Icon-Only Segment ohne aria-label --> <button class="nc-segmented-control__item" role="radio" aria-checked="false"> <svg class="nc-segmented-control__icon">...</svg> </button>

Sichtbare Selektion über Farbe hinaus

  • Das aktive Segment hat einen erhöhten Hintergrund (elevated background) — nicht nur eine andere Farbe
  • Zusätzlich erhält das aktive Segment einen Schatten (box-shadow), der es visuell vom Container abhebt
  • Das aktive Segment hat ein höheres Font-Weight (600 vs. 500) für zusätzliche Unterscheidung
  • Diese Kombination stellt sicher, dass die Selektion nicht allein auf Farbe basiert (WCAG 1.4.1)
